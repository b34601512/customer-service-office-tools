# 10.自动报量 · 项目索引（开工先看）

> 从管易 ERP 取「订单商品明细统计」CSV → 按日期/店铺/料号/白夜班汇总 → 写全年报量模板（Excel + 长图）。
> 最后更新：2026-10-09。本项目无 `断点记录.md`：状态看根 [`断点记录.md`](../断点记录.md)。

## ① 开工先看什么
1. 本索引 → [`CLAUDE.md`](./CLAUDE.md)（结构、数据流、运行方式）→ [`README.md`](./README.md)（入口）。
2. **要 ERP 单取数**（也服务 7号 登记）：先看 [`../20.经验库/ERP查单两段式/`](../20.经验库/ERP查单两段式/)。

## ② 规矩 / 口径（一句话 + 出处）
- 日常入口：双击 [`运行自动报量CLI.bat`](./运行自动报量CLI.bat)；**菜单 1 = ERP 一键流程**，菜单 2/3 = 本地 CSV 手动补报 → `CLAUDE.md` §5。
- ERP 导出循环：`查询汇总 → 点「查询」→ 等明细网格（合计行/`.ag-row`，120s 超时）→ 才 CSV 导出`；**明细未加载绝不导出**（会出 787 B 空表）→ 已修 + 反向断言锁死（2026-10-09）。
- ERP 日期框必须**回车提交**（`Tab` 会把开始时间还原成旧值）；制单时间范围**不能超过 1 年** → 同上。
- 报量过滤：校验 CSV、过滤**退款/作废/赠品**后聚合 → `CLAUDE.md` §3。
- 一个平台单可能对应**多个 ERP 单**（原单 + 0 元补发单）；赠品行 0 元 → 台账 10-09。

## ③ 经验 / 踩坑
- ERP 查单两段式（订单查询定日期 → 报表按范围导；也能直接取登记字段）：[`../20.经验库/ERP查单两段式/`](../20.经验库/ERP查单两段式/)。
- 已成规律：**Edge 下载收尾 `save_as` 崩溃 5 次**（`.crdownload` 结构校验可恢复），建议做正式「下载恢复」兜底 → [`失败台账.md`](../失败台账.md) 10-09、[`失败台账-规律分析.md`](../失败台账-规律分析.md) §一#4。
- 报量逻辑回归测试：`自动报量CLI/tests/`（28/28 绿，2026-10-09）。

## ④ 常用命令
```bash
cd "10.自动报量"
# 日常：双击 运行自动报量CLI.bat（菜单1=ERP一键；2/3=本地CSV）
cd 自动报量CLI && python -X utf8 -m unittest discover -s tests   # 回归测试
# 网页备用：html导入工具/点我开始.html（选空白模板 + CSV + 日期）
```

## ⑤ 红线
- ERP / 平台一律**只读导出**；不重复请求、失败不自动重试（现场写 [`失败台账.md`](../失败台账.md)）。
- ERP 密码/凭据本机加密保存，`project-config/`、登录态不入库。
- 报表产物是唯一验收依据（真数据件），不认脚本自报成功。
