本项目以店铺为执行单位，自动采集天猫、京东、拼多多、抖音客服指标，并写入统一汇总表。

## 主要能力

- 多平台、多店铺顺序汇总；店铺数量增加不改变运行方式。
- 业绩、平均响应时间、3分钟响应率、客户满意度四类指标。
- 智能日期、全局手动日期、单店自定义日期。
- 自动登录辅助；滑块或安全验证由用户在业务浏览器中完成，程序原地等待。
- 成功源文件复用，避免相同店铺、日期和来源重复下载。
- CLI内管理店铺、客服姓名映射、凭证、源文件和汇总表。

## 启动

双击 `启动控制台.bat`，或运行：

```powershell
npm run cli
```

配置文件位于 `project-config/platform-config.json`，运行产物位于 `runtime`。

## 制作便携版

双击 `打包便携版.bat`。便携包会排除当前电脑的配置、账号密码、登录状态、日志和下载数据。

包内“应用”和“共享CLI”保持同级，根目录保留启动批处理和内置 Node。请完整解压后运行，不要单独移动“应用”目录。每次打包会在硬盘根目录的“备份文件夹/客服数据自动更新/打包校验”中独立解压，用包内 Node 检查首次初始化、六个 TUI 页面和运行依赖；校验失败不会报告打包成功。

打包还会使用虚构配置检查四个平台新增店铺、凭证、路径、日期、客服映射、京东筛选、金山设置及重启读取。测试内容只写入独立校验目录，不会装入 ZIP。首次使用请按包内“使用说明.txt”完成配置，并准备已有的 `.xlsx` 汇总表模板。


## 浏览器运行模式（混合无头分支）

默认 `npm run cli` 或 `npm run cli:hybrid`：采集使用无头浏览器；登录失效、安全验证、无法精确自动切店时，在安全边界重建可见浏览器供人工处理。手动“打开后台页面”一直保留可见窗口。

- `npm run cli:headed`：全程可见，兼容排查入口。
- `npm run cli:headless`：严格无头；需要人工处理时明确报错，不隐藏等待。
- `npm run test:hybrid`：无账号单元测试。
- `npm run test:browser`：需要已安装 Chrome，使用虚构页面做浏览器集成测试。

不是“验证码自动破解”或“所有广告自动消失”。只关闭可确认的营销弹层/已知广告页，未知弹窗不猜点。可能已经触发导出的数据源不会自动重放，避免重复导出；当前任务结果保留，可单店重跑。完整验收与回退说明见 `HEADLESS_TESTING.md`。

公开仓库未包含金山 AirScript 的三个本地 `.txt` 模板。默认测试明确跳过依赖这些文件的模板集成用例，其他金山本地数据/请求/回执测试照常运行；本机已有模板时会全部执行。`npm run test:kdocs-templates` 强制要求模板齐全，缺失即失败。此分支没有虚构或替换你的在线金山脚本。
