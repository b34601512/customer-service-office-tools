# 9号项目混合无头：本地验收

## 分支与边界

开发分支：`refactor/9-hybrid-headless`。在本地真实平台验证通过并明确确认前，不合并主线。

只重构浏览器生命周期、人工验证交接和弹窗防护。不修改客服姓名映射、日期业务规则、源表复用和汇总表字段，不增加账号并发，不取消原有点击节流。现有CLI/TUI保留。

## 本地开始

在仓库根目录先检查 `git status`，保留本地修改和本机配置；不要运行 `git reset --hard` 或 `git clean -fdx`。

```powershell
git fetch origin
git switch --track origin/refactor/9-hybrid-headless
cd "9.客服数据自动更新"
npm ci
npm test
npm run test:browser
npm run cli:hybrid
```

已有同名本地分支时，使用 `git switch refactor/9-hybrid-headless`，然后 `git pull --ff-only`。在开发前另行备份本机汇总表；测试前关闭 Excel/WPS。首次真实登录或没有有效登录态时会打开可见浏览器。

## 实现方式

无头是完整 Chrome 的 `--headless=new`，不是隐藏/最小化现有窗口。人工交接会先让当前下载函数完成清理，然后正常关闭旧浏览器，再用同一账号资料目录重建可见浏览器。不会让两个进程同时占用该目录。

登录失效或已识别的验证码出现在导出前：仅重新执行当前数据源，重新验证店铺和日期。可见模式保持至该店任务结束；后续店铺仍按所选模式启动。

可能已经提交导出之后：打开可见浏览器，但不自动重放；返回 `EXPORT_OUTCOME_UNCERTAIN`。先确认源文件/平台导出任务，再单店重跑。普通网络/字段/业务报错不被当成人工验证来盲目重试。退出请求不允许再次开窗。

无头没有可关闭的主窗口，故使用 CDP `Browser.close` 正常退出落盘；只有在进程确认归属本项目后才发命令，仍保留现有关闭失败兜底。

营销弹层只按明确文字与关闭入口处理，验证/授权/支付/导出/切店对话框受保护。已知广告域名的新页会关闭，未知域名、登录页、导出页及暂时空白页默认保留。网页内广告和新窗口是不同问题，本实现不承诺屏蔽全部广告。弹窗循环有总时限和次数限制，不使用强制点击穿透遮挡。

除拼多多旧导出事件链保留兼容例外外，不再全局关闭 Chrome 自带弹窗拦截。可设置 `CUSTOMER_PERFORMANCE_ALLOW_POPUPS=1` 临时放行，`0` 强制开启浏览器拦截；这不等于网页广告开关。没有默认屏蔽图片、验证码资源、业务请求，也没有通过请求路由关闭浏览器缓存。

## 运行选项

`npm run cli:headed` 为全程可见兼容入口；`npm run cli:headless` 为严格无头，遇到人工处理明确失败，不等待一个看不见的窗口。

可通过 `CUSTOMER_PERFORMANCE_BROWSER_MODE=hybrid|headed|headless` 选择默认模式。`CUSTOMER_PERFORMANCE_HUMAN_TIMEOUT_MS` 为人工安全验证等待毫秒，默认180000，允许1000至900000。登录页原有平台等待上限仍然生效。配置在进程环境中，不改写你的真实账号配置。

## 真实平台验收

四个平台各选一家测试店，对同一日期范围分别运行可见模式和混合模式，对比源表、客服姓名、业绩、响应指标和汇总表行数。确认没有串店。

当天再次运行，应按原规则复用今天源表；只有强制下载才重新导出。人工退出登录后再跑，观察可见窗口出现、人工验证后续跑。导出已提交时触发验证，应明确停止而不是重复提交。

出现营销弹层时检查是否正确关闭；出现业务确认或验证码时必须保留。关闭程序后确认受控浏览器正常退出、账号资料仍可复用。真实验证码、弹层变体和平台登录态必须以你的本机实测为准。

## 自动化验收范围

`npm test`：原有回归与新增无账号单元测试。

`npm run test:browser`：真实Chrome，但页面、验证码提示、Cookie和下载文件全部是测试构造；不会访问真实店铺。Windows还覆盖同一资料目录从无头到可见的交接。

仓库原本没有三个本地 AirScript .txt 模板，原有全量测试在干净Windows环境会因此 ENOENT。本分支将“本地模板集成”和“代码内本地数据/客户端校验”分开：缺模板只明确跳过依赖模板的用例，不伪造模板、不跳过其他断言。恢复你本机已有模板后执行 `npm run test:kdocs-templates`，该命令缺任何模板就失败。这不代表在线金山脚本已通过远程实测。

## 回退

只切运行模式时：退出后重新用 `npm run cli:headed` 启动。

回退代码时：先保留工作区修改，再切回 `main` 并 `git pull --ff-only`。本分支不迁移或删除你的真实配置。不要把 runtime、账号资料、源表或截图提交至公开仓库。
