## 红线
- 金山文档**只按登记好的 AirScript 通道写**（webhook + token；写前 allowWrite 门、写后回读）；不做浏览器手写。
- 电商平台后台（京东/天猫/拼多多/抖音）一律**只读**；京东物流页只点「查询/导出明细」。
- 删除/覆盖类写入 = 覆盖『京东仓退货数据』是既定口径（用户指定「直接覆盖」）；其它表不动。
- 失败不自动重试；登录/滑块/验证码 → 停下问人。
