# 德达医疗业务专用资料

这里仅保存德达医疗真实业务内容；通用方法统一从 `../../01.通用/` 获取。

## 新规则

| 内容 | 放哪里 |
|---|---|
| 通用操作方法 | `../../01.通用/方法论/` |
| 探域平台接口与执行方法 | `../../01.通用/平台适配/探域/` |
| 参数化脚本 | `../../01.通用/工具/` |
| 德达政策、型号、活动 | 本目录 |
| 德达对象ID、当前配置 | 本目录 |
| 德达任务参数 | `任务/` |
| 历史一次性脚本 | 仅作历史证据，不直接执行 |

## AI怎么做

先读通用手册，再读本次任务对应的德达资料。需要修改后台时，把公司差异写成任务JSON，交给通用执行器处理。

例如知识卡修改不再写一个 `apply-xxx.cjs`，而是：

```text
德达业务事实/主管确认
        ↓
任务/xxx.json
        ↓
../../01.通用/工具/探域知识卡任务执行器.cjs
        ↓
写前核对 → 保存 → 回读 → 记录
```

图片修改同理：坐标、文字、源文件属于德达任务参数；编辑算法属于通用工具。

## 迁移说明

当前目录仍保留大量旧记录、快照和一次性脚本，用于追溯历史。它们不再是新任务的执行入口。后续新增内容优先按“业务事实/任务参数”保存，不再继续复制通用代码。
