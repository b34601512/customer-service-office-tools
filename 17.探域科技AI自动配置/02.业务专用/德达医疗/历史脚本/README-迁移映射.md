# 历史脚本迁移映射

本目录共有35个可执行历史脚本，另有2个JSON数据文件。它们保留用于追溯，但不再是新任务入口。

| 历史类别 | 数量 | 新方式 |
|---|---:|---|
| 计划/审核类 | 21 | `01.通用/工具/规则任务生成器.cjs` + 德达规则JSON |
| 修改/确认/拆分/停用类 | 9 | `01.通用/工具/探域知识卡任务执行器.cjs` + 德达知识卡任务JSON |
| 核验类 | 2 | 同一知识卡执行器使用 `--action verify` |
| 图片定点处理 | 2 | `01.通用/工具/图片定点编辑器.py` + 德达图片任务JSON |
| 图片上传/发布 | 1 | 暂保留为历史参考，后续再抽平台通用上传能力 |
| 数据JSON | 2 | 继续作为业务参数/历史索引，不属于执行代码 |

## 迁移结论

35个可执行脚本中，34个的核心逻辑已经可以由通用工具承担；公司专用区只需要保留业务事实和任务参数。

最后1个 `publish-deterministic-tutorials.cjs` 同时包含图片上传、知识卡新建/更新和德达默认值，暂不直接重跑。需要再次做同类任务时，应先把“上传与绑定”抽成探域平台通用工具，再把德达型号、图片和目标卡写成任务JSON。

## 文件名不是授权

`apply-*`、`confirm-*`、`publish-*` 等名称只说明历史用途，不代表当前允许执行。任何新任务仍按当前主管授权、当前后台状态和通用手册执行。
