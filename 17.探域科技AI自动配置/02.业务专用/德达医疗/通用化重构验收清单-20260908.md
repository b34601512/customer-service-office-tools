# 17号项目通用化重构验收清单

## 意图

把当前德达专用脚本按职责重构为少量可跨公司复用的通用引擎；公司差异只保留在独立私有参数和业务数据中，让其他客服主管的AI能读懂、配置和安全执行。

## 边界

- 通用目录不得出现德达公司名、店铺ID、账号、Cookie/Token、商品/SKU、政策、真实Agent正文、真实快照和订单数据。
- 不发布业务规则，不修改正式Agent，不删除文件；旧文件只允许移动到备份目录。
- 禁止有头GUI；无头GUI仅限模拟测试，后台配置优先API。

## 验收清单

- [x] 完成56个德达脚本逐个职责分类：通用引擎、平台适配、公司私有作业、废弃/重复。见`通用化脚本分类清单-20260908.md`。
- [x] 通用引擎不硬编码公司、店铺、账号、商品、卡片ID、业务政策和本机路径；通用目录静态扫描通过。
- [x] 探域平台适配层参数化baseUrl、登录画像、店铺范围、请求体、备份目录，并额外参数化依赖路径和浏览器通道。
- [x] 通用读写引擎默认只读；写入需显式动作，保存前备份、保存后完整回读。
- [x] 通用模拟测试支持测试问题参数化，并验证新问题/新回复，避免历史上下文误判；德达专用脚本已有严格无头实测通过。
