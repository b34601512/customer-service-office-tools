# 德达医疗任务参数

这里放“本次德达业务差异”，不放通用执行代码。

## 推荐三种任务文件

### 1. 规则任务

用于从后台快照生成before/after计划。

通用模板：`../../../01.通用/模板/规则任务.example.json`
通用工具：`../../../01.通用/工具/规则任务生成器.cjs`

文件里可以出现德达的型号、店铺ID、旧话术、新话术等真实业务内容。

### 2. 知识卡修改任务

用于已经明确具体卡ID和完整before/after的修改。

通用模板：`../../../01.通用/模板/知识卡修改任务.example.json`
通用工具：`../../../01.通用/工具/探域知识卡任务执行器.cjs`

### 3. 图片定点编辑任务

用于德达图片的坐标、替换文字和源文件路径。

通用模板：`../../../01.通用/模板/图片定点编辑任务.example.json`
通用工具：`../../../01.通用/工具/图片定点编辑器.py`

## 原则

业务发生变化时优先改任务参数和业务记录，不复制一个新的 `.cjs` / `.py`。

旧 `历史脚本/` 只用来查“当时做过什么”，不能作为当前任务直接执行入口。
