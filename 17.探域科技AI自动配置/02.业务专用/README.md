# 业务专用区

这里只存某一家公司的真实业务内容。

## 可以放什么

- 公司政策、活动规则、售前售后口径
- 店铺、商品、SKU、型号范围
- 当前后台配置、快照、待拍板事项
- 本公司操作记录、执行日志、备份索引
- 只有本公司才成立的业务脚本或一次性迁移脚本

## 不应该放什么

只要换一家公司仍然成立，就不应留在这里，应抽到 `../01.通用/`：

- 怎么读取完整知识库
- 怎么判断规则冲突
- 怎么做before/after计划
- 怎么备份、写入、回读、验收、恢复
- 探域接口调用方法
- 在线文档读取方法
- 通用图片绑定、规则审计、范围审计方法

## AI边界

进入某家公司目录后，才允许读取该公司的业务事实。不得把A公司的政策、店铺ID、商品ID、账号、路径、历史授权带到B公司。
