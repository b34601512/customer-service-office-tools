## 1. 登录、集团与店铺

- 后台地址：`https://agent.tanyuai.com`。
- 主账号登录：开户手机号 + 验证码，或账号密码；主账号可绑定微信扫码登录。
- 角色创建（决定谁能操作后台）：集团与店铺 → 集团子账号 → 角色管理 → 新建角色（如客服主管、售前/售后客服、管理员）。
- 子账号创建：集团与店铺 → 集团子账号 → 子账号管理 → 新建子账号。
  - 两种用途：给客服登录智能体客户端接待；给运营登录商家后台做配置。
  - 建议用邀请成员微信扫码创建；扫码创建的账号**没有自动绑定角色，需手动绑定**。
  - 子账号账号密码登录格式：`用户名 + @ + 主账号手机号`。
- 店铺授权：**必须从探域智能体商家管理后台操作**（否则授权信息无法与集团关联）。授权后智能体才能获取客服账号、买家订单、商品详情。
  - 各平台逐步骤教程（含客户端安装托管、淘宝/抖店/京东自营/拼多多）见同目录 `店铺授权与客户端接入.md`。
  - 淘宝：内嵌迁移，需买【探域智能体】应用；另买【利润库存】应用（影响物流信息、售后工单）。
  - 抖音：需【路人打单】（影响物流信息、售后工单），并按迁移步骤接入【探域智能体】。
  - 京东自营：应用【探域客服助手】；**用供应商子账号授权（不支持店铺主账号，子账号必须是英文）**，且该子账号需同时有供应商后台和京麦后台权限、已绑定目标自营店铺、已绑定对应产品线。
  - 京东POP（非自营）：应用【探域客服助手】，店铺主账号授权。
  - 拼多多：主账号/子账号均可，授权账号须有商品管理权限；拼多多无需购买授权，发“店铺+店铺ID”给销售添加；店铺ID获取：客户端下载拼多多工作台 → 登录店铺在线一下 → 复制店铺ID。
  - 快手：【探域CRM】，店铺主账号。
  - 判断京东自营登录的是哪种子账号：账号前缀是店铺ID=店铺子账号；是供应商简码=供应商子账号（最终以智能体客户端判断为准）。
- 商品同步学习：店铺授权成功后一键解锁。路径：商品管理 → 商品列表 → 勾选商品。
  - 学习前先勾“禁用AI商品学习清单”，避免误耗积分；支持商品ID批量导入/批量禁用。
  - 禁用后智能体不再学习该商品，也不能用之前的对应知识卡片。
  - AI商品学习规则（自动添加/手动添加）：新链接默认“普通商品”不会自动学习；仅手动添加=初始默认。
- 店铺子账号：同步店铺客服子账号，用于查看登录情况、选金牌客服、建客服分组。
  - 金牌客服：启动即设为金牌客服；智能体可学其聊天知识（人工自己编辑发出=默认不可信）和采纳知识（点击采纳发送=默认可信）。学/采纳对象**只有金牌客服**，普通客服不算。
  - 客服分组：分组管理里配置；常用于触发器排查（查看子账号登录情况）。
  - 京东自营：若京麦登录的是供应商子账号，需去对应自营店铺机器人后台**手动添加客服子账号**。
- 财务中心：订购记录（套餐）；积分消耗明细。
  - 商品学习 1 个=10 积分（只学 1 次）；京东自营一个 SKU=一个独立商品链接，各按 10 积分算。
  - 国补问答回复：当天算 1 人/1 积分（同一天重复进线算 1 人次）。
- 商品分组：给不同店铺的同款商品分组，统一管理。建议每张文档知识卡都有“适用范围”和“标签体系”；适用范围由粗到细：平台/店铺通用 → 类目通用 → 指定商品通用；一张卡尽量解决一类问题（而非一个问题）。

## 2. 客服 Agent Builder

### 开场白

- 欢迎语（路径：欢迎语 → 话术策略 → 添加欢迎语）。前提先在店铺管理 → 开启智能体接待。
  - 可设永久时效/固定时效（大促用）；适用客服（全部或指定客服/客服组）。
  - 话术设置可按时间段/订单状态；可指定订单状态、生效时段。
  - 发送内容支持文本、表情包、变量（买家昵称/客服昵称/店铺名/换行符/买家称呼）、图片；可多条随机发送。
  - 延迟发送：第一条之后再发一条，最长 3 秒。
- 商品卖点：买家进线可发给售前买家。开关“自动发送卖点”；“进店优先发送卖点”开启时从商详进线只发卖点不发欢迎语；未自建卖点时智能体按商品知识自动生成。

### 知识中心

- 知识库（投喂重点）：
  - 视图：知识视图（按检索看）/ 商品视图（按商品看）。
  - 知识类型：商品知识（智能体自动学习=不可信）；全店知识（手动补充=可信）；聊天知识（金牌客服的采纳话术=可信、聊天记录=不可信）。
  - 知识标签：可新增/删除/分类管理；内置标签不可修改删除。
- 表格知识：补充商品固定属性、参数、尺寸、材质、特色功能的复杂查找；商品检索用；商品推荐可在自定义Agent中用 `@+表格`。
- 国补知识（仅淘宝天猫）：系统自动获取/人工维护（参与商品、省份、活动时间、国补类型）；买家问国补时召回。可在全店知识配置各省补贴链接（需按商品链接实时更新）。使用前提：下载安装客户端并托管客服账号。
- 技能：工具集、定制报价产品计算等（如尺码表、报价计算器，均有单独教程）。

### 策略

- 自定义Agent：按合同套餐开放；用于接待流程/商品推荐/讨价还价，售后安抚等流程；使用见手册配套指引。
  - **成本敏感**：话术生成/催单若调用自定义Agent=1.5积分、未调用=1（按店铺×天，当天命中一次即全天 1.5）→ 拆分与归位方法见同目录 `积分成本优化-自定义Agent拆分.md`。
- 自定义风格：给智能体设定人设与话术规则；可做发送字数限制（如每段≤50字、超了分段）、语气词/禁止词、区分售前售后组话术类型。
  - 是**唯一“对所有回复生效且不按自定义Agent计费”**的位置：角色/称呼/详细设定/示例话术（≤100/100/500/300 字），需绑定客服或分组；适合放“不得猜型号、不重复追问、不承诺、不引导外平台”这类通用约束。

### 上下文工具

- 记忆（按套餐）：智能体参考有效期内买家对话记录；可设有效期。记忆标签：永久记忆 / 临时记忆（买家付款 xx 天后，付款前产生的记忆失效）。一个店铺只能绑定一个分组。可与自定义Agent联动（例：记住买家车型，下次不反问）。
- 场景库：把咨询场景/回复场景单拎出来，配合触发器使用；配置的场景会同步到话术拦截。

### 兜底策略

- 触发器（特殊情况转人工）：可多配但**不要重叠**；指定商品组需提前在商品分组配置，指定客服组需提前在分组管理配置。
  - 规则优先级：数字越大优先级越高，最高 100；触发频次限制：每分钟可被触发的次数，超限不再触发或走低优先级。
  - 状态条件：当前订单状态 / 咨询商品（可指定商品或商品组）/ 当前接待客服。
  - 触发条件：智能体未回复 / 客服手动转交 / 买家发图片、视频、平台卡片 / 客服撤回智能体回复 / 买家进线首句。
  - 执行动作：发送话术 / 转人工 / 将买家转交给指定客服（转交前后可各发话术；淘宝内置生效）。
- 话术拦截：
  - 重复内容不发送：限定轮次（买家单次提问+客服单次回复=1轮）内相似话术只生成不发送。
  - 咨询场景 vs 回复场景：咨询场景=识别买家意图后拦截不发；回复场景=识别回复有误后拦截不发（如买家要开票时仅生成不发送）。可与触发器搭配：场景关闭（未拦截）时可“照常发送+转人工”，或“不发送+转交给谁”；场景打开（拦截）时可触发“智能体未自动回复”触发器或该场景专用触发器。
  - 敏感词（违禁词）：触发优先级 白名单词 > 替换词 > 敏感词；只对**智能体自动发出**的词生效，不含人工点击采纳发出的。配置顺序：先补违禁词 → 再白名单 → 替换词；建议分平台配置；区分人工拦截/智能体拦截。设置：单词语回车；多词用【，】分隔后回车。
- 兜底话术：策略可设场景（售前/售中/售后）、每天生效时间；触发条件可设“xx 秒未回复就发”；支持随机回复、循环回复（每 20 秒一条）、每个买家每日上限。

### 协助接待设置

- 会话周期：买家最后一句话后 XX 分钟无会话视为结束，再次进线重新发欢迎语（按首次接待）。
- 焦点订单：以最近一笔交易订单为当前咨询订单（多订单时未交易完成订单优先），或以当前咨询商品所在订单为准；买家咨询前 XX 天无交易成功订单视为售前咨询。
- 焦点商品变更设置：客服手动发商品后，焦点商品同步变更。
- 售前售后订单状态：与全店知识的订单状态设置**互通**，改一处所有知识卡的订单范围跟着变。
- 手动转交前置话术【内置淘宝不生效】：客服手动转交前发送的话术，可配合触发器“客服手动转交”规则。
- 买家称呼：欢迎语和兜底话术里的买家称呼变量。

### AI协作

- 亮灯读秒【内置淘宝不生效；新版千牛有转人工提示】。
- 防止抢话：人工优先（当前接待窗口智能体不介入，其他窗口照常回复）/ 智能体优先。
- 自动发送场景：默认生成不发送（人工侧边栏采纳）/ 可信发送（只有可信知识自动发）/ 全自动；可针对不同客服单独配置。
- 回复标识：在调优工坊/接待页面区分智能体回复与人工回复。

## 3. 诊断优化

- 调优工坊：看客服与买家聊天记录；字段=买家ID（须用侧边栏显示的买家ID）、接待客服、咨询商品（焦点商品）、相关知识（生成引用的知识来源 + 焦点商品全部知识卡）。用途：话术生成错误时顺着“相关知识”找来源并纠错。
- 调优方法（查询筛选项、生成分析、未发送原因全清单与排查顺序）见同目录 `调优工坊调优指南.md`。
- 知识审核：关闭=智能体可直接学习金牌客服聊天记录；开启=需人工定期审核。
- 智能工单、跟单鱼池：手册只列名称（未展开）。
