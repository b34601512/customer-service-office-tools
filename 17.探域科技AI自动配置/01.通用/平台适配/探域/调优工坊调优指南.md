# 调优工坊调优指南（2026 实操沉淀）

来源：手册引用的两份飞书文档——《调优工坊的使用方式》（2026-07-02）与《调优工坊话术不发送原因解析》（2026-09-10），2026-09-28 全文采集（183 行/约 2700 字 + 34 行/约 820 字，快照自检通过）。
只记平台操作与排查方法，不含公司话术、店铺/账号信息。菜单与字段以当前后台为准。

## 1. 怎么查

- 查询筛选项：店铺名、买家ID、商品ID、客服昵称、订单状态、话术类型、发送状态、标记状态、处理状态、来自哪个自定义Agent、是否撤回、未自动发送的原因、买家提问、智能体生成话术内容。
- 左键点击记录弹出详情；点击某条话术进入“话术生成分析”。

## 2. 话术生成分析看什么

- 买家侧：买家ID、话术类型、买家的话术、买家咨询的商品、话题分析（买家问题含义）、买家情绪、买家下单状态。
- 生成侧：生成结果（回复话术）、执行结果（是否发送）、未自动发送原因、相关知识（引用的知识点）。

## 3. 常用处置

| 情况 | 处置 |
| --- | --- |
| 引用知识点有误 | 找到生成来源 → 点进知识点可编辑（SKU 规格品名不可改）；被引用卡没问题时，查其他相关知识卡；右侧可看全部相关卡并编辑 |
| 知识点引用错误（如绑了不该绑的商品） | 编辑知识卡，把该商品剔除 |
| 话术未生成 | 回知识库 → 新建知识 → 用 QA 模式补“问题+答案” |
| 改完想验证 | 用「场景回放」直接验证，不用等现场观察 |

## 4. 未自动发送原因清单（按出现频率和你该先看什么）

### 4.1 接待归属类（工坊里最常见的“买家非当前客服接待”）

- **买家非当前客服接待**（主要看这个）：A 客服把买家转给 B 后，A 侧智能体生成的话术不会以 A 名义发出；若 B 未托管，工坊会显示该原因，平台端口才能看到转出记录。
- **买家已转交**：触发器转交时，转出/转入两个账号都要托管智能体客户端，否则话术不发送。
- **买家处于人工接待状态**：触发器执行过【转人工】后，智能体不自动发送，直到人工回复或人工切换当前买家才解除。
- **买家要求转人工**：买家的相关话题触发转人工（知识库写了【转人工】/自定义Agent写了该场景/语义识别到要转人工）。

### 4.2 风控话术拦截类

生成的话术命中风控就不发送，常见触发点：

1. 话术不是直接来源于知识库/自定义Agent，或不能从其推导；
2. 链接不是来源于知识库；
3. 知识库书写要求执行转人工；
4. 承诺性风险话术：答应补发/补偿/备注、“肯定允许”、加急/立马/优先发货等（智能体说备注但实际没备注，风险很高）；
5. 话术与当前语义不符；
6. 智能体回复里说“联系人工客服”（名字叫【风控】）；
7. 智能体自己生成的话术有问题，自己触发风控（如知识库说有刀架、人工却回复没有，冲突）；
8. 设置了“可信发送”时，回复没有引用知识（无引用就风控）。

处置：先核对“咨询是否有对应知识支撑”；没有 → 补知识库或补自定义Agent查表。

### 4.3 发送策略类

- 店铺未开启自动回复（服务端后台设置）。
- 店铺/商品分组/客服分组/客服账号在自动发送里没选“全自动发送/可信知识发送”。
- 某个商品分组选了“仅生成不发送”，其他分组或店铺选的是全自动/可信发送（分组级优先）。
- 客户侧选择了仅生成不发送。
- 买家未开启自动接待（客户端/平台店铺侧把自动接待按钮关了）。
- 回复来自非可信知识（自动发送=可信知识发送时，商品知识、聊天记录这类非可信知识只会生成不发送）。

### 4.4 会话/触发条件类

- 买家有新咨询（正在生成时买家又发了新消息）。
- 上下文存在相似话术（配了“重复内容不发送=1 次”，第二次相似话术不发送）。
- 人工客服已回复（当前接待客服已回复；平台/第三方机器人代替人工回复的、非智能体回复的都算人工已回复）。
- 人机协同（人工优先）：买家处于当前打开的接待窗口，智能体不自动回复；客服停在该买家窗口但没发话术也算人工在接待。
- 话术未生成：知识库没有可生成的知识（生成结果是“未找到相关资料”）→ 重点补知识库。
- 话术拦截类：违禁词拦截、自定义禁用自动发送场景、买家负面情绪、退货退款流程、咨询优惠相关、与上下文相同媒体信息（图片/链接/视频已发过）、咨询意图拦截、回复意图拦截。

### 4.5 淘宝内嵌专用（平台限制，智能体后台改不了）

辅助接待已停止（只能手动点恢复）：转交后客服未开/当前客服未开启；回复内容含人工介入提示；人工已回复为避免抢答；**手动转交后 3 小时内该买家的任何智能体话术都不能自动发送（含兜底）**；买家发送视频消息；售后问题。
其它：重复发送过多（重复 3 次）；会话过长（超 30 分钟）；客户点了转人工按钮；转人工成功后 30 分钟内拦截；买家对智能体消息点踩后 30 分钟内拦截；买家存在负向意图。

## 5. 排查顺序（给弱 AI）

```text
读“未自动发送原因” → 分类：归属问题 / 风控 / 发送策略 / 会话条件 / 淘宝内嵌限制
→ 归属与策略类：核对托管状态、自动发送配置、分组设置，不先改知识
→ 风控类：顺着“相关知识”找引用来源，改知识库/自定义Agent；改完用「场景回放」验证
→ 知识未生成：补 QA 知识，不编造答案
→ 全部动作仍按通用流程：before/after、备份、回读、状态说明
```
