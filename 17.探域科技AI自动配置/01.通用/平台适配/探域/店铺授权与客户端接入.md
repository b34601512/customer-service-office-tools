# 店铺授权与客户端接入（引用教程沉淀）

来源：手册引用的《对外：淘宝应用接入教程（千牛店铺主账号）》《抖店接入授权教程》《【探域智能体】京东自营接入SOP流程（对外）》《关于拼多多接入店铺学习商品》《客户端初始使用指南》，2026-09-28 全文采集（四件套+快照自检通过）。
只记平台接入步骤，不含任何店铺/账号信息。图例步骤在原文截图里，本文件只保留文字流程；执行以当前平台页面为准。

## 1. 客户端初始使用

1. 下载智能体客户端（不一定非得某一版本；示例为 2.9.1），地址形如 `https://cdn.tanyuai.com/client/version/app/<build>/tanyu_agents_setup_<版本>.exe`。
2. 登录：用智能体后台-个人中心创建的子账号登录（微信扫码或账号登录）。
3. 先在智能体里安装商家平台（必须用新版本，不能用旧的）。
4. 启动平台并登录 → 点“托管”→ 出现右侧侧边栏即托管成功。
5. 左侧=聚合接待列表（各平台买家消息，可点击跳转到对应接待页）；右侧=智能体话术生成界面。
6. 排查问题需要提供**买家ID + 店铺名**（买家ID在侧边栏）。
7. 生成的话术可直接改、可点发送；有问题可标记，管理人员在后台调优工坊溯源并调整知识库。
8. 催单按钮：智能体自动生成催单话术。
9. 关闭后该买家停止使用智能体接待；也可以清除智能体对该买家聊天记录的记忆。
10. 智能工单在“客服代表”里处理；可给客户加标签（用于营销消息过滤）。

## 2. 淘宝（千牛店铺主账号）

三步：① 获取官方应用授权 → ② 进入应用做店铺授权 → ③ 进入千牛开启智能体接待。

1. 订阅应用：淘宝服务市场订阅【探域智能体】→ 立即购买 → 付款后点“去授权”做服务授权。
2. 店铺授权：应用里点“立即授权”→ 确定授权后跳转 → 登录探域账号（已有账号选账号登录；没有则点“扫码开户”联系工作人员）→ **核对“正在将 [您的淘宝店铺名] 绑定至 [您的探域集团名]”** → 显示“绑定成功”。
3. 千牛开启接待：打开千牛点【探域智能体】入口（不再点“启动客户端”）；首次进入需主账号/管理员用【探域千牛助手】应用操作（可多店铺一键操作）。
   - 开启路径：【客服】→【接待设置】→【选择机器人】“探域智能体”→【辅助接待】“设置”。
   - 全自动接待：人工介入前/夜间无人时智能体接待，可按需设置分流。
   - 辅助接待：人工接待时智能体同时辅助；把需要辅助的人工账号加到【探域智能体】页签下。
4. FAQ：面板有显示但没有焦点商品、也发不出去消息 → 主账号操作：【店铺】→【子账号管理】→【选择应用】“探域智能体”→应用授权。

## 3. 抖店（需主账号操作）

1. 概览：抖店服务市场购买【探域智能体】→ 立即使用 → 跳转绑定集团 → 开启客服机器人。需物流/售后工单/跟单时，额外增购【路人打单】。
2. 购买与绑定：选套餐时长支付 → 立即使用 → 复制链接（或直接跳转）→ 页面确认绑定 → 回抖店应用界面点“我已绑定一键刷新”→ 进店发一句咨询完成启用。
3. 应用权限：飞鸽客服系统 → 客服管理 → 应用管理 → 智能客服 → 启动（关闭会导致机器人无法接待）。菜单栏会出现“探域智能客服机器人”。
4. 话术范围与接待时段：探域智能体后台 → 平台应用设置；未设置策略则默认开启前置接待和无人值守。
   - 没有“平台应用设置”选项 → 主账号给对应角色开通页面权限。
   - 想直接人工接待（保留侧边栏辅助）：设置接待时间，类型选“不接待”。
   - 前置接待=需要机器人先接待。
5. 授权成功标志：调优工坊有聊天数据；服务助手（纯机器人）的对话分析只在飞鸽工作台「探域智能体」应用查看（转人工后后台能看到完整对话记录）。
6. FAQ 要点：国补店铺不支持第三方智能客服（只能买应用做授权）；全自动阶段的机器人回复不计入三分钟回复率；抖音迁移后原客户端功能（含转交）不受影响。

## 4. 京东自营（不买服务市场，直接在探域服务后台授权）

### 前置要求（缺一不可）

1. 用**供应商子账号**在京麦后台授权（不支持供应商主账号）；子账号名只能是纯英文或数字，**不能含 `_ - & "` 等符号**（地址解析会截取失败；若已有带符号账号、京东不支持改名，只能申请新账号绑产品线）。
2. 子账号须有供应商后台 + 京麦后台权限（双重身份）。
3. 子账号已绑定目标自营店铺。
4. 子账号已绑定对应产品线。
5. 先判明是哪种接入情况（见下）。

### 接入前检查

- 供应商后台（`https://shop.jd.com/jdm/seller/account/manage`）→【配置】→【基础信息】→【子账号管理】→【修改产品线】。
- 京麦 → 店铺/账号管理：确认子账号已绑定目标店铺。
- 权限管理：确认双重身份；商品基础信息权限必选（建议勾所有商品相关权限）。
- 产品线绑定：没绑对应产品线就取不到该类目商品数据。

### 三种情况

| 情况 | 说明 | 操作 |
| --- | --- | --- |
| 1 单个子账号覆盖全部产品线 | 1 店铺/1 供应商/1 子账号绑定全部产品线（或 2 店铺共用 1 个子账号） | 按下面步骤走一遍 |
| 2 同供应商多子账号分工 | 每子账号只看部分产品线，合起来才是全部 | 按情况 1 的步骤，用不同子账号**重复操作多遍** |
| 3 多供应商子账号分工 | 店铺绑了多个供应商，各自负责部分产品线 | 同上，按各供应商子账号重复操作多遍 |

### 授权步骤（情况 1）

1. 登录探域后台 →【探域服务后台】→【添加店铺】。
2. 点【立即购买】跳到京麦服务市场 → **用正确的供应商子账号登录京麦** → 购买“探域客服助手”。
3. 购买成功后回【探域服务后台】-【添加店铺】点【去授权】。
4. 输入**供应商简码（供应商ID）** → 账号信息校验 → 确认绑定。
5. 核对页面显示的账号是否为购买应用的子账号；不对就换正确子账号登录后重走 4-5。
6. 最后确认授权页面的商品权限；成功提示“授权成功”。
7. 多个产品线/多个供应商：重复上述步骤。

### 常见问题

- 无法同步商品的 5 个原因：未用供应商子账号（用了主账号，需主账号退款后重做）、子账号未绑店铺、未绑产品线、商品权限未开通、未配置供应商简码。
- 价格显示：京东接口返回的是 SPU 价格（多规格时取 SKU 最低价），与实际 SKU 价格不一致属正常展示逻辑。
- 在售状态：不要用 SPU 的在售/下架状态对比 SKU 的（列表还没展示 SKU 状态）。
- 授权账号弄错：退款，用正确子账号重新购买并授权。
- 同步商品缺失（如 10 个只同步 7 个）：先查授权账号是否正确，具体分析。
- 名词：【店铺模式】=京东 POP（非自营）；【供应商模式】=自营；自营店铺没有店铺模式。

## 5. 拼多多

1. 开户：智能体和客服机器人两个产品均无需购买应用授权；联系销售把【店铺名称、店铺ID】上报，由销售手动开户。
2. 商品更新：新增/变更商品时，保证有客户端在线，按商家后台操作**手动同步**。
   - 同步时确保对应店铺客服已托管（在线越多同步越快）。
   - 在线客服必须有“商品列表-商品详情”的查看权限，否则同步异常（典型表现：缺失商品图片）。
   - 权限添加由管理员角色或主账号操作：管理员改角色权限（选有商品管理权限的角色）；主账号改具体权限（选【查看商品权限】）。
   - 注意误区：接待页能看到商品、后台能看到商品列表，**不等于**有商品详情权限。
3. 售前/售后订单识别不及时：买家咨询过程中下单可能订单状态更新延迟，可按官方步骤在拼多多商家后台配置（配置后系统能及时获取最新订单数据）。
