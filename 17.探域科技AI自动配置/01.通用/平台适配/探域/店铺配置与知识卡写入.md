## 1. 风控词（敏感词，话术拦截）

- UI：话术拦截 → 敏感词（`?key=sensitive`）。
- 读：`POST /api/shop-config/agent/config/get`，body `{metaIds:['agent.prohibited.words', …]}`（**不带 orgId**，平台 UI 同款）。
- 写：`POST /api/shop-config/agent/config/save`。
- 字段：`data['agent.prohibited.words'].item[0]`：
  - `client` / `clientWhitelist` / `clientReplacementWord` —— **人工 + 智能体**都拦（现状 33 词）；
  - `server` / `serverWhitelist` / `serverReplacementWord` —— **只拦智能体发送**（给 AI 加约束走这里，人工不受影响）。
- 规矩：改前整份 before 快照 → 小步写入 → 回读逐词比对 → 保留回滚件（当前值==已写值才允许 rollback）。
- 词表口径：**宁少勿滥**。准入 = 问题答复命中 ≥1、合格答复命中 0、全库卡命中 0；会拦正常话术的词一律不加（误拦=客户收不到回复，比答错更糟）。
- 未知项：敏感词页提示「更新后需要重新托管客户端」——生效链路未实测，若出现「该拦没拦」先怀疑它。

## 2. 回复约束（自定义风格）

- UI：策略 → 自定义风格（可按客服/分组绑定）。
- 读：`GET /api/shop-config/customer-style/list` → `data.customerStyleDetailList[]`，字段 `styleName / role / salutation / setting / example / toServices[]`。
- 写：`POST /api/shop-config/customer-style/save`。
- 限制：**setting ≤ 500 字、example ≤ 300 字**（写前算字数）；绑定（`toServices`）与 role/salutation 不要动。
- 用法（2026-10-03 实证）：给 AI 加「禁止承诺 / 医疗约束 / 操作安全 / 隐私」四类约束 → 追加进 setting + 补 example；回读逐字比对、绑定数不变。

## 3. 知识卡（卡库）

- 全量读：`POST /api/kbe/v1/knowledge-card/page`，body `{pageNo:1, pageSize:10000}`（**pageSize 上限 10000**，20000 会被限）；返回 `data.total` + `data.results[]`。
- 建卡：`01.通用/工具/探域建卡.cjs`（**默认 dry-run**，出现 `--dry-run` 即只读；真实写入要显式加参数）。建后**列表回读有索引延迟**（即时读可能 0 命中）→ 用全量接口回读 `total` 是否恰 +1。
- 批量改：`01.通用/工具/探域知识卡任务执行器.cjs`：
  - 正文改动走 `after`（逐段/逐行替换，写前 before 快照、写后回读逐字比对）；
  - 业务字段走 `businessPatch`（`ifOpen / includeCondition(SPU/店铺) / orderStatus / ifBelievable / timeliness` 等）；
  - 流程：`check`（返回 ready）→ `apply`（返回 **verified**）；每张卡留 before/after/payload 三件套。
  - 副作用（可忽略，非范围变化）：保存后 `content[].index` 变序号、段 id 重生成、`excludeCondition` 由 null 变 `[]`。
- 检索冲突/批量替换（2026-10-03 实证，84 张）：先全库拉下来按关键词聚类**冲突写法变体** → 只替换含冲突句的整句/整行（保留列表前缀）→ 逐张 diff → 全库终检（其余卡零正文变化、业务字段零变化）。
- 红线：不删卡（除已批）；不改业务字段（除已批）；拿不准的不改，列回执问。

## 4. 通用踩坑（今天都踩过）

| 坑 | 现象 | 做法 |
|---|---|---|
| 列表缓存 | 写入后列表 1~2 分钟才更新（review/新建卡） | 写后**等 ~60s** 再回读；或全量接口比对 `total` |
| `--since` 格式 | 只写到分（`20:30`）→ `paginateV2` 返回 `http=200 code=0` | 时间**必须带秒**（`20:30:00`） |
| 画像并发 | 两进程同 profile → playwright `exitCode=21` | 任务窗在跑时**不抢画像**；写入/扫描串行 |
| 失败重试 | —— | 一律**不自动重试**；先定位（`失败台账.md`），人工判断后补跑 |
