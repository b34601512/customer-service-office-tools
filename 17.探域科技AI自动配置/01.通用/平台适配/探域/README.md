# 探域平台适配

这里记录“探域后台怎么操作”，不记录“某家公司应该配置什么业务内容”。

## 已沉淀文件

- `探域平台API无头执行手册.md`：接口/无头执行的通用方法与安全流程。
- `探域2026新后台操作地图.md`：2026 新页面后台的菜单路径与功能地图（集团与店铺、Agent Builder、知识中心、兜底策略、协助接待、AI协作、诊断优化、数据罗盘口径）。
- `知识库书写格式.md`：全店知识书写格式（场景式/QA/三段式/图片视频/分段/表格/@tool{calculate}/【转人工】）。

## 允许沉淀

- 页面与接口入口
- 列表、详情、保存、发布、模拟测试的调用方式
- 字段含义、分页、回读、并发冲突处理
- 无头浏览器/API的执行方法
- 平台特有的异常和验证经验

## 禁止沉淀

- 公司名称、真实店铺ID、商品ID、知识卡ID
- 公司话术、活动政策、型号结论
- 本机固定用户名、浏览器画像路径、备份盘符
- 历史授权、Cookie、Token、登录凭据

## 弱AI最短流程

1. 从本次业务专用区取得公司、店铺和授权范围。
2. 只读验证当前登录账号和目标店铺。
3. 完整读取目标对象并保存快照。
4. 按通用方法生成计划，不把旧脚本直接重跑。
5. 写入前再次读取；发现变化则停止该项。
6. 只修改批准字段，保存后完整回读。
7. 记录“草稿 / 已保存 / 已核验 / 已模拟”真实状态。

接口和字段以当前后台实际响应为准；历史实测只能作为定位线索。
映射手册与 API 手册冲突时，以当前后台实际页面/响应为准，并把实测写回本目录。
