# 自定义Agent编写要点

来源：手册引用的《自定义 Agent 使用指引》（2026-05-19）与《自定义Agent示例》（2026-06-29），2026-09-28 全文采集（四件套+快照自检通过）。
只记编写方法；示例里的行业话术不搬进通用区，落地时按本公司业务事实重写。

## 1. 启用方式

1. 后台配置 → 创建自定义 agent → 完成基础设置。
2. 编辑“触发场景描述”，撰写提示词（见下）。
3. 客户端选择对应版本（可只给单个客服账号设置新版本，其他账号继续用稳定版）。
4. 触发情况可在调优工坊查看。

## 2. 触发场景

系统按“触发场景描述”决定用哪个自定义智能体还是默认智能体接待；调整描述即可调整触发范围。写法要点：用买家会遇到的情形描述（如“买家咨询是否包安装时”“买家提供身高体重时”“买家确认要购买的度数时”），必要时列多条。

## 3. 提示词规范

### 3.1 用词指代

| 含义 | 建议用词 |
| --- | --- |
| 智能体 | 你（当买家……时，你应该……） |
| 买家 | 买家 / 客户 / 消费者 / 顾客 |
| 订单阶段 | 订单状态、下单状态、购买情况（售前/售后、付款前后、发货前后） |
| 历史 | 对话记录、聊天记录、服务记录 |
| 客服 | 客服 |

### 3.2 参考结构

```text
一、核心目标
[明确最主要任务]
二、关键行为与流程
第一步：……
第二步：……
第三步：……
三、限制
禁止行为：[如不提供非官方承诺、不涉及敏感话题、涉及退款/补差价等金钱的要求转人工]
必须遵守：[如按知识库回复、不能编造]
```

- **语气风格必须写**，否则可能导致回复内容过长；无特殊要求就用平台给的通用示例。
- 提示词尽量简洁；接待流程用步骤写；不要在里面写计算逻辑（计算类用报价计算器/`@tool{calculate}` 等工具）。

## 4. 示例要点（保留方法，不抄话术）

| 场景 | 可复用的方法 |
| --- | --- |
| 安装咨询（家电家居） | 按商品详情的不同关键词分支回复（免安装/包安装/无提及），提示词里写清判断条件与对应口径 |
| 尺码推荐（服饰） | 先收集身高体重；卡码时按版型推荐（紧身版型大一码、宽松版型小一码；内搭小一码、外套大一码）；结合体型突出穿着效果 |
| 配镜流程（眼镜） | 分步推进 + 每步强制确认：先获取年龄/度数 → 按规则推荐度数 → 处理“有近视”做度数换算、度数超范围推荐平光防蓝光 → 追问镜框颜色并锁定 → 引导拍下对应套餐；客户犹豫/问别的时先简短回答再立即追加强制确认 |
| 批发定制 | 按步骤收集数量、型号、联系方式，先给批量方案引导凑单，再留资跟进 |
| 讨价还价 | 先共情再强调价值，多次议价时用新客券/满减/搭配引导，不用否定词 |
| 家具定制留资 | 按用途→尺寸→预算风格→推荐方案顺序收集，每步完成再进下一步，最后引导留资/咨询设计师 |

示例原文（含完整提示词）见手册引用的《自定义 Agent 使用指引》《自定义Agent示例》两份文档；本文件只保留可复用的结构和方法。
