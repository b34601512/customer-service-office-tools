# 通用能力区

这里存放所有公司都能复用的方法、流程、模板和平台操作能力。

## AI执行原则

1. 先读本区方法，再进入具体公司的业务专用区。
2. 不从某家公司复制政策、型号、店铺ID、账号、路径或历史结论到通用区。
3. 所有脚本优先参数化：公司、店铺、对象ID、输入正文、备份目录由本次任务提供。
4. 弱AI不会判断时，先按模板完成只读采集、生成计划和风险检查，不直接写后台。
5. 写入统一遵循：读取现状 → 生成before/after计划 → 写前再读 → 保存 → 回读核验 → 记录结果。
6. 平台接口属于平台适配经验，不等于任何公司的业务政策。

## 建议结构

- `方法论/`：主管经验、判断规则、沟通和验收流程。
- `平台适配/`：探域等后台的接口、字段和执行方法。
- `工具/`：参数化、可跨公司复用的脚本。
- `模板/`：公司接入、任务计划、拍板、验收、恢复模板。

业务事实只放在 `../02.业务专用/`。
