# 公司接入与拍板记录模板

复制到当前公司的私有工作目录后填写。此文件保持空白模板，不存真实账号、订单或政策。

## 接入（没有资料填“待确认”，不要猜）

- 公司：
- 主管确认的平台/店铺及后台ID：
- 后台入口和当前账号核对结果（不记密码/token）：
- 本次目标：
- 允许动作：只读 / 问答原位修改 / 另行明确授权动作：
- 不允许动作与不可逆确认要求：
- 本机项目/原始资料/独立画像/私有备份位置：
- 可用工具与缺失能力：
- 当前资料版本与来源：
- 本次实时快照位置、采集时间、唯一卡数、完整性依据：

## 单问题记录（每个问题独立复制此结构）

- 题目：
- 意图与背景：
- 冲突证据A（原卡ID/原文/范围/来源）：
- 冲突证据B：
- 需要主管决定的唯一问题：
- 主管原话与时间：
- 已确认的准确规则、适用平台/店铺/型号/日期：
- 未被本次确认的内容：
- before/after计划与备份位置：
- 执行日志及原卡/新卡ID：
- 状态：待证据 / 待确认 / 已确认待执行 / 已保存待核验 / 已核验 / 暂缓
- 恢复方式及限制：
- 下一步：

验收：

- [ ] 有依据且授权范围清楚
- [ ] 相关入口全文读完，确定修改范围
- [ ] 保存前完整备份及并发比较
- [ ] 正文与全部业务条件回读一致
- [ ] 图片线上内容/哈希（如涉及）
- [ ] 学习/模拟结果记录，未做项明示
- [ ] 主管收到实际完成状态，清单已更新

## 交接给主管的最短格式

“已写入后台N条，回读一致；尚未模拟真实买家回复。下一项请确认：……。”

如只是草稿：“N条改稿已整理在本地，尚未写入后台，原因：……。”
