# 旧候选到通用入口映射

旧候选均含公司参数或私有输出，不再作为活动入口；原文件在 `D:\备份文件夹\17项目通用候选旧脚本-20260908`，以下映射用于复用其职责，不复制其数据。

| 旧候选职责 | 通用入口 |
|---|---|
| Agent/API/配置读取、接口探测 | `探域API只读调用模板.cjs`；接口清单由调用方传入 |
| Agent列表/详情/草稿回读 | `探域自定义AgentAPI模板.cjs` |
| JSON配置同文保存回读 | `探域配置同文回读模板.cjs` |
| 页面模拟发送与新增回复判定 | `探域无头模拟测试模板.cjs` |
| 有头GUI违规扫描与意图核对 | `执行方式审计模板.cjs` |
| Agent正文、草案、政策文字风险检查 | `文本规则审计模板.cjs` |
| 公司商品、政策、图片、聊天批次采集与报告 | 只复用上述读取/审计引擎；查询范围、规则和输出必须放在接入公司的私有配置中 |

## 迁移原则

- 通用入口只接收参数，不接收或保存真实公司凭据、店铺ID、商品/SKU、业务正文和快照。
- 旧候选只用于追溯历史实现；新公司不得直接运行旧候选。
- 发现接口或业务字段不确定时先只读采集，再由主管确认，不用兼容分支掩盖未知字段。
