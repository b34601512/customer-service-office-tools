# 18.win10-copy-file-address · 项目索引

> 总规矩：根 `../AGENTS.md`。最后整理：2026-10-09。

- **干嘛的**：Windows 10 单文件小工具（bat 内嵌 PowerShell），给右键菜单加「**复制文件地址**」（用系统 `copyaspath` 处理，不拿文件名拼 shell 命令）。
- **入口**：双击 `Win10_CopyPath_TUI.bat` → 菜单 `Menu / Install / Uninstall / Status`。
- **红线**：只改**自己的 HKCU 唯一注册表键**；不下载、不提权、不改执行策略、不联网；不要为了"顺手"扩大改动范围。
