## 八个分类

| 分类 | 管什么 | 典型例子 |
|---|---|---|
| 配件与结构缺陷 | 配件、结构件本身有毛病或设计不合理（含冷凝水、漏气、易断、易丢） | 吸氧管/鼻氧管里出水珠、湿化瓶漏气或刻度不清、过滤棉看不见换不了、遥控器接收口朝上、水箱崩开、显示屏开胶、雾化螺帽易丢 |
| 机器性能故障 | 机器本体该有的性能不达标或异常 | 氧浓度达不到、气量不足、噪音/震动大、开机异味、报警太晚或误报、定时不准、开关机抖动 |
| 操作易用性 | 用户（多为老人）用不起来、容易误操作 | 开关在底部要弯腰、加减键合用一个、息屏＋长按才关机、显示屏朝上看不见、防呆不足误当加水口、省电模式被当成坏机 |
| 安全与合规 | 涉及人身安全、法规或标识 | 出氧口非金属可烧毁、外壳不阻燃、无「严禁明火」警示、低氧报警超 15 秒、过滤器三无标签、氧气袋无警示 |
| 说明书与文案 | 纸质/电子说明书写错、写没用的话、用词误导，以及播报语音文案 | 「终身维修」措辞、1L~9L 对应 30%~96% 写法、「进气盖」用词、开机播报「殡葬」误听 |
| 包装与运输 | 出厂包装、运输造成的破损或防护不足 | 泡沫太薄脚轮摔坏、屏幕被湿化瓶压碎/刮花、配件无密封包装、说明书褶皱 |
| 来料与供应链 | 供应商切换、来料检验缺失导致批次性问题 | 电源线插不进（只验样品）、供应商直接切换未并行、降本降在顶配版 |
| 售后与成本 | 售后处置、维修可维护性、退换货成本 | 客户想自己换分子筛省运费、因质量问题申请退货退款 |

## 判定顺序（一条记录命中多条时按这个优先级）

1. 涉及安全/法规/标识 → **安全与合规**
2. 属于配件或结构 → **配件与结构缺陷**
3. 属于机器性能 → **机器性能故障**
4. 属于用不起来/易误操作 → **操作易用性**
5. 属于说明书/文案/语音 → **说明书与文案**
6. 属于运输损坏或包装 → **包装与运输**
7. 属于来料/供应商/批次 → **来料与供应链**
8. 属于售后处置或成本 → **售后与成本**
