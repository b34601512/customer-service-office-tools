## 三、使用约定（README）
- 先读对应文件夹里的 `*经验.md`；有配套脚本**优先直接跑，不要重写**。
- 脚本依赖借用现有项目：`$env:NODE_PATH = "D:\桌面\木婉清\12.店铺指标数据自动更新\node_modules"`。
- 所有脚本**默认只读**：不写在线文档、不保存/打印 Cookie/token；密码只从环境变量或本机文件读入，示例一律 `<密码>` 占位。
- 新增经验：新建以经验命名的文件夹 → 放 `<经验名>.md` → 需要脚本放 `<经验名>.cjs`（注明"配套脚本：同目录"）→ 更新 README 目录表。
