## 使用约定

- 先读对应文件夹里的 `*经验.md`，里面有完整步骤、实测结论和常见坑。
- 有配套脚本时优先直接运行，不要重写。脚本依赖借用已有项目即可：

```powershell
$env:NODE_PATH = "D:\桌面\木婉清\12.店铺指标数据自动更新\node_modules"
node "<脚本路径>" --help
```

- 所有脚本默认只读：不写入在线文档，不保存、不打印 Cookie/token，真实登录态只留在本机浏览器画像。
- 密码类经验统一约定：密码只从环境变量或本机文件读入，示例一律用 `<密码>` 占位，不入库、不进聊天记录。

## 新增经验

1. 新建文件夹，文件夹名就是经验名；
2. 放入 `<经验名>.md`（关键代码可以直接内嵌在 Markdown 里）；
3. 如需可复用脚本，放入 `<经验名>.cjs`，并在 Markdown 开头注明“配套脚本：同目录 …”；
4. 更新本 README 的目录表。
