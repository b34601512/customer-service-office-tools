# GEO 实操方法与实测发现（可分享复用版）

> 适用：想让 AI 搜索 / AI 问答在回答里提到你产品的人；也适用于替人做这件事的 AI。
> 用法：一 → 六 顺一遍，每节末尾有「做完的标志」，对上了再往下走。
> 全篇不举具体品牌例子，示例统一用虚构品类；方法可套到任何 To C / To B 产品上。

---

## 一、GEO 是什么（以及不是什么）

一句话：**SEO 争的是排名位置，GEO 争的是「答案里有没有你、引的是谁」。**

用户不再只点蓝链，他直接问一句「有什么好用的 X」，AI 给一段答案并且列几个来源。
你要争取的是：**答案正文里提到你，来源列表里有你。**

三个可观察的结果，后面所有判断都落在这三个上：

| 看什么 | 怎么读 |
|---|---|
| 出现次数 | 同一个问题问 N 次，答案里提到你几次 |
| 被引域名 | 来源卡里都有谁，你占几个 |
| 引用位置 | 你在第几条来源、在答案正文的哪一段 |

**它不是**：多发软文、多买外链、把关键词堆满页面。这三件事在 GEO 里既不计分也测不出来。

**做完的标志**：你能用一句话说出「现在 AI 提到我的时候，说的是什么、引的是谁」。

## 二、先测再改：跑一次基线

不知道 AI 现在怎么说你，改什么都叫猜。

### 2.1 题库怎么出（10 题就够）

两类题，缺一不可：

- **通用题（6~7 题）**：用户真实会问的推荐 / 对比 / 怎么选。
  例：「有哪些好用的 X 工具」「A 和 B 怎么选」「做 X 用什么软件便宜点」
- **品牌题（3~4 题）**：「X 是什么」「X 好不好用」「X 和 Y 哪个好」

出题三条纪律：
1. **照用户口气写**，不要写关键词堆砌（"X 工具 推荐 好用"），AI 对整句提问才会给完整答案
2. **每题只问一件事**，一句话塞三个条件的题，答案没法比对
3. **同一套题长期固定**——改了题，历史数据就断了，等于重新开始

### 2.2 平台怎么选

三类各覆盖一到两个，不要只测一个（同一问题在不同平台能给出完全相反的结论）：

- 通用型助手（不带搜索也硬答）
- 带联网搜索的助手
- 各自生态里的助手（视频生态的、搜索生态的、办公生态的）

### 2.3 取数纪律（这一段决定数据能不能用）

- 每题**新开一个对话**，不在同一窗口连问（上下文会污染答案）
- 等答案**生成完**再截，别截一半
- 展开「来源 / 参考资料」，把**答案原文 + 来源卡**一起存
- 每条记录四样：日期时间、平台、题号、答案全文

存法建议：`日期/平台/Q编号.json`，原始文件不覆盖，只追加。以后所有结论都回原始文件核。

### 2.4 判据（不看感觉，只看数）

| 结论 | 判据 |
|---|---|
| 被提到 | 答案正文出现你的名字（含错认，要另标） |
| 被正面介绍 | 答案里的定义和你官方一句话定位**对得上** |
| 被引 | 来源卡里出现你的域名，记第几条 |
| 渠道偏好 | 统计来源卡的域名类型分布，不是看哪条印象深 |

模型输出有随机性：**一次只是快照，同题同法隔期复跑才有比较意义**（建议月度一次）。

**做完的标志**：一张基线表，任何人看了都能回答「我目前被提了几次、被谁引、答案说得对不对」。

## 三、看渠道：AI 爱引的是哪类内容

不用背别人的渠道清单，先测自己品类，再排优先级。但有几条跨品类都成立：

- **短视频平台的内容**：视频生态里的助手会大比例引用站内视频（口播讲产品的那种）
- **应用商店 / 下载站**：搜索型助手爱引；商店页文案写清楚，等于免费给 AI 一份简介
- **问答与长文**（知乎一类）：长文、对比、实测最容易被整段抄走
- **公众号 / 官方博客**：中文生态助手偏爱；自家号的文章也可能被引
- **竞品官网和帮助中心**：**这才是被引大户**——同行把「FAQ / 对比 / 选型指南」写在官网上，AI 直接引它
- **评测站 / 软件目录站**：少量但稳定，属于"存在的证明"

结论落到行动上只有一句：**不要每个渠道都去占，先做一处能被反复抽到的地方**（通常是官网的可抽取内容页 + 一个问答平台）。

**做完的标志**：一张「平台 → 爱引类型」的表，并写明「这个季度先做哪一处、为什么是它」。

## 四、写能被抽取的内容

### 4.1 结构（照这个写，不跑偏）

1. **标题就是问题**（用户怎么问就怎么写）
2. **第一段直接给答案**，别铺垫背景
3. **然后给依据**：数字、规则原文、实测步骤
4. **末尾 FAQ 3~5 条**，覆盖长尾问法

### 4.2 三类最容易被引的内容

| 类型 | 长什么样 | 为什么吃香 |
|---|---|---|
| 对比 / 选型 | 「A 和 B 差在哪，按团队规模怎么选」 | AI 的比较类回答要引用对比依据 |
| 规则 / 口径 | 「某平台的响应时长怎么算（官方定义 + 出处）」 | 有唯一正确答案，敢被抄 |
| 操作 / 步骤 | 「从零到能用的 5 步，每步截图」 | 步骤本身就是答案 |

### 4.3 一条铁律

**能被单独抄走的一段话，才叫可被抽取。**
如果你的答案必须连着上下文读才成立，AI 就没法引——它只会引"能独立站住"的段落。

反面清单：通篇形容词没有具体数字；标题党但正文答不上；把关键信息做成图片；只有"联系我们"没有"是什么"。

**做完的标志**：每篇文章你都能在 30 秒内指出「哪一段会被抄走」，指不出来就是还得改。

## 五、实体澄清：先让 AI 分清你是谁

这是最容易被跳过、也最容易白干的一步。尤其是英文品牌名或常见词命名的产品。

### 5.1 症状（有任一条就要修）

- 问「X 是什么」，AI 介绍的是别家的同名产品
- AI 给你安了一个不是你的官网
- 把你归类到完全不相干的品类（朗读软件、聊天插件……）

### 5.2 做法

1. **一句话定位定稿**（是什么 + 给谁用 + 解决什么），全站、商店页、公开资料统一用这一句
2. **官网有可抽取的身份页**：About / 产品说明 / FAQ，写清楚公司、产品、能力边界
3. **外部资料口径一致**：商店简介、问答平台介绍、目录站收录，都跟这一句对齐
4. **近名产品不用打**，把「你不是谁」写成 FAQ 即可（"和 X 的区别"这类问法反而是流量）

### 5.3 判据

品牌题的答案里，**定义句能不能和你的官方一句话对上**。对不上就是没澄清好，别急着做内容。

**做完的标志**：品牌题的 3 条答案，定义句都能对上官方口径，且不再出现别家同名产品。

## 六、地基三件（不花哨，但要齐）

| 项 | 做什么 | 怎么验 |
|---|---|---|
| 可抓取 | robots 不挡关键页；正文别只靠 JS 渲染；有可读的静态文本 | 关掉 JS 打开页面，正文还在吗 |
| 结构化数据 | JSON-LD：Organization / Product / FAQPage / BlogPosting | 每页跑一次官方 validator，报错归零 |
| 索引 | sitemap 提交（国内外搜索引擎都提）；关键页优先 | sitemap 里每条 URL 都能打开且返回 200 |

顺带两条容易漏：

- **新页面发布后主动提交**，别等爬虫自己发现
- **改版/改名时同步改 sitemap 与站外资料**，否则索引里留着旧标题

**做完的标志**：任意抽三个关键页，抓取正常、结构化数据校验通过、sitemap 有它。

## 七、实测观察（定性，不给具体数字）

下面几条是跨品类反复出现的，可以直接当假设用，但**上线前仍需自己测一遍**：

1. **"官网没被引"不等于"官网没流量"**——很多产品官网从没出现在 AI 的来源卡里，但站内数据正常。原因是内容不可抽取，不是没人看。
2. **通用题和品牌题的结果常常相反**：问「有什么好用的」时清一色竞品；只有问「X 是什么」时才提你——这说明你在"候选池"里还不存在。
3. **竞品官网就是渠道**：它们把 FAQ、对比、选型写成内容页，AI 一引就是它。照着这个形状做，比自己发明结构靠谱。
4. **同名混淆是通病**，尤其英文常见词。先做实体澄清，再谈内容，否则你做的内容会被算到别人头上。
5. **平台差异大于内容差异**：同一篇文章，在 A 平台被引、在 B 平台完全没有存在感。渠道选择比文笔重要。

## 八、常见坑（都会让人返工）

1. **挂没核实的标**：备案号、主体全称、资质、成立时间——错标比不标更糟，AI 会当事实转述，客户也会拿它质疑你
2. **改名只改首页**：站外商店页、问答、目录站还是旧名，实体更乱
3. **只写软文，不建内容页**：软文发完就没入口，AI 抽不到第二次
4. **踩平台红线词**：文案里出现"自动化/自动回复/外挂"这类词，可能被平台判；写之前先查平台规则原文
5. **拿"被引次数"当 KPI 却没固定题库**：数字每天变，没法证明做对了还是运气好

## 九、可复制清单

### 9.1 基线表（照这个列）

| 日期 | 平台 | 题号 | 是否出现 | 定义句对得上 | 被引域名（第几条） | 备注 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

### 9.2 每篇内容自查 6 问

1. 标题是不是用户会问的那句话？
2. 第一段有没有直接给答案？
3. 有没有具体数字 / 规则原文 / 步骤？
4. 有没有一段能独立被抄走？
5. FAQ 覆盖了几种长尾问法？
6. 有没有踩平台红线词或没核实的标？

### 9.3 月度复盘只看三个数

- 品牌题里"定义句对得上"的条数（实体澄清是否生效）
- 来源卡里自家域名的条数（是否进入被引池）
- 通用题里出现的次数（是否进入候选池）

三个数都不动，说明改的位置不对——回去重测基线，别继续加内容。

---

> 收尾一句：GEO 的活儿九成是「把话说清楚、把结构做对、把能测的测了」，看起来慢，但这三步做完，后面每一篇内容都在累积；跳过它们，写得再多也只是在自说自话。
