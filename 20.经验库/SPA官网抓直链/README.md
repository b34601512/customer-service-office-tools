# 经验包：SPA 官网找不到下载直链——钩住点击把 URL 抓出来

> **一句话**：下载直链是页面 JS 在**点击那一刻**拼出来的，静态 HTML 和「兜底接口」里都搜不到 →
> 在页面里装钩子（覆写 `window.open`、`<a>.click`、捕获真实点击），触发按钮，读记录。
>
> 用法：把本文件夹交给你的 AI，说「照这个包，把某 SPA 官网的下载直链抓出来」。

---

## 一、症状（真实案例）

- `curl` 拿到的页面**只有 JS**；试探 `/api/config`、`/api/download` 全是 SPA 兜底 HTML；
- 直链是点「立即下载」时在 JS 里现场拼出来的——搜文本、翻接口都找不到。

## 二、做法（四步）

1. **装钩子**：把 `模板\抓点击URL.js` 粘进浏览器控制台（或用自动化工具的「页面执行」）：
   它覆盖三个逃逸口——`window.open`、`HTMLAnchorElement.prototype.click`、以及捕获阶段的真实点击，
   命中都记进 `window.__抓`。
2. **触发按钮**（示例）：

   ```js
   [...document.querySelectorAll("button")]
     .find(b => b.innerText.trim() === "立即下载")
     .click();
   ```

3. **读记录**：控制台里看 `window.__抓` → 官方 CDN 直链到手。
4. （可选）把 `location.assign` / `location.replace` 也钩上，覆盖跳转型。

## 三、坑

- **同名按钮不止一个**（页头一个、Windows 一个、macOS 一个）——第一把点了「最后一个」，
  拿到的是 macOS 的包；**按顺序 / 坐标 / 相邻文字核对**再点。
- 页面若是 iframe 里的按钮，钩子要装进对应 frame。

## 四、给 AI 的执行说明（速查）

1. 先确认是 SPA（查看源码只有壳、接口都是兜底页）；
2. 注入钩子 → 用选择器/坐标找对那个按钮 → 点击 → 读 `window.__抓`；
3. 多按钮页面：先列出候选（位置＋文案＋尺寸），确认是目标平台再点；
4. 拿到直链后验签再装（如 Windows 用 `Get-AuthenticodeSignature`）。

## 五、包里有什么

| 文件 | 干嘛 |
|---|---|
| `模板\抓点击URL.js` | 钩 `window.open` / `<a>.click` / 捕获点击，把 URL 记进 `window.__抓` |

## 六、实测记录

- 手法为**来源现场实录**：用浏览器自动化真实抓到过官方 CDN 直链（含「点错平台」那次的教训）。
- 钩子片段为通用写法，本机（无浏览器自动化环境）**未复跑**，按控制台直接可用的形式给出。
