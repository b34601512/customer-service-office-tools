# 项目说明

## 1. 项目目标

把客服粘贴的杂乱文本整理成可直接复制的拼多多订单号或天猫退款编号；天猫模式还能读取退款明细 `.xlsx`，把退款编号反查成真实订单编号。

## 2. 技术形态

- 纯本地 HTML、CSS、原生 JavaScript 页面，没有后端、数据库、构建步骤和第三方联网依赖。
- 浏览器负责剪贴板、文件读取、ZIP 解压和 Excel XML 解析；同一套提取代码也可在 Node.js 中测试。

## 3. 模块结构

- `index.html`：页面骨架、平台选择、文件入口和结果区域。
- `src/extractor.js`：拼多多订单号与天猫退款编号的正则规则、去重和统计。
- `src/xlsxExtractor.js`：直接解压 `.xlsx`，读取首个工作表的“退款编号”“订单编号”，完成一一匹配。
- `src/app.js`：绑定粘贴、提取、选文件、复制和清空操作；`styles.css` 管界面样式。
- `tests/extractor.test.js`：Node.js 回归测试；`tests/browser-xlsx.html` 是浏览器解析验证页。

## 4. 数据流

拼多多：`粘贴文本` → `正则找订单号` → `按原顺序去重` → `页面显示并复制`。天猫：`文本提取退款编号` + `本地退款明细 xlsx` → `浏览器解压并读取表格` → `退款编号匹配订单编号` → `分列显示、统计未命中并复制订单号`。文件全程留在本机浏览器内。

## 5. 运行与测试

直接用新版 Edge/Chrome 打开 `index.html` 即可；若浏览器限制本地剪贴板，可在项目目录运行 `python -m http.server 8000`，再访问 `http://127.0.0.1:8000/`。安装 Node.js 后运行 `node tests/extractor.test.js`，测试会读取项目根目录的天猫样例表并校验提取数量和匹配结果。
