# 开源边界：哪些是公司私有、哪些可分享（2026-09-28 用户拍板）

> 本仓库是对外开源的；企业微信里的资源属于公司私有。
> 总规则：**私有信息只放本机、永不入库；通用经验脱敏后才能写进仓库。**

## 一、绝不入库（公司私有 / 凭据）

| 类别 | 例子 | 正确存放 |
|---|---|---|
| 企微 webhook | 群机器人地址、智能表格「接收外部数据」Webhook（含 key） | 本机环境变量或 `project-config/`（本项目已 gitignore） |
| 机器人凭据 | Bot ID、Secret、`wecom-cli` 凭据文件 | 只在本机（CLI 加密存储）；仓库只写「怎么获取」 |
| 登录态 | 企微/平台 cookie、浏览器 profile | `runtime/`（已 gitignore） |
| 业务数据 | 工单内容、客户/员工姓名手机号、订单号、聊天记录、金额、店铺账号 | 只在本地运行产物里；永不提交 |
| 公司内部结构 | 真实表名+字段定义、群名、组织架构 | 文档里只写脱敏示例（`示例字段A/B`） |
| 内部链接 | `doc.weixin.qq.com/smartsheet/...`、微盘分享链接 | 只在本地配置或当轮会话里用 |

> 智能表格 Webhook 是**只写密钥**：POST 才有效，GET 读不了表（实测 `errcode=40058`）。
> 官方 Skill 要求「用完即弃」；本项目遵循同一口径，除非某自动化项目明确需要，才放进已 gitignore 的本地配置。

## 二、可以入库（通用经验）

- 官方文档链接、官方提示词、安装/排错步骤、错误码含义（`893001`/`851003`/`45009` 等）；
- 参数化脚本模板：URL/Secret 一律从参数或环境变量读，默认 dry-run；
- 脱敏例子：字段用 `示例字段`、人名用 `张三`、截图文案打码；
- 踩坑规律本身（如 `wecom-cli auth init --manual` 必须真实终端）——不含公司信息就属于通用经验。

## 三、给 AI 的提交前检查（机械化）

1. `git diff --cached` 逐行看，重点搜：`key=`、`secret`、`webhook`、手机号长数字、订单号、真实人名/群名；
2. 命中的必须是**占位符或官方文档示例值**，否则撤回该文件；
3. 配置一律放 `project-config/` 或环境变量，并确认被 `.gitignore` 覆盖（本项目已有 `27.企业微信机器人/.gitignore`）；
4. 从企微/平台读到的内容**默认视为公司数据**——先脱敏再写进任何入库文件（README/经验/测试）。

## 四、已确认安全的现状（2026-09-28）

- 27号仓库文件里只有占位符（`key=xxx`、测试值 `key=abc`），无真实 key/ID；
- 授权信息（Bot ID/Secret）不在仓库，由 `wecom-cli` 加密存放在本机；
- 用户提供的售后任务工单表 Webhook 只存在于对话记录，**未写入任何仓库文件**。
