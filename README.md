# 客服主管办公软件

面向电商客服主管的一站式办公工具集：覆盖客服超时督办、发票自动化、响应时间发送、退款提醒、电话漏接分析、自动报量、店铺指标自动更新等日常场景，全部为本地运行工具。

## 项目清单

| 目录 | 工具 | 定位 |
| --- | --- | --- |
| 1.客服超时督办 | 客服督办控制台 | 平台超时/转接/漏回复监控与企微升级提醒 |
| 2.发票自动化 | 发票自动化套件 | 京东开票巡检、京东/天猫/拼多多/抖音发票回传、通用发票下载中心 |
| 3.响应时间 | 京东响应时间直连发送器 | 网页客户端与京东客服端直连发送测试内容 |
| 4.仅退款自动提醒 | 退款自动提醒 | 管易云 ERP 退款订单扫描与系统通知 |
| 5.电话漏接分析 | 电话漏接分析 | 呼入/呼出/呼损报表下载与客服统计 |
| 7.订单号提取 | 订单号提取 | 批量提取、去重订单号（网页版） |
| 8.抖音直播评论家 | 抖音直播评论家 | 本地控制台自动发送直播评论 |
| 9.客服数据自动更新 | 客服数据自动更新 | 天猫/京东/拼多多/抖音客服指标自动汇总 |
| 10.自动报量 | 自动报量 | 报量表格 CLI 与网页导入工具 |
| 11.视频压缩工具 | 视频压缩工具 | 批量压缩视频到目标大小以下 |
| 12.店铺指标数据自动更新 | 店铺指标自动更新 | 多平台店铺考核指标自动采集 |
| 13.客服培训课件制作 | 客服培训课件制作 | 聊天记录演示 HTML 制作经验模板 |

## 使用方式

- 每个子项目的使用说明见对应目录 README（作者与版权信息已标注在各首页）。
- 仓库根目录的 `备份办公软件源代码.bat` 用于一键备份源码到 GitHub。

## 隐私说明

- 仓库仅收录源代码；账号密码、登录会话、浏览器数据、日志与业务数据均不入库（通过 `.gitignore` 与提交过滤器保证）。
- 各项目运行所需的本地配置（店铺账号、金山令牌、座席映射等）**只保存在本机，不进仓库**；仓库对应位置提供 `*.example.*` 模板，克隆后复制改名并填写真实值即可。
- 这些配置的真值文件（如 `project-config/platform-config.json`）被 `.gitignore` 排除，即使误执行 `git add --all` 也不会入库。
