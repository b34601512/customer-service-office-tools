# 京东登录按钮定位失效

## 意图

修复京麦新版密码登录页无法自动提交的问题，使京东1店能够沿用统一登录流程完成采集。

## 背景

- 2026-09-10 京东1店和京东3店均失败。
- 失败现场已经填入账号密码，页面可见“立即登录”按钮。
- 现场 DOM 实际为 `button.password__submit > span`，没有 `#loginsubmit`；Playwright 的 `button:text-is('立即登录')` 在该页实际返回0，虽然页面肉眼可见按钮。
- 之前单测只模拟了 `button` 选择器，没有覆盖新版京麦的真实文本定位，因此误判已修复。

- [x] 存在多个可见候选时拒绝猜测点击目标。
- [x] 已有密码输入框时不重复点击密码登录切换入口。

## 边界

- 不自动绕过验证码、滑块或安全验证。
- 不使用强制点击或坐标点击掩盖页面结构问题。
- 不修改本次问题无关的既有工作区改动。
