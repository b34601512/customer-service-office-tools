当前版本为 `v0.01` CLI 控制台。双击启动后，程序在命令行中管理多平台、多店铺，按已启用店铺逐家复用登录会话，读取平台官方店铺考核页面，并写入统一数据源表。

## 使用方法

1. 双击 `启动控制台.bat`，只会打开命令行控制台，不再打开控制台网页。
2. 输入 `2` 强制重新采集全部已启用店铺；同记录键覆盖，新的记录追加。
3. 输入 `3` 进入店铺管理；可以新增店铺、修改编号、名称和登录凭证、启用或停用店铺。新增编号可直接填 `6`，允许跳号。
4. 输入 `4` 选择“智能修改”或“手动修改”。手动方式只选择一个快照日。
5. 输入 `1` 开始汇总。程序会按顺序运行全部已启用店铺，并实时显示当前进度。
6. 当天同一店铺、同一统计方式已经成功完成且汇总表数据完整时会直接跳过；手动删掉数据后会自动重采集。
7. 输入 `7` 可打开汇总文件夹；输入 `6` 可打开最近凭证文件夹。
8. 输入 `A` 进入金山文档同步：首次配置在线文档、共享脚本 webhook 和脚本令牌后，可一键同步本地“数据源”。

开始汇总前请先保存并关闭汇总表。若汇总表正在被WPS或Excel占用，程序会在登录任何店铺前停止并明确提示，不会让多家店铺逐家白跑，也不会强制关闭表格软件。

智能日期会读取各考核页面的最新可用数据；手动日期只指定店铺星级快照日，其他页面仍保存页面自身展示的真实统计区间。

## 当前范围

- 平台：京东、天猫、拼多多、抖音。
- 店铺：支持多平台、多店铺；抖音已配置德达抖音和dedakj抖音，可逐店启用或停用，编号允许跳号。
- 结果：只保存平台直接展示的店铺考核最终数值，不下载客服接待数据，不保存个人或业务明细。
- 来源：京东店铺星级、违规服务分析、店铺合规；天猫真实体验分及考核得分；拼多多客服数据、售后数据、综合体验星级页面中的店铺整体数值；抖音服务体验页面中的服务得分、考核表现和差行为数据。
- 数据源：`outputs\019fbb96-c39c-7ec1-899b-038594c1381a\店铺指标数据源.xlsx`。
- 当天跳过：同一店铺、同一统计方式、同一汇总表和同一批官方来源当天已经成功完成后，再次运行会直接跳过，不启动浏览器；失败记录不会阻止重试。
- 跨天更新：进入新的一天，或切换智能/手动统计方式后，程序会重新采集；同一店铺、指标、来源和统计口径仍会更新原记录，不会重复累加。
- 凭证：页面读取成功会保存页面截图；页面或批量任务失败时，至少保存一份“失败原因”文字，不再出现失败却没有凭证。
- 凭证命名：新凭证文件夹按时间、平台、店铺名称和编号命名；文件名标明凭证类型及读取成功或失败。
- 失败处理：某家店失败后继续下一家，最终分别显示成功和失败结果；凭证按真实存在的文件计数并标明来源。
- 写表保护：运行前先检查汇总表占用状态；短暂占用会自动重试，持续占用时保留待写文件并保护原表。
- 操作界面：纯CLI；程序本身不启动本地网页服务器，也不打开控制台网页。
- 金山同步：只保留一个数据源脚本；先清空在线“数据源”，再从A1镜像本地12列，旧尾行和旧列必须为空，逐格一致才算成功。

## 运行边界

- 正常运行完全由本地程序完成，不调用AI或Codex。
- CLI不会显示已保存密码，只显示是否已配置；输入新密码时使用掩码。
- 登录页允许程序自动填写账号、密码并点击登录；抖音沿用9号项目的共享登录会话，首次登录或登录失效时请在独立浏览器中人工完成。京东、天猫、拼多多、抖音若出现滑块、验证码或安全验证，程序会停留在当前浏览器页面持续等待，不会尝试绕过，人工完成后自动继续。
- 数据源只保留一个“采集日期”；平台页面自己的统计窗口只作为“原始统计窗口”文字备注。
- 每家店重新采集后覆盖该店旧数据；指标名称统一为“平台-指标”，不再保留指标分类和跨平台统一指标。
