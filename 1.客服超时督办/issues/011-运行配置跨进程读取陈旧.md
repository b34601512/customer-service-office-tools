# 运行配置跨进程读取陈旧

## 意图与证据
登录子进程会自动写入工作台地址，但控制台读取配置一直返回启动时缓存的 appConfig.targetUrl；主管随后编辑其他配置可能把地址覆盖回旧值。配置文件应为唯一持久化真源。

## 验收
- [x] 配置页每次读取使用文件最新值。
- [x] 局部更新没有提供的字段保留文件现值，不重置地址或引用进程旧值。
- [x] 回归覆盖“外部写入后读取”和“只更新主管姓名”。

## 边界
不修改用户配置内容、不引入副本或数据库。TUI保存前重读最新值叠加编辑字段；网页未编辑工作台地址时省略回写，已用真实Edge本地保存验证，不实现多人协同编辑系统。
