# 未回复监控覆盖全部联系人

## 意图

待回复客户不能因离开最近 20 位联系人而从督办中消失。

## 背景

现场联系人快照约 90 位，当前未回复模块只截取最近 20 位，并清除不在这 20 位中的运行状态。

## 验收清单

- [x] 未回复监控消费接口当前可返回的完整联系人快照。
- [x] 消息读取仍按批次轮转，避免一次读取全部会话。
- [x] 已发现的未解决责任即使暂时不在联系人快照中也保留并继续核验。
- [x] 只有消息事实确认已解决时才清除待回复状态。

## 边界

- 不把本地状态变成会话事实真源；它只保存待核验索引与提醒去重记录。
- 不用提高机器负载的全量高频消息请求作为简单兜底。

## 验证记录

- 已验证 90 位联系人不再截断为 20 位；每轮仍按配置小批轮转。
- 已验证快照缺失时保留未解决索引，已解决展示项才允许清理。
- 完整 `npm test`：341 项通过。
