# 待回复计时从首条未解决消息开始

## 意图

客户连续追问不能把已经产生的等待时间清零。

## 背景

现策略取最后一条需处理客户消息作为计时起点；同一待办内客户再次追问会重置超时和漏回复时间。

## 验收清单

- [x] 上次人工实质回复后的首条需处理客户消息开启待回复责任。
- [x] 后续客户追问只更新最新内容，不改变原计时起点。
- [x] 人工实质回复后才关闭旧责任；之后的新问题开启新责任。
- [x] 同一责任的超时与漏回复各最多提醒一次，追问不生成重复事件。

## 边界

- 客户弱收尾、纯标点及无正文小程序卡片不新建责任。
- 不增加第二套计时状态；提醒身份统一使用同一待回复责任起点。
