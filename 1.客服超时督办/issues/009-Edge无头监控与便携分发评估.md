## 意图

后台监控不弹业务浏览器窗口，主管仍能在独立界面查看过程；取消项目对 Chrome 的依赖，方便分享给其他主管。不是卸载用户电脑上的 Chrome，也不以隐藏窗口冒充修复白屏。

## 结论与边界

建议方案为一个现有控制台 + 后台 Edge 无头监控，首次登录或登录失效时显示独立登录窗口。只保留 Edge 一条浏览器实现，不新增 Chrome 自动回退分支。具体改动须在完整阅读相关代码后实施。

无头可消除业务窗口干扰，但仍执行网页脚本、网络请求及页面布局，不能承诺显著降低 CPU/内存或缩短督办周期；需同负载对照测量。Edge 替换的主要价值是部署便利，不是保证比 Chrome 更快。它也不能保证修复未知白屏原因。

真正分享即用还需制作包含运行时、依赖和必要共享模块的分发包，逐台首次登录及配置；不能携带开发者登录态、机器人密钥、业务日志或客户数据。新 Edge 使用应用独立数据目录，不复用个人默认浏览器配置，不把旧 Chrome 资料夹直接视作兼容资料。

Win10 需现代 Chromium Edge，不能覆盖所有老旧或精简 Windows；浏览器被移除或企业策略禁止自动化/无头时须明确提示，不绕过策略。所选 Node/Playwright 版本也须核实目标 Windows 支持。
