# 工具（单一用途，可组合）

排班**不做一键脚本**。需要动手时按需挑一个跑：每个工具只干一件事，中间产物是 JSON / TSV，
方便人工看一眼、替换、重跑——**脚本是手脚，不是模板**。

| 工具 | 用途 | 读写 |
| --- | --- | --- |
| `读排班表.py` | 读一份排班 xlsx（或 TSV），打印结构 / 班次 / 底色 / 每日覆盖 | 只读 |
| `验排班表.py` | 按 `验收清单.md` 逐项判：跨月、覆盖、晚接早、连上、值班、底色、统计公式 | 只读 |
| `写排班表.py` | 把「计划 JSON」写回 xlsx：班次 + 底色 + 公式统计 + 缓存值 + TSV | 写 |
| `对比排班表.py` | 对比两张表（改前/改后、AI 版/人工版、快照对真表）：班次/底色/覆盖/统计/值班次数 | 只读 |
| `解排班示例.py` | 2026-10 案例的求解过程（**模板**：下月复制，改顶部「案例配置」） | 只读，输出计划 JSON |

## 典型组合（排新月份）

```powershell
cd "D:\桌面\办公软件\21.AI自动排班经验"

# 1) 先看现状/上月
python "工具\读排班表.py" --xlsx "测试数据\2026年10月客服排班表.xlsx"

# 2) 求解：复制 解排班示例.py 改配置（上月末状态、休息、政策休息天数），输出计划
python "工具\解排班示例.py" --out "测试数据\2026年11月-计划.json"

# 3) 写回表（值+底色+公式统计+缓存值+TSV）
python "工具\写排班表.py" --xlsx "测试数据\2026年11月客服排班表.xlsx" `
    --plan "测试数据\2026年11月-计划.json" --tsv "测试数据\2026年11月客服排班表.tsv"

# 4) 验收（✗ 必须清零，再到 验收清单.md 勾人工项）
python "工具\验排班表.py" --xlsx "测试数据\2026年11月客服排班表.xlsx" `
    --prev "…\2026-10-31-2026年10月.tsv" --lead 李守耀

# 5) 改过表？和改前/上一步对拍，确认只改了你想改的
python "工具\对比排班表.py" --a "改前.xlsx" --b "改后.xlsx"

# 6) 改了校验工具？拿反例表回归一遍（该抓的一个都不能漏）
python "工具\验排班表.py" --xlsx "测试数据\反例\bad.xlsx"  --lead 李守耀   # 期望 14 项 ✗
python "工具\验排班表.py" --xlsx "测试数据\反例\month30.xlsx" --lead 李守耀 # 期望 30 天全过
```

## 计划 JSON 格式（`写排班表.py` 的输入）

```json
{
  "meta": {
    "days": 31,
    "policy_rest": 6,
    "policy_note": "大小周",
    "lead": "李守耀",
    "carry": {"韩欢欢": "0", "缪婷婷": "-1天"},
    "codes": {"缪婷婷|8": "行"},
    "orange": ["柯紫婷|12", "缪婷婷|14"],
    "white": ["麦诺谦|15"],
    "carry_width": 24
  },
  "seller": {"韩欢欢": ["早", "早", "晚", "", "…31 个…"]},
  "after":  {"李守耀": ["", "早", "早", "…31 个…"]},
  "duty":   {"韩欢欢|1": "早", "刘秀文|1": "晚"}
}
```

- `seller` / `after`：每人一格，`""` = 休；长度 = `days`。
- `duty`：售前值班绿标，键 `姓名|日`。
- 2026 年 10 月的成品计划在 `../测试数据/2026年10月-计划.json`，可直接拿来试跑。

## 注意

- 工具是幂等的：同一份计划重跑，结果一样。
- `写排班表.py` **直接改原表**（就地写）；跑前先备份，或在 git 里确认有 TSV 兜底。
- 「剩余」列是手填文本（上月结转 + 小时折算），工具不猜、也不改；只把它那一列调宽。
- 统计列写公式的同时会写入**缓存值**，这样不重算的程序（openpyxl 等）也能读到数字；
  用金山 / WPS / Excel 打开时会自动重算（表里已置 `fullCalcOnLoad`）。
