# 其他
# 春节排班：
1.只需要弄清楚当月休几天，然后给客服安排休几天即可。
2.休息总天数需要知道具体的组成结构。例如：16天假计算方式（16天=1天元旦+3天春节法定节假日+7天周末+5老员工带薪假福利）
3.需要2个月班一起排，不然过年假期无法安排下个月排班，或者刚上班后来不及安排，所以最好提前安排2个月的。而且两个月一起排才方便知道假期放在哪个月休比较好。
# 关于调班
调班必须是跟未上班的同事调，需要有未上班的同事来顶你的班才能算调班，不可以自己的时间调整而没有其他人来顶班，否则这样会因为自己不在岗而造成在岗人员工作量加大。
如果没人来顶班只能算请假，不可以算调班。
如果是请假或者调休，请提前最少24小时跟我说明，不要等到最后一刻才跟主管说，这样主管会感觉很被动，没有任何选择的余地，感觉像是被通知，感觉不被尊重，主管也需要被尊重。除非你是突发意外无法来上班了。
# 请假休假注意事项：
1.连续休假超过3天，含3天，请主动跟经理说明情况，避免发生意外不知道寻找方向。
2.请假提前24小时以上说。
3.离职提前30天以上说，如果是双12以后尽量2个月以上提前说明，过年不好招人。
4.申请休年假需要在企业微信上申请，由公司人事审批。
5.如果申请住院病假，不知道要住院多久的，也先企业微信申请，申请时间写一周，后续看情况再销假或者延长，记得把入院通知和医生报告作为附件。
# 特殊注意事项
当到下个月后，记得把上个月排班内容设置提示，因为偶尔会有人看错班次，上错班的情况发生。
