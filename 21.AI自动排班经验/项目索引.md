# 21.AI自动排班经验 · 项目索引

> 开工先看：**本页** → `断点记录.md`（上次做到哪）→ `README.md`（每月怎么用）→ `排班原则.md`（制度）+ `排班经验.md`（我们自己的定稿经验）。
> 总规矩：根 `../AGENTS.md` + `../0.木婉清档案/规矩与红线.md`。最后整理：2026-10-09。

- **干嘛的**：AI 排班经验库 + 单一用途小工具（读表/验表/写回/对比/推应休）。**不做一键自动排班脚本**（死板、不好调整）——每次由 AI 结合当月实际情况思考怎么排。
- **口径**：
  - **本月应休必须每次问用户/人事确认**（= 法定节假日 + 大小周，月月不同，**别沿用上月值**）；大小周可用 `工具/推应休天数.py` 从上月周六红标推。
  - 排法顺序：**排休 → 晚班 → 值班**；保底售前每天 2 早 2 晚，**售后也是每天 2 早 2 晚**；日常不排「行」（只新员工入职时人工）。
  - 教程是**原则**、日志是**经验**，冲突时以过往人工排法和经验日志定稿为准。
  - 排完对照 `验收清单.md` 逐项打勾 + `工具/验排班表.py` 自动判（跨月/覆盖/晚接早/连上/值班/底色/统计公式…）。
- **命令**（详见 README/断点）：
  ```bash
  python "工具\验排班表.py" --xlsx "测试数据\2026年10月客服排班表.xlsx" --prev "…上月表/快照.tsv" --lead 李四
  python "工具\写排班表.py" --xlsx "…xlsx" --plan "…计划.json" --tsv "…tsv"   # 统计/汇总用公式
  node "工具\写在线排班表.cjs" --plan "…计划.json" --sheet "2026年10月" --dry-run   # 写在线=真写
  ```
- **红线**：**法定节假日/天数不许猜**（问用户/人事）；**写在线班次/值班底色必须用户批准**（先 `--dry-run/--diagnose`，写后只读对拍）；`*.xlsx` 与真值配置不入库；脚本文件要带 BOM 的 UTF-8、给用户走剪贴板别用 `cat | clip`。
