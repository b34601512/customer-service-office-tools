# 21.AI自动排班经验

AI 排班经验库：**不做一键自动排班脚本**（死板、不好调整）。这里记录排班方法与制度；每次排班由 AI 结合当月实际情况（天数、节假日、每人剩余假期、请假需求、业务忙闲）去思考怎么排合理。需要动手时，用 `工具/` 里的单一用途小工具按需组合——像手脚，而不是一套模板。

| 文件 / 目录 | 说明 |
| --- | --- |
| `排班原则.md` | **原则/制度**：金山《排班教程》提取的流程与规矩（五阶段做法、春节、调班、请假、月底） |
| `排班经验.md` | **我们自己的经验**：主管口述、历史人工排法与踩坑的定稿结论（带日期，持续追加） |
| `工具/` | 单一用途小工具，可自由组合 |
| `测试数据/` | 2026 年 10 月格式样例（xlsx + tsv），对照表结构与底色 |
| `参考/` | 《排班教程》正文 + 8 张截图 + 提取报告存档 |

> 教程是**原则**，日志是**经验**：原则定流程，经验定每月具体怎么排；两者冲突时，以过往人工排法和经验日志里的定稿为准。

## 每月怎么用

1. **先接上月**：看上月底最后一天每人的班次与已连上天数（晚班只能接休息或继续晚；连上含跨月），再收集当月事实：天数、节假日与调休、**每人剩余假期（从上月剩余继承）**、请假/固定休需求、业务忙闲。年假不主动排（客服自行申请）。
2. 先看旧表和现状（`工具/读排班表.py`），再按经验判断：**排休 → 晚班 → 值班**；保底：售前每天 2 早 2 晚，售后每天 2 早（晚班 1~2 个）。
3. 排完自检：每天在岗人数、晚班不接次日早班（**含跨月**）、连续上班不超限（**含跨月累计**）、休息在额度内、剩余假期算对、值班尽量间隔（不连值）。
4. 和上月实际、主管要求对照，不合适就调整。
