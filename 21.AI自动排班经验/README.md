# 21.AI自动排班经验

AI 排班经验库：**不做一键自动排班脚本**（死板、不好调整）。这里记录排班方法与制度；每次排班由 AI 结合当月实际情况（天数、节假日、每人剩余假期、请假需求、业务忙闲）去思考怎么排合理。需要动手时，用 `工具/` 里的单一用途小工具按需组合——像手脚，而不是一套模板。

| 文件 / 目录 | 说明 |
| --- | --- |
| `排班原则.md` | **原则/制度**：金山《排班教程》提取的流程与规矩（含跨月衔接、五阶段做法、春节、调班、请假、月底） |
| `排班经验.md` | **我们自己的经验**：主管口述、历史人工排法与踩坑的定稿结论（带日期，持续追加） |
| `验收清单.md` | **排完逐项打勾**的验收表；全部通过才算排好 |
| `工具/` | 单一用途小工具，可自由组合（清单与用法见 `工具/README.md`） |
| `工具/读排班表.py` | 读表：结构 / 班次 / 底色 / 每日覆盖，只读 |
| `工具/验排班表.py` | 按验收清单自动判（跨月/覆盖/晚接早/连上/值班/底色/统计/公式），只读 |
| `工具/写排班表.py` | 把计划 JSON 写回 xlsx（值+底色+公式统计+缓存值+TSV），可复用 |
| `工具/对比排班表.py` | 对比两张表（改前/改后、快照对真表），只读 |
| `工具/解排班示例.py` | 求解模板（2026-10 案例，下月复制改配置） |
| `测试数据/` | 2026 年 10 月格式样例（xlsx + tsv + 计划 JSON），对照表结构与底色 |

> 教程是**原则**，日志是**经验**：原则定流程，经验定每月具体怎么排；两者冲突时，以过往人工排法和经验日志里的定稿为准。

## 每月怎么用

1. **先接上月**：看上月底最后一天每人的班次与已连上天数（晚班只能接休息或继续晚；连上含跨月），再收集当月事实：天数、节假日与调休、**每人剩余假期（从上月剩余继承）**、请假/固定休需求、业务忙闲。年假不主动排（客服自行申请）。
2. 先看旧表和现状（`工具/读排班表.py`），再按经验判断：**排休 → 晚班 → 值班**；保底：售前每天 2 早 2 晚，售后每天 2 早（晚班 1~2 个）。
3. 排完自检：对照 **`验收清单.md` 逐项打勾**，并用 `工具/验排班表.py` 把自动项一次判完（跨月、覆盖、晚接早、连上、值班、底色、统计/汇总/上班人数、统计公式是否按当月天数取范围）；全部通过才算排好。
   ```powershell
   python "工具\验排班表.py" --xlsx "测试数据\2026年10月客服排班表.xlsx" --prev "…上月表或快照.tsv" --lead 李守耀
   ```
4. 写回表用 `工具/写排班表.py`（吃计划 JSON）：统计/汇总/小计/上班人数都用**公式**，「本月天数」自动算，避免把 30 天的月份算成 31 天；公式同时带缓存值，不重算的程序也读得到数（详见 `排班经验.md`）。
5. 和上月实际、主管要求对照，不合适就调整。
