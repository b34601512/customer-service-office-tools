# 排班验收清单

> 排完当月表后**逐项对照**，全部打勾才算排好。自动项用 `工具/读排班表.py` + `工具/验排班表.py`，主观项人工看。
> 配套：`排班原则.md`（原则/制度）、`排班经验.md`（定稿经验）。
> **维护约定**：主管/用户每次提要求、纠正或口径，当场落三处：经验一条 + 本清单一条 +（能自动判的）补进 `工具/验排班表.py`。

## 〇、跨月衔接（先验，这里错了后面全白排）

- [ ] 已看上月底最后一天每人是什么班（来源：上月表或其快照）
- [ ] 上月底晚班的人，本月 1 号是「晚」或「休」——**晚班只能接休息或继续晚班（跨月同样）**
- [ ] 连上天数**含跨月**：上月已连 N 天 + 本月开头连上 ≤5 天（最多 6，且要说明原因）
- [ ] 固定班顺延（如李守耀「上五休一」：按上月最后一个休息日往后推，不重新起算）
- [ ] 剩余假用上月「剩余」列的值做起点（不是从 0 开始）

## 一、在岗覆盖（保底人数）

- [ ] 售前：每天 2 早 + 2 晚 + 1 休
- [ ] 售后：每天 **2 早**（保底），晚班 1~2 个（宁可少晚班，不减早班）
- [ ] 李守耀休假日：售后其余 4 人全上（2 早 2 晚）
- [ ] 李守耀：全早、上五休一
- [ ] 每天上班人数与表内「上班人数」行一致（结构行标签不能丢），且不低于要求

## 二、晚班

- [ ] 不出现「晚接早」：月内、跨月都要查（9/30 晚 → 10/1 不能早）
- [ ] 晚班成段（一般 1~4 天）且只接休息或继续晚班，不东一天西一天
- [ ] 同组晚班次数均衡（相差 ≤1~2 天）
- [ ] 晚班总天数与覆盖要求对得上（售前每天 2 个；售后每天 1~2 个）

## 三、连上与休息

- [ ] 连续上班 ≤5 天（含跨月累计）；超过要说明
- [ ] 休息日错开（相邻休隔 3~6 天），**不用固定周期/取模**
- [ ] 每人休息天数在应休额度内；超出/不足用剩余假记录
- [ ] 在岗不受影响的前提下，尽量安排连休 2~3 天
- [ ] 请假、固定休等需求已满足并标记

## 四、值班（底色）

- [ ] 售前每天早班、晚班**各 1 人**值班（绿 `#E2F0D9`）
- [ ] 同一人不连续两天值班，尽量拉开间隔
- [ ] 全月每人值班 12~13 次（均衡）
- [ ] 售后每天早班、晚班**各 1 人**值班（蓝 `#BDD7EE`）；组长李守耀在岗时早班这个名额就是他（黄 `#FFFF00`），他休息的日子早班另选 1 人
- [ ] **一个班次只标一个人**：售后其他人照常在岗但不涂色（当班 ≠ 值班，曾经把全部当班涂蓝是错的）
- [ ] 值班不标在休息/行/年假格上，不标给不在岗的人
- [ ] 颜色只用于约定含义（白 `#FFFFFF` = 无标记）；读取时用 `getAppliedXf`

## 五、特殊标记与休假

- [ ] **年假不主动排**（客服自己申请）；休息格直接记空白，用剩余假
- [ ] 售后每天 **2 早 2 晚**（不是只保 2 早）：5 人（组长全早）每天 1 人不在岗；组长休息日 4 人全上（2早2晚）
- [ ] **实到 ≈ 应到、休息 ≈ 本月应休**：别让人休 11~12 天（那是严重超休）
- [ ] 「行」算实到、不算休息，也不打断连上（算间隔时要把它当上班日）
- [ ] 售后不在岗日可以连休 2 天（真表就有）；售前休息仍按“每天 1 人、相邻休隔 3~6 天”
- [ ] 「行」/公休（橙 `#FBE5D6`）只落在休息格，且与实际一致
- [ ] 月份标记等非员工行不参与员工统计
- [ ] 备注写清每人休息构成（如：休 6 天 = 本月 5 天 + 上月剩余 1 天）

## 六、数据与统计（统计列必须是公式）

- [ ] 日期、星期、当月天数（28/30/31）正确
- [ ] 「本月天数」格是公式自动算当月天数（`=COUNTA(日期行)`），**不是写死的 31**
- [ ] 「本月休息天数」政策格有值（节假日调休写明，如「6+1天中秋」）
- [ ] 休息 = `COUNTBLANK(当月天数范围)` 或 `=本月天数−早−晚−年−行`；**30 天的月份不能把 31 号空白当成休息**；两种写法都必须引用「本月天数」格
- [ ] 早班/晚班 = `COUNTIF($C4:$AG4,"早"/"晚")`（范围直接写 1 号到 31 号，看着就知道统计整月）；实到 = 早+晚（+行）；年假不算实到
- [ ] 应到 = 本月天数 − 本月休息天数，**全组统一**（不是逐人“天数−个人休息”）
- [ ] 汇总行（早/晚/休）用 `COUNTIF/COUNTBLANK`；小计用 `SUM`；上班人数用汇总行相加
- [ ] **年假列 = 上月结转的年假余额**（如 `1天3小时`），不是本月休了几天——不能写 `COUNTIF(...,"年")`；本月真休了年假要人工扣减
- [ ] **剩余 = 上月结转 +（本月应休 − 实休）**，按 8 小时/天折算成 `x天x小时`（读真表 `-1天=3天…` 这种只取等号前的余额）
- [ ] **不超休**：可休假期 = 上月剩余 + 本月应休 + 愿用的年假；实休 > 可休就要安排上班，实在要休写备注（如「下个月」）
- [ ] 统计列若写成数值，必须与矩阵逐人对账一致
- [ ] **剩余列宽度跟每日排班的格宽一致**（别自己加宽，显得 “太宽”）
- [ ] 公式格带**缓存值**（不重算的程序/工具也能读到数字）；用金山/WPS/Excel 打开能重算
- [ ] xlsx 与 TSV 同步导出（公式不入 TSV，TSV 存数值）

## 七、制度

- [ ] 调班必须有人顶班，否则只能算请假
- [ ] 连休 ≥3 天已报经理；请假提前 ≥24 小时；离职提前 ≥30 天
- [ ] 上月表已设置「本月已经结束~」数据有效性提示（月底收尾）

## 验收方式

1. 自动项一把过（跨月、在岗覆盖、晚接早、连上、值班、底色、统计/汇总/小计/上班人数、统计公式是否按当月天数取范围、月份标记；TSV 无底色会自动跳过值班）：
   ```powershell
   cd "D:\桌面\办公软件\21.AI自动排班经验"
   python "工具\验排班表.py" --xlsx "测试数据\2026年10月客服排班表.xlsx" `
     --prev "D:\桌面\办公软件\1.客服超时督办\runtime\schedule-query-snapshot\2026-09-12-2026年9月.tsv" --lead 李守耀
   ```
   输出里 `✗` 必须清零；`!` 逐条看是否可接受。
2. 人工核对（工具不判）：剩余假口径（上月剩余 + 应休 − 实休）、备注是否写清、请假/调班/连休报备等制度项——对照本清单逐条打勾。
3. **写表用 `工具/写排班表.py`**（计划 JSON → 值+底色+公式+缓存值+TSV）；写完与验收前各跑一次 `验排班表`。
4. **改过表就对拍**：`工具/对比排班表.py --a 改前 --b 改后`，确认只改了想改的。
5. **改了校验工具就回归**：`测试数据/反例/` 三张反例表（bad 应报 14 项 ✗、bad2 应报 5 项 ✗、month30 应 30 天全过）——该抓的没抓到就是工具坏了。
6. **全部打勾才算排好**；有不过的项回炉重排，改完从「〇、跨月衔接」重新验一遍。
