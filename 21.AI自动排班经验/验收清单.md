# 排班验收清单

> 排完当月表后**逐项对照**，全部打勾才算排好。自动项用 `工具/读排班表.py` + 校验脚本，主观项人工看。
> 配套：`排班原则.md`（原则/制度）、`排班经验.md`（定稿经验）。

## 〇、跨月衔接（先验，这里错了后面全白排）

- [ ] 已看上月底最后一天每人是什么班（来源：上月表或其快照）
- [ ] 上月底晚班的人，本月 1 号是「晚」或「休」——**晚班只能接休息或继续晚班（跨月同样）**
- [ ] 连上天数**含跨月**：上月已连 N 天 + 本月开头连上 ≤5 天（最多 6，且要说明原因）
- [ ] 固定班顺延（如李守耀「上五休一」：按上月最后一个休息日往后推，不重新起算）
- [ ] 剩余假用上月「剩余」列的值做起点（不是从 0 开始）

## 一、在岗覆盖（保底人数）

- [ ] 售前：每天 2 早 + 2 晚 + 1 休
- [ ] 售后：每天 **2 早**（保底），晚班 1~2 个（宁可少晚班，不减早班）
- [ ] 李守耀休假日：售后其余 4 人全上（2 早 2 晚）
- [ ] 李守耀：全早、上五休一
- [ ] 每天上班人数与表内「上班人数」行一致，且不低于要求

## 二、晚班

- [ ] 不出现「晚接早」：月内、跨月都要查（9/30 晚 → 10/1 不能早）
- [ ] 晚班成段（一般 1~4 天）且只接休息或继续晚班，不东一天西一天
- [ ] 同组晚班次数均衡（相差 ≤1~2 天）
- [ ] 晚班总天数与覆盖要求对得上（售前每天 2 个；售后每天 1~2 个）

## 三、连上与休息

- [ ] 连续上班 ≤5 天（含跨月累计）；超过要说明
- [ ] 休息日错开（相邻休隔 3~6 天），**不用固定周期/取模**
- [ ] 每人休息天数在应休额度内；超出/不足用剩余假记录
- [ ] 在岗不受影响的前提下，尽量安排连休 2~3 天
- [ ] 请假、固定休等需求已满足并标记

## 四、值班（底色）

- [ ] 售前每天早班、晚班**各 1 人**值班（绿 `#E2F0D9`）
- [ ] 同一人不连续两天值班，尽量拉开间隔
- [ ] 全月每人值班 12~13 次（均衡）
- [ ] 售后：李守耀在岗 = 值班负责人（黄 `#FFFF00`）；其余售后当班（蓝 `#BDD7EE`）
- [ ] 颜色只用于约定含义（白 `#FFFFFF` = 无标记）；读取时用 `getAppliedXf`

## 五、特殊标记与休假

- [ ] **年假不主动排**（客服自己申请）；休息格直接记空白，用剩余假
- [ ] 「行」/公休（橙 `#FBE5D6`）只落在休息格，且与实际一致
- [ ] 月份标记等非员工行不参与员工统计
- [ ] 备注写清每人休息构成（如：休 6 天 = 本月 5 天 + 上月剩余 1 天）

## 六、数据与统计

- [ ] 日期、星期、当月天数（28/30/31）正确
- [ ] 统计公式已按当月天数调整（空白格统计覆盖全月）
- [ ] 剩余 = 上月剩余 + 应休 − 实休，逐人核对（含小时折算/负数）
- [ ] 年假/休息/早班/晚班/实到/应到 与明细一致；小计 = 明细之和
- [ ] 每日汇总（早/晚/休）与「上班人数」与矩阵一致
- [ ] xlsx 与 TSV 同步导出

## 七、制度

- [ ] 调班必须有人顶班，否则只能算请假
- [ ] 连休 ≥3 天已报经理；请假提前 ≥24 小时；离职提前 ≥30 天
- [ ] 上月表已设置「本月已经结束~」数据有效性提示（月底收尾）


3. **全部打勾才算排好**；有不过的项回炉重排，改完从「〇、跨月衔接」重新验一遍。
