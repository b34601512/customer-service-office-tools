# 反例表（证明校验工具真的能抓到错）

`验排班表.py` 说"全部通过"时，得先证明**它抓得到错**。这里放几张故意做坏的表，用来做回归测试：
工具升级后重跑一遍，该抓的一个都不能漏。

| 文件 | 做法 | 期望结果 |
| --- | --- | --- |
| `bad.xlsx` | 统计/汇总/小计/上班人数**全写成数值**（老式表），并植入 5 处错 | **14 项 ✗**：韩欢欢晚班=99、10 人应到=24（政策应为 25）、售前早班汇总 d1=3、上班人数 d5=9、售前小计休息=30 |
| `bad2.xlsx` | 公式/口径改坏：`AK4` 休息不引用「本月天数」、`AJ4` 年假写成本月计数、`AO4` 应到写数值、`AK9` 小计写死、`AM19` 本月天数写死 30、`E26` 上班人数写死 | **5 项 ✗**（含“年假写成了本月计数”） |
| `bad3.xlsx` | 售后把当班每个人都涂浅蓝（当班≠值班） | **2 项 ✗**：售后早班/晚班浅蓝超过 1 人 |
| `bad4.xlsx` | 结转列写错：`AI4`/`AI8` 剩余不按「上月结转 + 应休 − 实休」、`AJ6` 年假余额被清零 | **2 项 ✗**：剩余与口径不符（年假清零要靠 `--prev` 比上月才能判，见下） |
| `month30.xlsx` | 清掉 31 号整列，模拟 **30 天的月份** | 读成 **30 天**、公式结构照过、自动项**全部通过** |

⚠️ 反例表是 `openpyxl` 重新生成的，公式格**没有缓存值**（正常；真表由 `工具/写排班表.py` 写，带缓存值）。
⚠️ 剩余/年假结转要带 `--prev` 才会自动对账（不带时只提醒）。

## 怎么用

```powershell
cd "D:\桌面\办公软件\21.AI自动排班经验"
$PREV = "D:\桌面\办公软件\1.客服超时督办\runtime\schedule-query-snapshot\2026-09-12-2026年9月.tsv"

python "工具\验排班表.py" --xlsx "测试数据\反例\bad.xlsx"  --prev $PREV --lead 李守耀   # 期望 14 项 ✗
python "工具\验排班表.py" --xlsx "测试数据\反例\bad2.xlsx" --prev $PREV --lead 李守耀   # 期望  5 项 ✗
python "工具\验排班表.py" --xlsx "测试数据\反例\bad3.xlsx" --prev $PREV --lead 李守耀   # 期望  2 项 ✗（售后每班多人标值班）
python "工具\验排班表.py" --xlsx "测试数据\反例\bad4.xlsx" --prev $PREV --lead 李守耀   # 期望  2 项 ✗（结转写错）
python "工具\验排班表.py" --xlsx "测试数据\反例\month30.xlsx" --lead 李守耀            # 期望全过（30 天；不带 --prev）
```

再配合 `工具\对比排班表.py` 做"A 改前 / B 改后"的对拍：

```powershell
python "工具\对比排班表.py" --a "测试数据\反例\bad.xlsx" --b "测试数据\2026年10月客服排班表.xlsx"
```

## 怎么重建

主表改了以后（例如换了月份/人数），这些反例会过时。重跑生成脚本即可，它从
`测试数据\2026年10月客服排班表.xlsx` 复制后按固定规则破坏：

```powershell
python "测试数据\反例\造反例.py"
```

> xlsx 按仓库约定不入库（`.gitignore` 排除 `*.xlsx`）：反例靠这个脚本随时可造，别只留文件。
