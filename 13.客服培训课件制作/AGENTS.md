# AGENTS.md — 13号 客服培训课件制作（AI 自动读取）

> 本文件仅在本目录（及其子目录）工作时生效。新链路优先；旧方法见「历史资料备份」。

## 本目录是什么

客服培训课件制作。**新做法 = 流水线**：取数全自动（程序），AI 只做"解析内容"，渲染与自检由程序完成。

## 新链路（优先，三步）

```
1. 程序取数：双击「启动课件制作助手.bat」→
   主菜单 1 从京东抓取 / 2 导入聊天记录 → 得到 runtime/chat/<基名>.chat.json
2. AI 产出解析：读该聊天记录 + 场景意图，按
   「给AI的解析提示词模板.md」写出 runtime/review/<基名>.review.json
3. 程序出片：主菜单 3 生成课件 → runtime/outputs/<月份>/<文件名>.html + 铁律自检
```

- 程序入口/文档：`README.md`
- **AI 做步骤 2 时**：只填可变内容（挑点、点评、建议话术），输出严格 JSON 契约；样式与自检程序负责。
- AI 也可不经 TUI，直接调用 `src/services/*`（同一套业务真源）完成取数/生成，供无界面自动运行。
- 铁律（就地解析、无目录、无结尾总结卡、客户ID脱敏+眼睛按钮、图片内嵌、去姓名）见 README「铁律速览」与「给AI的解析提示词模板.md」。
