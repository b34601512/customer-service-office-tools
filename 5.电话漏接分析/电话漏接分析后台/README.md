## 使用方式

1. 双击项目根目录的 `一键启动.bat`。
2. CLI 启动后直接进入全屏界面，菜单：`1呼入 2呼出 3呼损 4客服 5趋势 6月总览 7下载 8配置 9退出`。
3. 选择“下载”页按回车，程序会在后台使用独立浏览器登录原系统并下载呼损、呼入、呼出三份报表。
4. 呼入 / 呼出 / 呼损 三个页面把下载的原始表逐列原样展示（↑↓选择、PgUp/PgDn 翻页、回车看单行完整详情）；呼入、呼出额外带“映射姓名”列，按座席映射表换算。
5. 选择“退出”或按 `Ctrl+C`，程序会清理本工具打开的浏览器和后台线程。

## 主要功能

- 呼入明细：原始呼入表，列含呼入/挂断时间、主叫、DID、组、座席分机、座席姓名、各段时长、归属地、满意度调查、映射姓名。
- 呼出明细：原始呼出表，列含呼出/挂断时间、主叫、被叫、组、座席分机、座席姓名、振铃/通话时长、归属地、映射姓名。
- 呼损明细：原始呼损表，列含来电时间、IVR/排队停留、队列号、丢失位置、归属地、DID、来电号码、处理时间/人/状态。
- 客服统计：综合、呼入、呼出、外呼质量排行与对比。
- 趋势分析：近 30 天呼入、呼出、IVR 呼损、排队呼损，每天一行的趋势条。
- 月总览：按月份汇总呼入、呼出、合计与呼损，回车查看当月每日明细（呼入=呼入明细条数，不含呼损；合计=呼入+呼出；呼损另计）。
- 配置管理：下载配置、座席分机映射（支持 `分机1,分机2=姓名` 一次新增多个）、投诉座席分机、判断口径。

## 核心口径

- 呼损 / 呼入 / 呼出三页展示的是下载的原始表数据，不做任何分析聚合；完整字段在回车后的单行详情里。
- 呼入、呼出表的“映射姓名”= 按座席映射表把座席分机换算成姓名，未配置时保持原座席姓名。
- 投诉座席分机（配置里 receiverPhones）决定哪些被接听的呼入算投诉电话，分机号在本地 complaint_config.json 中维护，不入库。
