# 金山筛选日期回车默认数据最新日

## 意图

金山透视筛选日期留空回车时，自动采用本地“数据明细”的最新“统计结束日”；填写日期时仅采用用户填写的自定义日期。

## 背景

当前 TUI 和旧 CLI 都把日期设为必填。历史版本曾把“电脑当天日期减两天”当作“最新”，但它不以实际数据为依据，已被移除。本次应复用汇总表读取链路已经计算出的最大“统计结束日”，不恢复系统日期推算，也不修改在线 AirScript。

## 验收清单

- [x] 留空回车会读取本地“数据明细”的最新“统计结束日”。
- [x] 填写合法 YYYY-MM-DD 时使用自定义日期，且不读取默认日期。
- [x] 非法自定义日期仍会被拒绝。
- [x] TUI 与旧 CLI 提示均明确“回车=数据最新日期”。
- [x] 金山同步定向测试与完整测试通过。

## 边界

- 不用电脑当天日期或配置日期冒充数据最新日期。
- 不在 TUI、旧 CLI 各自复制业务规则；统一由金山筛选业务入口解析。
- 不增加兼容分支、强制兜底或第二日期真源。
- 不修改在线 AirScript，避免要求用户重新粘贴脚本。
- 不覆盖当前工作区其他 AI 或用户的未提交改动。

## 验证记录

- 金山同步专项测试通过。
- 完整 `npm test` 的 13 个测试脚本通过。
- 当前本地汇总表只读核对：共 90 行，最新“统计结束日”为 `2026-08-30`，共 90 行属于该日期。
- `git diff --check` 通过；未修改在线 AirScript 模板。
