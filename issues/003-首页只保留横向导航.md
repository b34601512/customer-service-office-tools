# 首页只保留横向导航

## 意图

删除总览页重复的纵向“快捷操作”菜单，只保留顶部横向分页导航，让首页专注展示状态。

## 背景

“开始汇总”“强制重新下载”“金山文档同步”已有顶部横向页面入口；纵向快捷操作造成重复。三个文件夹入口没有替代入口，迁移到“设置”页，避免为了精简首页而丢失功能。“0 退出”改为全页面统一快捷键，不再依附首页菜单。

## 验收清单

- [x] 总览页不再显示纵向“快捷操作”。
- [x] 顶部横向六页导航保持不变。
- [x] 汇总、强制重下、金山功能仍由对应横向页面提供。
- [x] 三个文件夹入口迁移到“设置”页且可执行。
- [x] `0` 在任意页面均可退出。
- [x] TUI 定向测试与完整测试通过。

## 边界

- 不删除现有功能，只整理入口归属。
- 不在总览页保留隐藏选择状态或失效处理分支。
- 不修改旧 readline CLI 的菜单。
- 不覆盖当前工作区其他 AI 或用户的未提交改动。

## 验证记录

- TUI 专项测试通过：总览无纵向菜单、设置页三个文件夹服务可调用、非首页按 `0` 可退出。
- 完整 `npm test` 的 13 个测试脚本通过。
- `git diff --check` 通过。
