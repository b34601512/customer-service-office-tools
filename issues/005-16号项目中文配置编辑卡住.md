# 16号项目中文配置编辑卡住

## 意图与背景

朋友反馈 v9 修改城市、岗位后界面不响应，页数可改；截图停在城市编辑状态。
已完整阅读 TUI 的输入、分发、编辑、渲染和启动清理链路。配置提交仅修改内存，无联网等待。
旧循环混用 CRT 的 kbhit（内部 PeekConsoleInputA）和 getwch；后者阻塞读取，扩展键还会二次读取，Esc 使用限时拼接。
本机隐藏控制台注入普通中文暂未复现朋友原始卡死，不能据此声称已确认其机器上的唯一触发原因。

## 方案与边界

统一使用 Windows Unicode 输入事件：先检查事件数，再读取已到达事件，直接区分虚拟键和文字。
移除旧 CRT/转义序列输入路径，不增加后台输入线程或并行真源；不改采集业务，不操作登录浏览器。
保持回车保存、Esc取消、页数/格式调整、Ctrl+C退出，退出恢复控制台模式。
