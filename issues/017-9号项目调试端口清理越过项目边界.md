# 调试浏览器关闭范围未限定当前项目

意图：只关闭当前客户端拥有的采集浏览器。
背景：端口守卫只检查调试端口标志，可能关闭另一个目录启动的调试浏览器；记录的 PID 未核对命令行归属；含空格的目录参数引号可能使原匹配失效。
方案：端口清理同时要求当前项目资料目录；关闭记录 PID 前确认其归属；命令行匹配统一忽略 Windows 参数引号。

- [x] 不属于本项目的记录 PID 不执行关闭或 taskkill。
- [x] 端口清理只接受本项目命令行匹配出的 PID。
- [x] 通过依赖注入测试，不操作真实浏览器。

2026-09-05：模拟监听PID111/222、归属仅222，关闭调用仅命中222；记录PID111不属于本项目时不调用主窗口关闭或taskkill。独立包回归通过。
