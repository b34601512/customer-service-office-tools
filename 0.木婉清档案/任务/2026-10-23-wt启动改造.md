## 二、怎么改（不许改变原行为）

1. **保留原脚本内容**，把它改成「内层」，外层再套 wt：
   - 复杂 .bat（10/12/16/18 有大量 setlocal / where 检查 / 内嵌 PS 载荷）：**改成 wt 里跑 `cmd /c "<原 .bat 文件名>"`**，不要把原逻辑拆散重写。
     ```bat
     @echo off
     chcp 65001 >nul
     start "" wt.exe -M -d "%~dp0." cmd /c "%~nx0"
     ```
     ——这条不能直接原地改（会自调用成环）：**把原文件改名为 `原名-内部.bat`，新 `原名.bat` 就是上面这 4 行，指向 `原名-内部.bat`**。
   - 简单 .bat（8/11）：命令就一条，直接 `start "" wt.exe -M -d "%~dp0." <那条命令>`，原文件即新文件，不留副本。
2. **相对路径全部靠 `-d` 指定工作目录**，原 .bat 里的 `cd /d "%~dp0"` 保留在内部脚本里不动。
3 每个文件顶部写一行注释：`rem 用 Windows Terminal 起（老板 2026-10-23 要求，统一外壳）`。
4. Windows 上 `wt.exe` 一定存在（本机已装，1号 在用）；**加兜底**：`where wt.exe >nul 2>nul || (echo 需要 Windows Terminal & pause & exit /b 1)`。
