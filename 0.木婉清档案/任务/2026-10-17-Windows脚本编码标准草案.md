## 一、一句话规矩

**`.bat/.cmd` 只当纯 ASCII 启动器，中文全部下沉到 `.ps1`（UTF-8 带 BOM）；`.vbs` 一律 UTF-16LE 带 BOM；换行全用 CRLF。**

## 二、四种文件的标准（照这个存盘）

| 类型 | 编码 | BOM | 换行 | 中文 | 备注 |
|---|---|---|---|---|---|
| `.bat` / `.cmd` | **纯 ASCII** | ❌ 绝对不要 | **CRLF** | ❌ 一个都不要 | 只做「调 ps1」的启动器；**文件名可以中文** |
| `.ps1` | **UTF-8** | ✅ 必须带 | **CRLF** | ✅ 中文都放这 | 开头加下面「三件套」 |
| `.vbs` | **UTF-16LE** | ✅ 必须带 | **CRLF** | ✅ 可以 | WSH 只认 UTF-16LE / 本机 ANSI |
| `.js/.mjs/.cjs/.json` | UTF-8 | ❌ 不要 | 随意 | ✅ 可以 | Node 自己处理；BOM 会让部分解析器报错 |

`.ps1` 开头固定三件套（否则控制台中文照样乱）：

```powershell
& chcp.com 65001 > $null
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding           = [System.Text.Encoding]::UTF8
```

`.bat` 启动器骨架（纯 ASCII，中文注释都不要）：

```bat
@echo off
rem Launcher ONLY. Pure ASCII (no Chinese, no BOM), CRLF.
chcp 65001 >nul
cd /d "%~dp0"
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0launcher.ps1"
if errorlevel 1 pause
```

> ⚠️ `.bat` 里别写**中文的脚本文件名**（那也是中文字节）。ps1 用英文名（`launcher.ps1`），bat 自己叫什么中文名都行。

## 三、为什么要这么定（实测证据，不是传闻）

| 组合 | 结果 |
|---|---|
| `.bat` **LF** 换行 | ❌ 行被拼错、中文被拆成伪命令（`'5001' 不是内部或外部命令`）；挂计划任务会「成功但什么都没跑」 |
| `.bat` UTF-8 **带 BOM** | ❌ `'﻿@echo' 不是内部或外部命令`（BOM 粘进了 @echo） |
| `.bat` 中文进了 `goto` / `call :` / `set 变量名` | ❌ 必坏（`goto 结束` → `'结束' 不是内部或外部命令`）；**所以「中文 bat + chcp 65001」这条老配方不成立** |
| `.bat` 中文只在 `echo` 里 | ⚠️ 本机能跑，但换机器/换代码页就乱 → 不合标准 |
| `.ps1` UTF-8 **无 BOM** 且有中文 | ❌ 按 GBK 读 → `字符串缺少终止符` 解析报错（本机实测） |
| `.ps1` UTF-8 带 BOM | ✅ 正常（LF/CRLF 都能跑，标准统一 CRLF） |
| `.vbs` UTF-8 **带 BOM** | ❌ `无效字符`（第 1 行第 1 列） |
| `.vbs` UTF-8 无 BOM + 中文 | ❌ `未结束的字符串常量` |
| `.vbs` UTF-16LE（带/不带 BOM） | ✅ 正常（标准要求带 BOM） |

**注意**：中文 Windows 上这些报错本身也显示成乱码（如 `'?@echo' 不是内部或外部命令`），
别被乱码骗了——真实原因是 BOM 进了命令行，不是「中文没编码好」。

## 四、写脚本前后各做一次：一键自检

工具（现成，已实测）：`D:\桌面\木婉清\20.经验库\Windows批处理中文乱码修复\工具\检查脚本编码.ps1`

```bat
rem 只检查（可给文件、也可给整个目录）
powershell -NoProfile -ExecutionPolicy Bypass -File "检查脚本编码.ps1" "D:\我的项目"

rem 连目录一起扫 + 自动修能机器修的那些（改前自动备份 .bak-时间戳）
powershell -NoProfile -ExecutionPolicy Bypass -File "检查脚本编码.ps1" -Fix -Recurse "D:\我的项目"
```

- 它按上表逐条判「合格 / 不合格 / 提醒」，并说清病因；
- `-Fix` 能修：ps1 补 BOM、vbs 转 UTF-16LE、bat 去 BOM、全部转 CRLF；
  **修不了的（bat 里的中文、GBK 编码的旧脚本）只报不动**——绝不把内容写成问号；
- 退出码：`0` 全合格 / `1` 有不合格 / `2` 参数错（可直接进 CI 或计划任务）。
