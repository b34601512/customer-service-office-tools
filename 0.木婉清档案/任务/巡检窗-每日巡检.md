# 任务：巡检窗 · 每日巡检

> **本窗由计划任务 `muwanqing-patrol-window` 每天 9:00 自动拉起**（不是监听窗；监听窗只负责跟黎路遥沟通——2026-10-10 他定的分工）。
> 干完 → 写回执 `0.木婉清档案/任务回执/巡检窗-每日巡检.md`（覆盖写）→ 守卫自动关窗。
> 大活儿可在本窗开编排带帮手（≤8）；别开一堆窗。

## 契约（任务窗通用）
- **只写回执**：不发企微、不提交 git（汇报走监听窗 / 看门狗）。
- **省额度**（黎路遥 2026-10-10 定）：只读必要文件；不做探索性大扫描；不确定就停下、把问题写进回执。
- 失败不自动重试；先定位原因；现场（哪一步 / 报错原文 / 页面地址）写进回执。
- 必须让路遥知道的（红线 / 需拍板 / 故障）：**在 bot-board 发一条 `[需要帮助]` / `[通知]`**（Grok / 赵敏 看到会转达；不要直接发企微）。

## 本窗的注册与重建（本机计划任务）
```powershell
$taskName = 'muwanqing-patrol-window'
$node = 'C:\Program Files\nodejs\node.exe'
$launcher = 'D:\桌面\木婉清\0.木婉清档案\开任务窗.cjs'
$taskFile = 'D:\桌面\木婉清\0.木婉清档案\任务\巡检窗-每日巡检.md'
$workDir = 'D:\桌面\木婉清'
$action = New-ScheduledTaskAction -Execute $node -Argument ('"' + $launcher + '" "' + $taskFile + '" "' + $workDir + '"') -WorkingDirectory $workDir
$trigger = New-ScheduledTaskTrigger -Daily -At '09:00'
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -StartWhenAvailable -MultipleInstances IgnoreNew -ExecutionTimeLimit (New-TimeSpan -Minutes 10)
Register-ScheduledTask -TaskName $taskName -Action $action -Trigger $trigger -Settings $settings -Description '木婉清巡检窗：每天 9:00 自动开任务窗跑日常巡检（频道/看门狗+探域例检）；回执落地自动关窗' -Force
```
（本机副本：`0.木婉清档案/runtime/巡检窗注册.ps1`）
