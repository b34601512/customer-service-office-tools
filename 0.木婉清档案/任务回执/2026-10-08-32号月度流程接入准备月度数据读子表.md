## 二、新读法口径（fail-loud，禁止猜）

1. **读**：`店铺主体对照.cjs` 的 `读对照`（AirScript 只读）→ 62 行 5 列：源表店铺名 | 目标表店铺名 | 主体 | 是否进主体子表 | 备注。
2. **建映射前本地守卫**（不过就停，一个字节都不出）：必须 5 列 / 源店铺名非空 / 目标店铺名非空 / 主体在白名单或空 / 「是否进主体子表」以 是/否 开头 / 「是」只能配两个子表主体 / 一店一行 / 行数对不上视为截断。
3. **出数据时**：源表店铺名查映射——**找不到 → 抛错**；**主体列为空 → 抛错**（不退回硬编码、不跳过该店继续）。
4. **进子表**：「是」才进对应主体子表；`否（无子表）` **只进汇总**（M 列照写主体）、不进任何主体子表；`否（无主体）` 主体空 → 第 3 条先停下。
5. **对账门（默认开）**：本批**出现过的店铺**逐一比较「读表结果（新）vs 原硬编码结果（旧）」；**有差异 → 抛错停下、不产出批次文件**；差异 0 → 提示可切换；人工确认后用 `--对照 子表` **显式切换生效**。
