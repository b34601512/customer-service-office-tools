## 五、踩到的坑（第二步要带着走）

1. **企微 url 字段不认纯字符串**：写 `"https://…"` 会被**静默丢掉**（不报错、回读也没有），必须写 `{link:"https://…", text:"展示文字"}`。第一次灌数 226 行全丢来源地址，补写后才 0 差异。
2. **命令行参数上限**：226 行整包 JSON 约 80KB，`spawn` 直接 `ENAMETOOLONG`；必须按 ~24000 字节切块（本次切 5 批写、3 批补）。
3. **日期量纲**：源表 `采集日期` 是 Excel 序列号，不能直接当日期写。
4. **百分比量纲**：源表按真值小数存（0.8704 = 87.04%，单位列 `%`）；本表一列混多种单位，所以用 `number` 原值，**绝不能用 `percentage`**（否则再乘 100）。
5. 企微 CLI 的 `-o` 文件必须事先不存在；业务错误常是「退出码 0 + errcode 非 0」，必须校验响应体。
6. 写完立刻回读可能读不到 url 的 `link`（本次回读解析把 `text` 当成了值），回读解析要优先取 `link`。
