# 任务回执 · 修 写同单备注.js 状态=undefined（2026-10-06）

## 根因（不是抖动，是判据字段不存在）
- 本地脚本改前最后两行（`scripts/写同单备注.js`）：
  ```js
  console.log(`\n  写同单备注：状态=${结果 && 结果.status}`);
  ...
  if (!结果 || 结果.status !== "已写入") process.exitCode = 1;
  ```
- 云端写入脚本（独立脚本 **v2026-09-30.16**，`执行写入()` 的 return 原文）**根本没有 status 字段**：
  ```
  { scriptVersion, mode:'write', sheet, duplicate:false, written:true, row, requestedRow,
    orderNo, writtenColumns:['S'], dateColumns:[], failedColumns:[], readBack:[...] }
  ```
  失败分支才是 `{ ... mode:'write', written:false, message:'指定行 J 列是别的订单号…' }`（或目标行已有单号 / 缺少 allowWrite）。
- 所以成功时 `结果.status` 恒为 undefined → 打印「状态=undefined」+ 退出码 1；**实际已写入**（10-05 起 4 次复现全是这个）。
- 只读探针确认两表部署的都是 v2026-09-30.16：`write`（德达--毛叶红）/ `write_jituan`（科技--唐雪梅）均为 `scriptVersion=2026-09-30.16`。
