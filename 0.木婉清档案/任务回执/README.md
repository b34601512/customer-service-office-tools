# 任务回执

任务窗（`0.木婉清档案/开任务窗.cjs` 派出去的窗口）干完活后，把回执写在这里：文件名 `日期-任务名.md`。

模板（照抄改成自己的内容）：

```text
# 任务回执 · <任务名>（YYYY-MM-DD）

- 任务：<一句话>
- 结果：完成 / 失败 / 部分完成
- 执行：任务窗（非监听窗）；只动 <哪些目录>；是否碰了 git（默认不碰）

## 做了什么（逐条，带证据）
- …改/读了哪些文件、跑了什么命令、测试结果、日志路径

## 建议提交的文件清单
- <相对路径>（为什么）

## 风险与遗留
- 无 / 具体风险 + 需要谁拍板

## 下一步（一个动作）
- …
```

规矩：
- 任务窗**不提交 git**（把"建议提交的文件清单"写进回执，主窗复核后提交；防平行会话互相吞改动）。
- 真实发送/写入类动作按任务书授权办；没写授权就**先问**（企微发消息本身按任务书要求做）。
- 失败写清现场（哪一步、报错原文、等了多久），照根 `失败台账.md` 的口径；**不自动重试**。
