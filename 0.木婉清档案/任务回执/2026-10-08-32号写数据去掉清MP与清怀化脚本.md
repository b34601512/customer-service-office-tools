## 二、「清怀化登记」脚本干了什么（四道锁 + 报数）

- **探针（只读）**：报两张主体表 M~P 现状——数据末行、哪几行非空、每格内容摘要（含公式/原长）；还会报「**数据末行之后**的非空行数」（就是上面那种尾巴）。
- **清怀化登记（写）**：只清 M~P（M=13~P=16 四列）；缺省行域 = 第 4 行~数据末行（透视锚点前）；四道锁：
  1. **表名白名单**：只认 集团 / 器械 / 全部（传「汇总」都拒绝）；
  2. **确认文本**必须**一字不差**「清空怀化工厂登记」（服务端不再 trim，尾随空格也拒）；
  3. **只允许动 M~P**：脚本只会对 M~P 构造 Range，每个改表地址都过列守卫；越界直接判失败、**一个格都不清**；
  4. **行域守卫**：起 ≥4、止 ≥起、≤200 行、且不越过透视锚点（无透视时 ≤120 行）；格式错/碰表头/越界都拒绝。
- **清前快照**：清前把 M~P 原文（值/公式）**读进返回值**，客户端先落盘 `2-清前快照.json` 并打印路径（人看得见「抹掉的是什么」）。
- **清后回读**：报「清了多少格 / 还剩多少非空」；清不干净 → `清空完成:false` → 顶层 `written:false`。
- **失败不重试**；不给 `allowWrite:true` → 一个字节都不清。

关键断言逐条对上任务要求：
- **① 清理范围只能是 A4:L**：`深等于(记录.清空, ['A4:L19'])` / `['A4:L12']` + 地址全匹配 `/^A\d+:L\d+$/` + 写完后 M~P（第 4 行整行、16/19 行抽查）**原值仍在**；回执 `清范围='A4:L{末}'`。
- **没对 M~P 调过 ClearContents（反向）**：清怀化测试的假表带「**越权清空即抛错**」硬保护（对 A~L 或其它的 ClearContents 直接报错）；同时断言清空地址全为 `/^M\d+:P\d+$/`、值写入 0、格式事件 0。
- 清怀化守卫：无 `allowWrite` / 错确认（含尾随空格）/ 错表名（含「汇总」）/ 坏行域（`3:6`、`6:4`、`4-6`、`4:250`、`4:999`）→ **全部拒绝且零 ClearContents**。
- 快照必带：服务端返回值带 `清前快照.明细` 原文；客户端校验「没带快照 ⇒ 判失败」。
- 回读报数：共 X 格 / 清后非空数 / 清掉数 / 清后剩余明细；`清空无效` 假表下 `清空完成:false`、顶层 `written:false`。
- **反向断言**：只回 `status:'已写入'` 无 `written:true` 必判失败；`written:'true'`（字符串）也判失败；清空完成=false 必判失败。
- 客户端：`--预演` **零请求**（注入的调脚本 0 次调用）、请求失败只发 1 次（不重试）、缺 `--确认` 客户端先拦（零请求）、`--表 集团` 只校验集团。
