## 改法（改前/改后片段）+ 为什么这样写
抽出纯函数 `拆行数据()`（就放在 `读一行()` 上面）：

```js
// 【v2026-10-06.17】单行 Range 的 Value2 是**二维数组**（形如 [[列A值, 列B值, …]]）；一维/标量兜底。
//   ⚠ 拆层必须是这个纯函数：单测 tests/云端读一行.test.js 直接把它从本文件里取出来跑；别再内联回去。
function 拆行数据(值) {
  var 第一层 = (值 instanceof Array) ? 值 : [值]
  return (第一层[0] instanceof Array) ? 第一层[0] : 第一层
}
```

`读一行()` 只改一行：

```diff
- var 行数据 = (值 instanceof Array) ? 值 : [值]
+ var 行数据 = 拆行数据(值)
```

另外：版本号 `2026-09-30.16` → `2026-10-06.17`（粘完用探针一眼确认新版生效），文件头版本注释与 v2026-10-06.17 变更说明同步更新。

为什么这样写（禁等号约束下）：
- 金山 AirScript 编辑器粘贴时会吃 `==`/`===`，所以这个脚本**代码里不用等号比较**。这里用 `instanceof Array` 判数组、三元 `? :` 取值 —— 与文件里既有写法一致，也与 `AirScript-脚本大全-写入.md` 里早就正确的同款拆层写法一致；新增代码零等号比较。
- 形状覆盖：`[[A,B,…]]`（金山单行真实形状）→ 取内层；`[[行1],[行2]]`（多行）→ 取第一行；`[A,B,…]`（一维）→ 原样；标量 → 包成 `[值]`；`null` 在调用前已有 `if (!值) return []` 兜底。
- 只动"读回拆层"这一处：写入 `写单元格` / `写日期单元格` / 查重 / 公式列红线（T 列等）一行没碰。
