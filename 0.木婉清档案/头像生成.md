# 木婉清的头像（纯代码生成）

纯代码生成**木婉清**的头像：零依赖、零图片素材，只用 Node 标准库（PNG 由 `zlib` + 手写 CRC32 编出来）。

- `assets/头像-750.png`：**750×750**，可直接当头像用。
- `assets/头像-250.png`：250×250 小图。

## 怎么画的

- **一体成型**：整张画只有一套 50×50 像素（×15 = 750），人物和夜景画在同一尺度上，没有"小头像贴大背景"。
- **人物**是手绘像素图 `LEFT`（只画左半边 25 列 × 50 行，程序镜像成 50 列）——五官绝对对称，不会斗鸡眼；肩胸一直画到画框底边，不留横向断口。
- **不对称零件**（发带飘带、背剑）放 `RIBBON` / `SWORD` 两个叠加层，镜像做不出来。
- **背景**：夜空渐变 → 月与月晕（带月面暗斑）→ 星点、两抹薄云 → 远山两重 → 左下松影 → 底边薄雾（只上在人物之外）→ 四角暗角。
- **复古感全靠抖动**：明暗过渡一律用 4×4 Bayer 有序抖动，不写渐变。

```powershell
cd tools
node gen-avatar.mjs                 # 750×750 + 250×250
node gen-avatar.mjs --size 250      # 边长（须是 50 的倍数）
node gen-avatar.mjs --preview       # 打印 50 行字符预览（调画用）
```

## 改样子

- `P` 色板；`LEFT` 人物像素画（每行必须 25 字符，写错当场报错）；`RIBBON`/`SWORD` 叠加零件；`paintSky` 里的月/星/山参数。
- 想调脸：`K` 描边、`d` 发亮、`F/S/s` 肤亮中暗、`x` 腮红、`W/E/e/G` 眼白/瞳/瞳亮/眼神光、`B` 眉、`M/m` 唇、`C/c/b` 衣亮中领。

产物 png 落在 `assets/`，按 `.gitignore` 图片不入库，仓库只存生成器（`tools/gen-avatar.mjs`）。
