## 十、文档与清理（现行规矩，黎路遥 2026-10-24 首定、2026-10-25 升为六条、2026-11-04 补第 7/8 条；**日常随时做，不是定时环**）

**八条**（一条一句，细则不写历史）：每条都要写明**为什么**（不这么做会真出什么事）；写「谁说的」不算理由（黎路遥 2026-10-24：引老板没意义，老板说的不一定对，**关键是为什么要做**）。
1. **一个文件只说一件事**：别把内容揉到一个文件；每次要用只读那一个文件（上下文隔离）。真人公司专人专岗也是同一个道理——每次只加载需要的那块。
2. **过时的真删，不划删除线、不写「旧写法作废」**，只保留最新思想；要查历史走 git。留着旧内容＝每次读都白烧 token，还会误导自己或同事；被否方案的原因用一句话写进现行那条，不另留残骸。
3. **要复用的留本地，不用的归档，没做完的进 GitHub issue**（新待办也走 issue，办完主动关）。堆积＝下次又要重读一遍，还会反复重问。
4. **内容/功能一致的只留一份**，其他人索引；通用工具一套，改一次全公司生效。同一口径写两处＝改一处必漏另一处。判据一句：**「换个人来干还用得上吗」——用得上就是通用**，进共享区；个人岗位独有的经验留自己档案，不往共享抄、也不互相抄。
5. **规则文件必须写「为什么」**：知道为什么，才不会曲解成另一个意思；引「老板说的」不算理由。
6. **垃圾文件＝不需要二次复用的文件，但必须人工一个个删，禁止程序化自动清理**（会误删）。
7. **自己的 AGENTS.md 只写自己的职责和「什么问题找谁」**，不写别人负责的项目经验；**不超过 25k，超了就压缩**，砍掉旧的只留最新思想（为什么：别人的活儿我读了也用不上，白烧 token；文件太长每次开机都要重读一遍旧账，抓不住重点）。
8. **反复要用的能力做成工具包，不是零散脚本；模型只调 API/命令**（为什么：每次临时拼一遍，写法全靠临场发挥，质量参差、同一个坑反复踩；做成工具后改一处全公司生效）。选路顺序：**API/HTTP 直调 > CLI 命令 > 浏览器 DOM/Playwright**。

**清理范围（他叫清理时按这个，不是定时环）**（黎路遥 2026-11-04 16:3x 问「内容是这个吗」）：
- 管 1（拆一件一事）、2（真删过时）、3（归档/未完成进 issue）、4（口径只留一份）、6（垃圾文件人工删）、7（AGENTS 超 25k 压缩）——都是**改文件/归档/删**的活。
- **不管 5**（规则文件要写为什么）：那条是**写规矩、写新条目时**的要求，不是清理时干一次的活。
- **不管 8**（工具包/只调 API）：那条是**动手做活时**的要求——每次要临时写的东西，先想「能不能收成工具」；不在清理里执行。
- 清理**只动本地文件，不发任何消息**；没变化就静默，不打扰人。

**落法**：
- **总索引** `0.木婉清档案/索引.md`（一屏以内，**只放指针不放正文**）；**项目索引**每个项目一份（`<项目>/项目索引.md`）＝开工先看：规矩/口径、经验/踩坑、常用命令、红线。
- **流水账**（任务书/回执这类「新窗口不会去读的」）→ 按分类/按月归档进 `任务/归档/YYYY-MM/`，留 `索引.md` 指路；**必读件里只留「在办 #号 + 一句话」**。
- **历史决策流水**（「10-09 改 X、10-11 改 Y」）只留现口径那句，过程删；**过时口径/作废方案/过期数字直接删正文**，只留「为什么有这条」一句（做不到会出什么事）；要查哪天谁定的走 git。
- **清理时把要复用的抽成《XX规范》/《XX经验》**（每个项目一套，如 `7号/发票登记规范.md`，新口径只进这一份），只有一次性的才留在流水账里。
- **节奏**：清理不定时——他叫才做（2026-11-06 停 08:20 环）；平时改文件随做随清。开工先看总索引 → 再进项目索引；聊到某话题主动翻对应笔记。判断标准：**每次必读的要一眼扫完，偶尔才查的（台账/验收/归档）才允许长**。
- **拆文件前先问两件**（2026-10-23 小昭/焦宛儿同一结论）：① 是不是母版铺下来的成品（是 → 别拆，改真源，`工具/企微/boot-prompt.md`、各家 `README.md` 这类）；② 里面混了几件事（只有一件事 → 文首加「一页速查」，不硬拆）。都不成立才拆，拆完原处留指针。
- **红线允许在「必读件」里各存一行**（有意例外，别当重复清掉）：`AGENTS.md`、`规矩与红线.md`、`工具/企微/boot-prompt.md` 各有一行「天猫待同意不点」这类红线。为什么允许：开机那几秒就要能把红线拦住，如果要串三个文件才读到，就会出现「还没读到就已经干了」；代价只是一行。**但只能是一行**——把正文、解释、判据抄过去就算违规，改口径只改 `规矩/` 里那份。
- **「用不上」≠「可以删」**（钟灵/王语嫣 2026-10-23）：被启动单、体检工具按**文件名**认的东西（`守护.mjs`/`直连.mjs`/`环.cjs` 这类）留着，删了会报缺件、又被当成故障。
