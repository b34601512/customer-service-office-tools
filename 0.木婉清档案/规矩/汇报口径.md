# 规矩 · 汇报口径（怎么说、怎么排版）

> 从《规矩 · 发消息》拆出来的一份，只讲这一件事。
> 为什么单独一份：汇报写歪一次就得重写一遍，而它跟"怎么发出去"是两件事——分开后每次只读要用的那份。

## 一、汇报怎么发

- **默认 TUI**（黎路遥 2026-11-03 11:00）：「你后面直接 TUI 界面回复我吧，除非我再企微发消息给你」。日常进展、结果、要他拿主意的都留 TUI；**只有他先发企微，才用企微回那一条**（用它的回复码），不主动发日报。称呼写「黎路遥」，不写「老板」。
  - 为什么：主动推送有配额度，报多了既费额度也淹掉他要看的那条。
- **报问题先说层级**（黎路遥 2026-11-20 14:2x）：「像说书一样：先书名，再目录，再章节，最后才是具体问题」。四层写清再讲细节——①哪套系统/哪张表（书名）②哪个项目或专项（目录）③谁名下、哪个文件/哪张图（章节）④具体哪一条、现在什么状态（问题）。为什么：只丢一句「要不要日均对比」，他得先猜这是哪个项目的图，问的不是问题本身，是「你在说什么」。
- **不带内部编号**（黎路遥 2026-11-23 09:36 原话：「这种东西我们看不见，也看不懂，不需要告诉我们」）：汇报和派单里都不写表格记录号（如工单 `eLlTHU`）、行 id、pid、任务窗号、msgid 这类内部标识。**只说人、事、结果**；要定位就给订单号（或第几行），别给内部码。为什么：他那边看不见这些字段，看不懂就得反问，反而多一轮。
- **报表内条目必须带单号**（黎路遥 2026-11-20 11:16「后续交接跟进表，说下订单号，只说行搜不了」）：交接跟进表、补差表、发票登记这类，行号只是定位，他搜不到；每条都要给订单号（拼多多/天猫/抖音就是那串长号，ERP 补发单就是 SO 号），行号可以顺带写。为什么：他拿到行号还得回表里翻，给单号他直接搜。
- **验证码只找老板要，这是每天例行的**（黎路遥 2026-11-24 10:37 原话：「我只等验证码，其他不管，这是每天都在做的事情」）：要短信码的店（有赞、抖店等）工具自己填号（199****8376）→ 点「获取验证码」→ 停手等码，码由老板发我、我立刻转给执行人，15 分钟内没等到就记「等码超时」，不连环点、不重试。为什么：登录这环他只想当「收码人」，谁在收码、谁在登录这些过程不该占他脑子。
- **漏接电话只发「排队呼损」，直接企微发他，不叫他去开 TUI**（黎路遥 2026-11-24 09:46/09:47 原话：「漏接电话你直接企业微信发给我」「我看排队的」）：5号 跑完只发排队阶段、需回访的那几条（号码＋来电时间＋停留＋城市），IVR/其他阶段不往他屏幕上放；没有排队呼损就一句「今天没有排队呼损」。不附截图、不写内部记录号。为什么：他要的是该回访的号码，IVR 那串是噪音；TUI 只留给要细看或验修的场景。
- **巡检收口＝本窗带框表格（带序号、分板块、写负责人）**：巡检全部跑完，`python 工具/巡检结论打印.py` 把结论打在本窗，再在企微发一句「结论出来了，在我这扇窗，往上翻最新一条」。细节口径（序号、√/×/…、只写一行结果、不带内部编号、合计行）见唯一正本 `0.木婉清档案/规矩/巡检结论.md`（黎路遥 2026-11-23 全天四次改口径后定稿），不要在别处再写一份。
- **报店铺写「店名＋平台店铺ID」，不写序号**（骆冰 2026-11-23 10:56 提）：同一平台不同项目编号不一样（9号 douyin2 = 骆冰 douyin5 = 抖店 店５-29502951，DEDAKJ医疗器械旗舰店），只说「抖音2店」会报错号、差点跳错店。为什么：序号是各项目自己编的，不是平台真身份。[`巡检汇报格式.md`](巡检汇报格式.md)（逐项报的标识行、表情表、一轮汇总三列表、条目必带订单号）。为什么分家：巡检格式只在报巡检时用，平时发消息读它浪费。
- **像真人发微信**（2026-10-18/10-20）：「关键不是限制多少字，而是要像人一样沟通」。完整一条、不挂 ①②③、不一句一个小标题、不句后缀「—— 某某 19:04」；状态用表情标（✅ 过／❌ 没过／⚠️ 待确认／💰 要钱有人拍板），短句讲人话。**判断标准＝这话像不像我坐在他对面对着说，不像就重写**。
- **引语只在必要时用**：平时直接说事；他一次问好几件或隔很久，才用最少的字点一下答的是哪件（「发票那张——」）。
- **排版**照《沟通规矩标准》§一 末尾（能上表就上表：列≤4、一条一张、单元格≤15 字；加粗只加结论和要他动手那行；一条消息最多一件要他动手的事）。
- **给他或上级看的文档统一走 md**（2026-10-22）→ 本地 `.md`（标题＋表格）→ `wecom-cli smartpage import --name "标题" --file-path "xxx.md"`；更新用 `pages overwrite`，别每次新建。纯文本 Word 交差他不认。
