## 八、Git 与开源
- 提交**只点名自己改的文件**：禁止 `git add -A` / `git add -u`（本仓库常有平行会话在改代码）。
- 仓库要开源：`project-config/`（密钥、webhook、令牌）、登录态、截图、Excel、客户真实身份信息**不入库**（见根 `开源边界.md`）。
- 干完的活当场提交并 push；issue 用本地 `gh` 关，**评论必须带证据**，没证据不许关。
- **提交走闸门**：`node tools/提交.js -m "提交信息" <点名文件...>`（= 扫描 →（有新的就）`--学` → `git add --renormalize` → 提交 → `--核对`）。
  它把顺序固定死，绕不过去；只允许点名文件（禁止 `-A`/`-u`）。
- 手工提交的话：`node tools/打码.js --扫描` → 提交 → `--核对`；扫描末尾若显示「**N 个还没进对照表 > 0**」→ **先 `--学`**，
  且 `--学` 之后必须 **`git add --renormalize <文件>`** 再提交（否则过滤器对已 add 的内容不生效，真值照样明文上路）。
  - 光写在纸上（「先 --学 再提交」）不够，得让工具替你守；测试 `tools/提交.test.js` 锁死「不许批量 add、必须 renormalize、必须先学」。
