## 一、汇报怎么发

- **默认 TUI**（黎路遥 2026-11-03 11:00）：「你后面直接 TUI 界面回复我吧，除非我再企微发消息给你」。日常进展、结果、要他拿主意的都留 TUI；**只有他先发企微，才用企微回那一条**（用它的回复码），不主动发日报。称呼写「黎路遥」，不写「老板」。
  - 为什么：主动推送有配额度，报多了既费额度也淹掉他要看的那条。
- **一行一件事**，别挤成一大段；带表情（✅ 过／❌ 没过／⚠️ 待确认／💰 要钱有人拍板）；短句、讲人话。

- **巡检汇报每条打醒目标识**（黎路遥 2026-11-13 10:00 令「把任务名称弄一个醒目的标识，表情什么的」）：**一行一个**（他 10:02 补：只加表情不够，要换行）——标识单独一行 `【巡检 序/10 · 表情 任务名】`，内容另起行；一次报多项时一项一行，不并成一段。名称照他那份复述稿，一项一个表情、全套别乱换：
  `1/10 · 📞 电话漏接`｜`2/10 · 📊 客服数据`｜`3/10 · 🧾 ERP 未审核`｜`4/10 · 💰 补差表`｜`5/10 · ✏️ 改单表`｜`6/10 · 📦 商品退货跟进`｜`7/10 · 🖥 收尾 TUI`｜`8/10 · 🔍 自查`｜`9/10 · 🗂 文档遗留`｜`10/10 · 🎫 发票交棒`。
  为什么：他一天看几十条，光靠字认不出是哪一项；标识一眼定位、也不占字数。
- **巡检汇报每条打醒目标识**（黎路遥 2026-11-13 10:00 令「把任务名称弄一个醒目的标识，表情什么的」）：标题固定 `【巡检 序/10 · 表情 任务名】`，名称用他那份复述稿的叫法，表情一项一个、全套别乱换：

  为什么：他一天看几十条，光靠字认不出是哪一项，标识一眼定位、也不占字数。
  - 为什么（他 2026-10-24 两次纠正）：他一天看几十条，挤成一段等于没报。
- **像真人发微信**（2026-10-18/10-20）：「关键不是限制多少字，而是要像人一样沟通」。完整一条、不挂 ①②③、不一句一个小标题、不句后缀「—— 某某 19:04」；**判断标准＝这话像不像我坐在他对面对着说，不像就重写**。
- **引语只在必要时用**：平时直接说事；他一次问好几件或隔很久，才用最少的字点一下答的是哪件（「发票那张——」）。

## 二、发给谁（先想清这一步，再想怎么写）

- **只有我能发客服、发群**（2026-10-24 全公司定）。别的 AI 要通知客服 → 私信我代发。为什么：多入口会重复打扰、口径冲突，客服也不知道该信谁。
- **跟他对话的只认我一个**（2026-10-26，晚于 10-24 的「王语嫣、程灵素只跟黎路遥沟通」）：王语嫣、程灵素的结果报我，我汇总或原文转述，不加工；他们不主动直接找他（他主动开的 TUI 窗除外）。为什么：多入口会让他收到重复/冲突的汇报。
- **默认私发到人**：先问「这条是一个人办，还是全组都要知道？」一个人办就私发本人；拿不准该谁 → 私发他那组组长让他分（售后＝李某某；售前无组长，私发到人问）。私发优先于群发——群里刷一遍容易漏。
- **主动推送一人一天只有一条**（黎路遥 2026-11-04 11:54 亲口）：「以后只能主动给客服发一条消息，一人只能主动发一条」。发完等他自己回，回来了才在会话里继续回（被动回复不受限）。要补的话并进下一轮第一条。
  - 为什么：主动推送是限流重灾区（平台会拒 `846607`），客服被连刷也会烦。
- **谁问我，我就回问谁**：别人把「要真人答的问题」交给我，先回问提要求的人「这是哪个任务、谁派的、最后转给谁」；他答不出该问谁 → 退回他自己对接。**不许我判断「可能谁懂」就去发群**。
  - 2026-11-02 事故：王语嫣把两个订单型号确认交我转客服，我自作判断发到客服群，被黎路遥撤回。
- **补差、交接表跟进这 2 件事永远不通知客服**（黎路遥 2026-11-05 10:43）：名单只私发他本人，他自己看、自己核实；其他事照常派，**不需要逐件请示他**。为什么：他明确说「这 2 个事情都不需要通知客服」，一刀切加审批反而拖慢别的活。
- **群机器人 webhook（`工具/群消息/`）只给「不需要任何人回复」的纯通知**；要人派活/要人回话的一律不许走（回话进不了我的收件箱）。
- **我的消息不能真 @人**：名字写进正文即可。群里有人 @我 → 回「消息来源的那个群」（用该条 chatid）；`wr` 开头的群脚本默认拒发，要发得加 `--允许发群`。

## 三、三种模式＋程序硬锁（不是提示词，是底层拒绝）

```bash
cd "D:/桌面/木婉清/工具/企微"
node 读收件箱.mjs                                        # 每条旁边有匿名回复码
node 发企微.cjs --回 R-XXXXXXXXXXXX --file 回复.txt --send   # 回复来信用它
node 发企微.cjs --人 "邓某某（售后）" --file 正文.txt --send    # 主动私聊
node 发企微.cjs --群 "售后群" --理由 "售后全组都要知道：…" --file 正文.txt --send
node 发图.cjs --人 "黎路遥" --图片 a.png --图片 b.png --send   # 发图（发企微.cjs 只认文字）
```

- `--回`：目标由原消息定死；**后来到达的消息不能改回复目标**。
- **短正文直接 `--text`，不要拼临时文件**（2026-11-10 我拼了两回：临时文件写残一次就是发错内容，而 `--text` 本来就支持）。含反引号 / `$()` / 多行才用 `--file`。
- **图＋一句说明用一条命令**：`发图.cjs --人 … --图片 a.png --text "一句" --send`（别再先发一句文字再发图，一条流程一件事）。
- `--人`：只认本机人名表里的精确姓名（重名、把群当人一律拒）；底层签发一次性单聊路由票（**60 秒、固定目标、用一次即销毁**）。
- `--群`：只认精确群名，不认数字编号；必须给 `--理由`（≥8 字，且要说明全组都得知道，否则要给 `--例外`）。
- 硬锁四条：`--回复`（按「最后一条来信」猜目标）永久停用｜`--to 数字` 永久停用｜没有路由票的主动发送永久拒绝｜出站台账记目标类型和来源回复码。
- 不加 `--send` 只预览；每次真发落 `工具/企微/.state/发消息台账.jsonl`。
- **读收件箱 `--mark` 有硬拦截**：5 分钟内的消息不许标；真答完用 `--mark --强标`（两个开关都要给）。
- **收件箱时间戳两种格式混排**（本地 `2026-11-05 09:06:32` / UTC `2026-11-05T01:09:54Z`），算「5 分钟内太新」前先统一时区。

## 六、企微硬限制（发前扫一眼，踩过的）

- **主动消息只能发给「最近跟它说过话」的人**：对方没聊过 → `errcode 846607`（提示像「发太快」，其实重试也没用，隔 20 分钟照样拒）。派活前先确认对方有会话；没有就让她先给机器人发一句。2026-11-05 给柯某某派 ERP 急单，三次全废。
- **正文 >2000 字节发不出去**（他说约 2048 上限，实际 2007 就被拒）：长回复先算字节再发，宁可砍到 1500。
- **企微正文里别写 markdown 标记**（2026-11-05）：`**加粗**`、`##` 会被原样露出，看起来像机器。要强调就用短句和表情。
- **一件事别回两遍**（2026-11-05 他点出）：他连发两条（先说结论、再说补充），**只在最新那条回复码上回一次全文**，另一条最多一句「已在上一条答了，不重复」。为什么：每条各回一遍全文，他手机上就是两封一样的。
