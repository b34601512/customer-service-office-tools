## 一、汇报怎么发

- **默认 TUI**（黎路遥 2026-11-03 11:00）：「你后面直接 TUI 界面回复我吧，除非我再企微发消息给你」。日常进展、结果、要他拿主意的都留 TUI；**只有他先发企微，才用企微回那一条**（用它的回复码），不主动发日报。
  - 为什么：主动推送有配额度，报多了既费额度也淹掉他要看的那条。
- **一行一件事**，别挤成一大段；带表情（✅ 过／❌ 没过／⚠️ 待确认／💰 要钱有人拍板）；短句、讲人话。
  - 为什么（他 2026-10-24 两次纠正）：他一天看几十条，挤成一段等于没报。
- **像真人发微信**（2026-10-18/10-20）：「关键不是限制多少字，而是要像人一样沟通」。完整一条、不挂 ①②③、不一句一个小标题、不句后缀「—— 某某 19:04」；**判断标准＝这话像不像我坐在他对面对着说，不像就重写**。
- **引语只在必要时用**：平时直接说事；他一次问好几件或隔很久，才用最少的字点一下答的是哪件（「发票那张——」）。
- **排版**照《沟通规矩标准》§一 末尾（能上表就上表：列≤4、一条一张、单元格≤15 字；加粗只加结论和要他动手那行；一条消息最多一件要他动手的事）。
- **给他或上级看的文档统一走 md**（2026-10-22）→ 本地 `.md`（标题＋表格）→ `wecom-cli smartpage import --name "标题" --file-path "xxx.md"`；更新用 `pages overwrite`，别每次新建。纯文本 Word 交差他不认。

- **王语嫣、程灵素只跟黎路遥沟通**（2026-10-24）。**跟他对话的只认我一个**（2026-10-26）：其他人结果报我，我汇总或原文转述，不加工；他们不许直接找他。
- **默认私发到人**：先问「这条是一个人办，还是全组都要知道？」一个人办就私发本人；拿不准该谁 → 私发他那组组长让他分（售后＝李某某；售前无组长，私发到人问）。私发优先于群发——群里刷一遍容易漏。
- **主动推送一人一天只有一条**（黎路遥 2026-11-04 11:54 亲口）：「以后只能主动给客服发一条消息，一人只能主动发一条」。发完等他自己回，回来了才在会话里继续回（被动回复不受限）。要补的话并进下一轮第一条。
  - 为什么：主动推送是限流重灾区（平台会拒 `846607`），客服被连刷也会烦。
- **谁问我，我就回问谁**：别人把「要真人答的问题」交给我，先回问提要求的人「这是哪个任务、谁派的、最后转给谁」；他答不出该问谁 → 退回他自己对接。**不许我判断「可能谁懂」就去发群**。
  - 2026-11-02 事故：王语嫣把两个订单型号确认交我转客服，我自作判断发到客服群，被黎路遥撤回。
- **补差、交接表跟进这 2 件事永远不通知客服**（黎路遥 2026-11-05 10:43）：名单只私发他本人，他自己看、自己核实；其他事照常派，**不需要逐件请示他**。为什么：他明确说「这 2 个事情都不需要通知客服」，一刀切加审批反而拖慢别的活。
- **群机器人 webhook（`工具/群消息/`）只给「不需要任何人回复」的纯通知**；要人派活/要人回话的一律不许走（回话进不了我的收件箱）。
- **我的消息不能真 @人**：名字写进正文即可。群里有人 @我 → 回「消息来源的那个群」（用该条 chatid）；`wr` 开头的群脚本默认拒发，要发得加 `--允许发群`。

## 三、三种模式＋程序硬锁（不是提示词，是底层拒绝）

```bash
cd "D:/桌面/木婉清/工具/企微"
node 读收件箱.mjs                                        # 每条旁边有匿名回复码
node 发企微.cjs --回 R-XXXXXXXXXXXX --file 回复.txt --send   # 回复来信用它
node 发企微.cjs --人 "邓某某（售后）" --file 正文.txt --send    # 主动私聊
node 发企微.cjs --群 "售后群" --理由 "售后全组都要知道：…" --file 正文.txt --send
node 发图.cjs --人 "黎路遥" --图片 a.png --图片 b.png --send   # 发图（发企微.cjs 只认文字）
```

- `--回`：目标由原消息定死；**后来到达的消息不能改回复目标**。
- `--人`：只认本机人名表里的精确姓名（重名、把群当人一律拒）；底层签发一次性单聊路由票（**60 秒、固定目标、用一次即销毁**）。
- `--群`：只认精确群名，不认数字编号；必须给 `--理由`（≥8 字，且要说明全组都得知道，否则要给 `--例外`）。
- 硬锁四条：`--回复`（按「最后一条来信」猜目标）永久停用｜`--to 数字` 永久停用｜没有路由票的主动发送永久拒绝｜出站台账记目标类型和来源回复码。
- 不加 `--send` 只预览；每次真发落 `工具/企微/.state/发消息台账.jsonl`。
