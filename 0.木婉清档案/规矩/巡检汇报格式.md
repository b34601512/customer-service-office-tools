# 规矩 · 巡检汇报格式（只在报巡检时读）

> 为什么单独一份：巡检汇报有固定格式（逐项报＋一轮汇总表），跟平时发一条消息不一样；混在 `发消息.md` 里，平时发消息也要把这一页读完。排版唯一真源仍是《沟通规矩标准》§一（`D:/硅基公司/员工/01.人事·阿朱/工作台/沟通规矩标准.md`），本文件只写巡检怎么落。

## 逐项报

- 标识单独一行：`【巡检 4/10 · 💰 补差表】`，空一行，再一行写结论（**数字在前、理由在后**）。
- 一项一个表情，全套别乱换：`📞电话漏接`｜`📊客服数据`｜`🧾ERP未审核`｜`💰补差表`｜`✏️改单表`｜`📦商品退货`｜`🖥收尾TUI`｜`🔍自查`｜`🗂文档遗留`｜`🎫发票交棒`。
- 为什么：他手机上一眼扫过去就知道第几项、哪一类，不用读完整段。

## 一轮汇总

- 表前后各一句白话，中间一张三列表 `# ｜ 项目 ｜ 结果`；列≤4、单元格≤15 字、只放状态不讲理由。
- 要他动手的单独一行：`→ 要你：…`（一条消息最多一件要他动手的事）。
- **条目里带订单号**（黎路遥 2026-11-20 11:16）：行号只是定位，他搜不到；每条给订单号（拼多多/天猫/抖音那串长号，ERP 补发单是 SO 号），行号顺带写。
- 为什么：手机上表能渲染成格子（他 2026-10-22 亲测）；套现成标准，阿朱改一次我跟着变，不用每回现编（2026-11-13 我连着自造三版）。
