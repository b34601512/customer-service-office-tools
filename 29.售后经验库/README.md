## 规矩（跟业务红线一致）

- **平台后台一律只读**（拼多多/抖音/天猫/京东）；要改商品/价格/库存/发货 = **运营部**的活，我们只写问题清单给人/工单。
- **唯一例外**：26号 拼多多**维权申诉**可以真实提交，但必须**用户先批准**（工具默认只填不交）。
- 本库**只放经验/口径**，不放可执行工具；工具代码仍在各项目 `src/tools/`（经验里写明的命令以所在项目为准）。
- **改这里要顺手看一眼引用它的项目**：22/24 号的 `经验/*.md` 都是指路到本库的空壳，不会再各存一份。
