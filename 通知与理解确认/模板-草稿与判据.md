# 模板：草稿与判据

> 一份通知两类内容：**问法**（发出去的那条）＋**判据**（怎么算懂）。两个都要在发之前定死。

## 一、问法（挑一种）

**A. 盘问式**（想让对方自己说，最看得出懂没懂）
```
X，麻烦回我一句：<谁>今天在群里发的<什么事>，你看了吧？
如果现在遇到<具体场景>，你会怎么处理？用你自己的话讲两步三步就行，不用长。
哪一步拿不准，直接说拿不准。
```

**B. 讲清式**（事情复杂、必须先教会，再确认）
```
X，<谁>今天在群里发的<什么事>，流程我给你写清楚，按这个做：
① <第一步>
② <第二步>
③ <第三步>
<截止时间/注意事项>。看完回我一句「明白」，哪一步不清楚就直说。
```

**C. 确认式**（已经很熟的事，只确认收到）
```
X，<什么事>你这边清楚吗？回我一句「清楚」就行，有疑问直接说。
```

> 黎路遥 2026-11-03 定：**用哪种都行，但他确认过的那版原样发，不许自己改字**。

## 二、判据（写清「懂」的标准，三条以内）

```
懂   = 说到 ①②③
半懂 = 漏掉其中哪一条（写明漏了哪条）
没懂 = 答的是别的事 / 说不知道
没回 = 截止时刻还没回（不许替他判成「没懂」）
```

## 三、清单表头（照抄）

| # | 谁 | 问了吗 | 回的原话 | 判 |
|---|---|---|---|---|
| 1 | 名字（岗位） | ✅ 时刻 已发 / ❌ 未发（原因） | 原样抄，不总结 | 懂／半懂（漏X）／没懂／没回 |
