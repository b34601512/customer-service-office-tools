# 11.视频压缩工具 · 项目索引

> 开工先看：**本页** → `README.md`（用法）→ `CLAUDE.md`（模块）。
> 总规矩：根 `../AGENTS.md` + `../0.木婉清档案/规矩与红线.md`。最后整理：2026-10-09。

- **干嘛的**：本地视频压缩小工具（默认压到 25MB 以下、可自定义；H.264/AAC 两遍码率；超标收紧码率最多 3 次）。纯本地文件工具，不碰平台。
- **入口**：`启动程序.bat`（TUI）→ `main.py`；依赖安装 `安装依赖.bat`；配置 `config.json`；输出在 `output/`。
- **命令**：`.\\.venv\\Scripts\\python.exe -B main.py "示例.mp4" --target-size-mb 25`；`python -m unittest discover -s tests -v`。
- **红线**：**原视频不覆盖**（结果另存 MP4）；2026-09-16 起不再打包发布（`build_release.py`/`packaging/` 已删），只发源码；不下 ffmpeg（`imageio-ffmpeg` 自带）。
