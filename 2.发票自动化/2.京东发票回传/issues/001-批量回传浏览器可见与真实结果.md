# 批量回传浏览器可见与真实结果

## 意图

批量回传启动后，每个本轮待回传订单所属店铺都必须打开可见京东页面并保留到控制台退出；界面只展示本轮真实结果。

## 背景

现流程先下载发票，只为下载成功的店铺打开京东页面。全部发票未找到时，上传分组为空，浏览器不会启动；TUI 又无条件覆盖为“已结束、页面保持打开”，导致页面现象与结果文案矛盾。

## 验收清单

- [x] 下载结果为空时，待回传订单所属店铺仍进入京东可见会话。
- [x] 有发票时继续在同一店铺会话完成上传，不额外打开重复窗口。
- [x] TUI 显示真实的成功、失败、跳过数量。
- [x] 后台任务失败时，TUI 不得显示完成。
- [x] 页面仍由控制台退出动作统一关闭。
- [x] 自动测试覆盖空上传清单与真实状态传播。

## 边界

- 不增加兜底、兼容分支或第二套完成判定。
- 不改变待回传订单筛选口径。
- 不为没有待回传订单的店铺打开无关窗口。
- 不触碰其他项目现有改动。
