# Issue 005：自动回传缺少处理中转换

## 意图与证据

抖音无需人工登记，待处理订单直接进入自动下载、回传。原进度只写 lastReturnAttempt，未转换 workflowStatus；成功落盘调用共享规则时，pending→handled 被拒绝。新增历史保留测试暴露此缺陷。

## 验收

- [x] 开始下载/上传时，待处理订单经共享转换规则进入 processing。
- [x] 成功后进入 handled 并保存防重复标记和截图；失败仍可重试。
- [x] 不伪造发票已登记状态、不放宽其他平台状态规则。

已通过新订单下载→成功落盘→空同步保留凭证→再次同步排除回传的测试；复测记录见 Issue 003。

## 边界

只修改抖音订单服务适配层，不操作真实订单，不触发真实提交。
