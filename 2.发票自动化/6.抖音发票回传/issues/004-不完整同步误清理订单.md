# Issue 004：不完整同步误清理订单与成功记录丢失

## 意图与证据

导出失败时 syncPendingOrders 把当前页作为完整快照保存；仓库删除不在快照内的本店记录，导致分页外记录和成功凭证消失。完整读取失败必须明确失败，保留原数据。

## 验收

- [x] 导出/解析失败或有可见订单但报表解析为空时不保存部分快照，逐店流程跳过该店回传。
- [x] 完整同步可清理已不待处理的旧队列，但保留成功订单和凭证。
- [x] 空快照和跨店同步测试证明成功历史与其他店数据不受影响，成功订单再次出现在报表中仍排除回传。

## 边界

只修复今后的同步行为，不猜测恢复已丢失数据，不直接写真实订单文件。
