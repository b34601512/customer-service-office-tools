# Issue 002：同手机号共用浏览器

## 意图

同手机号只维护一份登录资料、一个专用浏览器，避免两店重复手机验证。店铺仍分别核验、保存订单。关联 Issue 001，但本问题是账号与浏览器归属。

## 背景与证据

- 两家启用店铺手机号相同，均配置平台店铺 ID 和名称。
- 原资料目录由浏览器、店铺 ID、账号摘要共同决定，造成两份登录态。
- TUI/CLI 状态和批量登录也沿用按店目录。共享工作台串行处理店铺。
- 切店返回实际页面，但调用方仍使用原页面；缺平台 ID 会跳过身份校验。
- 未发现本项目专用浏览器进程。源码、测试、README 已备份到 `D:\备份文件夹\抖音同号共用浏览器-20260907`。
