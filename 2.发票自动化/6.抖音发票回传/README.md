抖音项目复用「通用发票下载中心」下载发票，不在本项目内重复实现取票功能。

## 配置

在 CLI 菜单选择「配置店铺手机号和地址」，每个店铺配置一条：

```json
{
  "stores": [
    {
      "id": "douyin-store-1",
      "name": "抖音店铺1",
      "targetUrl": "https://fxg.jinritemai.com/",
      "phoneNumber": "登录手机号",
      "enabled": true
    }
  ]
}
```

## 启动

```powershell
npm start
```

CLI 可按需执行登录、页面采集和正式回传。发票处理区先用“同步待处理订单（只读取）”读取当前列表并解析 XLSX/CSV 订单报表，持久保存到 `data/invoice-order-records.json`；该动作不调用下载中心、不上传发票、不提交回传。

订单状态管理固定提供待处理、处理中、发票已登记、已处理四个直接队列。正式回传只消费“发票已登记”且未成功回传的订单：成功自动进入“已处理”，下载缺失、跳过或上传失败仍留在“发票已登记”并保存原因和截图。

选择多店时单店失败会继续后续店铺，CLI 最后输出逐单进度、文件/截图对应、逐店结论和总汇总。Edge 只用于真实业务页面；确认正式回传前会再次询问。

## 自检

```powershell
npm test
```

测试使用模拟订单报表和回调，不执行真实登录、下载、上传或提交。
