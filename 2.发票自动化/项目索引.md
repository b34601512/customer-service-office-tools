## ② 规矩 / 口径（一句话 + 出处）
- **平台后台只读**：不点同意/提交/保存/回传；**天猫「待同意」永远不点**（先人工登记、后同意）→ [`规矩与红线.md`](../0.木婉清档案/规矩与红线.md) §一、§三 + [`CLAUDE.md`](./CLAUDE.md)。
- **回传要当次授权**：发票回传=平台写操作，必须黎路遥**当次**明确「允许回传」（不认长期口令）→ [`每日自动化流程.md`](../0.木婉清档案/日常流程/每日自动化流程.md) §二。
- **登记写表逐次授权**：`写登记表.js --已确认` 才写；先干跑/查重/快照、写完回读 → [`7号 项目索引`](./7.自动登记发票/项目索引.md)。
- **巡检只走既有只读入口**（京东 `npm run check`、各项目 TUI/collect）；**不要额外开自动化浏览器读后台**（风控）→ [`规矩与红线.md`](../0.木婉清档案/规矩与红线.md) §一。
- 登记全部口径（个人票/金额/查重/赠品/ERP 查单）**唯一落点 = 7号经验库**，见下节链接。

## ④ 常用命令
```bash
cd "2.发票自动化"
node scripts/每日只读巡检.js                                  # 日常只读巡检 + 待处理清单
node .codex-temporary/检查诺诺发票.js <订单号...>              # 诺诺有票后：生成检查结果（只读）
node scripts/回传已开发票.js                                  # 只回传已登记（真实提交，须当次授权）
cd 7.自动登记发票 && npm test                                  # 登记单测（不触网）
```
