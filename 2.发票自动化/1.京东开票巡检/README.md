## TUI 控制台（默认入口）

`启动巡检.bat` 或 `npm run panel` 进入 TUI，使用备用屏幕 + 方向键/数字键操作：

| 页面 | 内容 | 操作 |
| --- | --- | --- |
| 1 总览 | 任务状态、店铺概览、最近巡检摘要、快捷操作 | ↑↓选择 回车执行 |
| 2 店铺 | 店铺结果镜像表格：状态/告警/待登记/已上传未逾期/明细/新增/最近结果；回车查看该店巡检明细 | ↑↓选择 回车明细 s启动该店巡检 |
| 3 日志 | 巡检执行过程实时日志 | ↑↓滚动 /过滤 f跟随 r清屏 |
| 4 配置 | 店铺配置总览 | ↑↓选择 t启用/停用 |

- 巡检在可见的 Edge 窗口中执行，完成后浏览器保持打开供人工核对，不再依赖截图凭证。
- 数字键或 ←→ 切页，q 返回总览，Ctrl+C 退出（需 y 确认）。
- 店铺新增/修改/删除请使用 CLI 模式：`npm run panel:cli`。

启动逻辑：

1. 先检查项目依赖是否齐全，只有缺依赖时才会执行一次 `npm install`。
2. TUI 维护多店铺、账号密码和目标地址（启用/停用可直接在 TUI 内切换）。
3. 单店巡检按需打开真实京东页面；批量巡检按店铺顺序执行，并把结果写回本地。

巡检逻辑：

1. 使用 Edge 持久化登录态打开京东目标页面。
2. 自动提取页面里可见的待开票明细，并与上次快照对比。
3. 仅在发现新增记录时发送桌面通知，并生成文本报告到 `data/reports/`。
