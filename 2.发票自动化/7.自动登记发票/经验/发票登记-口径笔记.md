# 发票登记 · 口径笔记（黎路遥 2026-10-06 定，免得后续再问）

> 来源：2026-10-06 金牌组原话（黎路遥，副经理）。写进登记流程/代码前先看这里。

## 1. 个人票（无税号）
- **原话**：「个人不用税号，填姓名就可以了，后台没有你就填收货人姓名」（2026-10-06 15:38）
- **操作口径**：票种＝个人 / 无税号时——**AB 税号栏填姓名**；平台后台/ERP 取不到姓名时**填收货人姓名**；**不因缺税号拒写**。
- **2026-10-09 重申（黎路遥）**：个人票 **AA 抬头 与 AB 税号 都填收货人姓名（AA=AB 同值）**；平台/后台只写「个人」时按**收货人姓名**填（不得用「个人」二字）。
- 企业票维持原样（仍必须税号）。
- 首个落地：单① `3316468010210055174`（天猫2店）、单② `5127801625173010542`（德达旗舰店/天猫1店）。

## 2. 金额 / 差价（平台 ≠ ERP）
- **原话**：「按后台金额为准」（2026-10-06 15:39）＋「差价的问题登记规范也做好笔记」（15:40）
- **操作口径**：
  1. **登记金额以平台后台显示的开票金额为准**（例：单② 平台 1122.16 / ERP 1150.00 → **按 1122.16**）。
  2. 发现差额（平台 ≠ ERP）时：**在备注列写明差额与原因**（原因取自平台/ERP 已有字段，如「卖家备注：收到让利29元」；**不猜、不编**）。
  3. 差额**不需要**单独登记差额明细行——金额按后台、备注写原因即可（如需例外，人工在金山表处理）。
  4. 若后台金额本身有多个申请页签（如「申请一/申请二」）看不清归属 → **停下问客服**，不猜。

## 3. 谁检查（黎路遥 2026-10-06 16:10 定）
- **原话**：「后续**谁让你登记，你就让谁检查**，除非这个人**下班了**，才让其他值班同事帮忙检查，**说明让他检查原因是之前那个同事下班了**，不然另一个同事不知道怎么回事」
- **操作口径**：
  1. 验收工单/群通知的检查人 = **提出登记的那个人**（谁喊我登记谁检查）——不是自动挑值班售后。
  2. 该人**下班/不在岗**时 → 才让**其他值班同事**帮忙检查，并且**必须写明原因**（「原登记的 XX 已下班，麻烦你帮忙看一下」）。
  3. 落地：`27号/scripts/写售后待办.cjs --owner <提出人 userid>`；提出人不在岗才用 `--owner auto` 并加说明。
  4. 例：2026-10-06 缪某某让登记 → 工单/通知都找缪某某（当天 AOStKz 即挂她名下）。

## 4. 关联口径（沿用既有）
- 同单多行（主商品+赠品）：S 列写「同一个订单发票开一起」+ **只合并备注列 S**；登记客服 O 写「木婉清」。
- **赠品登记口径（黎路遥 2026-10-09）**：**ERP 里能查到的赠品就登记**（赠品行 Y=0）、**查不到的不登记**——先在 ERP「订单查询」按平台单号搜（`20.经验库/ERP查单两段式/`），不要只看「订单商品明细统计」报表。
- **个人票姓名从哪取（黎路遥 2026-10-09 14:01「收货人信息是在后台看」）**：个人票的**收货人姓名去平台后台看**（订单/发货信息里）——ERP 列表接口是加密/打码的，别在那儿死磕；平台后台自动化只走**既有只读入口**（5号/22号/24号 的受控浏览器只读路径），**不新开自动化浏览器**（风控红线）。
- 一单多主件（组合/套装）：每条非赠品明细各一行、金额按行拆；拆行与逐行写入步骤 → `一单多行-多主件怎么写.md`（2026-10-08）。
- 型号照表里已有行抄（如 YY-XYG / YQD / CMS50D），表里无先例的（如「纯正弦波逆变器」）先问客服。
- 天猫发票「待同意」单**绝不自动点同意**；登记完成由人工去平台点。
