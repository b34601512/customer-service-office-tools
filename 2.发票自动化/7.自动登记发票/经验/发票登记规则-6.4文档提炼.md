## 三、金额规则（最容易开错，重点）

基础口径：
- **ERP：订单商品明细统计 → 开票金额 = 买家支付金额**；平台支付金额、其他服务费这两项**不开**。
- 开票前先跟客户确认金额（"系统显示是 XX 金额，对吧"）；客户有凭证以客户凭证为准。

分平台：
- **天猫**：以后台订单详情「平台推荐【应开票给客户金额】」为准，**不是**千牛订单上的金额。
- **京东**：以 ERP 买家支付金额为准；发票只开【余额】+【实付金额】；京豆 / 优惠券 / 京东卡支付的金额**不开**。金额纠纷举证规则：`https://help.jd.com/user/issue/502-974.html`
- **拼多多**：以 ERP 买家支付金额为准，但总额要与平台"应开金额"一致。

赠品 / 次产品：
- 赠品显示 0 → 登记金额是 0，但**前面要备注赠品的销售金额**（赠品销售金额在发票表格子表里，没有就反馈添加）。
- 搭配销售订单（一个订单 ≥2 个产品，且非赠品）显示另一个产品金额为 0 时 → **通知运营拆分**，并告知要拆分的金额。
- **主产品开票金额 = 平台应开票金额 − 赠品/次产品开票金额**。
  - 例：969 − 76.82 − 30 = 892.12。
  - 反例：直接填 ERP 买家支付金额会加总超平台应开金额（对不上）。

其他硬规则：
- **只保留 2 位小数**（四舍五入；可设单元格格式自动算）——财务开票软件只能开两位小数。
- **ERP 与平台金额不一致** → 登记差额明细（平台金额、ERP 金额、差额、平台显示截图）；只有有差额的订单才登记，已补过差价的也截图登记。
- **型号统一**：`DE-1A` 和 `DD-1A01` 都按 `DE-1A` 登记。
- **ERP 有几条产品信息，就登记几条发票信息**（例：ERP 2 条 → 登记 2 条）。
- 发票金额**不含运费**；无法开"配件"之类统称，内容必须实开。

## 四、登记要求与红线

- **禁止重复登记**：先看备注/聊天记录是否已答应登记；表内用匹配函数查重，重复要删。
  已开通电子发票的店铺，**必须先核实是否已登记电子发票**，重复登记 = 公司重复交税。
- 客户购买时间较长的：**先查后台是否已退款**（出现过已退款还来开票的情况）。
- 登记后用**匹配函数查重**，再在**对应订单上备注**。
- 登记内容要严格、严谨：错票不可作废、作废多了影响发票申领。

## 五、冲红重开（登记三行，不改历史）

1. **首次登记**（冲红不要修改历史记录）；
2. **登记冲红**：「数量」和「总金额」标记为**负数**，B 列重开原因备注"冲红"；
3. **重新登记**：B 列重开原因备注"重开"。

❌ 错误做法：在第一次登记那行上直接改。

## 六、状态与时限

| 状态 | 口径 |
|---|---|
| 加急 | 3 天内要求开出 |
| 紧急 | 当天登记，次日开出 |
| 正常 | 7 天内 |
| 暂停 | 无限延迟 |

- 不允许多数单都标"紧急"（挤占真正紧急的额度）。
- 财务批量开票，一般 **7 个工作日**内开出。

## 七、专票（开具条件）

- 开专票需《确认开票基本信息便函》**填写 + 盖章回传**；区分**合同客户**与**平台客户**两种确认函，不能混用。
- 客户不愿提供资料 → 劝其改开纸质普票/电子普票（普票暂无必须盖公章的资料要求）。
- 个人**不能**开专票（《增值税暂行条例》第二十一条）；专票是公对公业务。
- 专票额度有限（每月 135 份），用完要申请超限量且不一定批。
- 税率：专票/普票/电子普票**同为 13%**。

## 八、常见合规口径（客户会问）

- 发票**必须用公司法定注册名称**，不能写店铺名（税务对接的是公司）。
- **数电发票没有公章是正常的**（2024-11-12 国家税务总局公告）；能通过国家税务总局查验平台验证即合法。
- 电子发票金额超千元版额度时会**拆成多张**（单价上限约 1129.998 元），属正常。
- 开发票**不收费**（额外收费违法）。
- 默认开**电子发票**（数电票推广）；发票不与产品一起邮寄（财务与发货不同城）。
- 不开收据（发票涵盖收据功能）。
- 机器买几年了：**没开过可以开，开过不支持重复开票**，需财务核实。

## 九、查询与退件

- 发票查询系统：诺诺（工单/表格里没有下载地址时查这里；**账号密码找经理要**）；
  搜不到时排查：时间范围选本月/近一年、右上角切换公司主体、用抬头搜。
- 换开的发票：用**新抬头**查（旧订单号只能对应旧发票）。
- 国家税务总局全国增值税发票查验平台：`https://inv-veri.chinatax.gov.cn/`
- 客户退件发票：统一退**大运**地址（深圳市龙岗区大运软件小镇 4 楼；收件人/电话先写自己的）。

## 十、给自动化的直接结论

1. 金额计算是一套**确定性规则**（平台口径 + 赠品拆分 + 2 位小数 + 差额登记），适合脚本化，但**必须先与客户确认**这一环要不要保留人工。
2. 登记是**写操作**（写金山在线表）→ 按业务红线：**先出待登记清单给人确认，再谈自动写入**。
3. 去重是硬要求，需要在脚本里内置（订单号/平台+订单号）。
4. 冲红重开是"三行结构"，自动化如果碰这部分要按三行写，且不改历史行。
