## 三、踩坑（全部实测过，改代码前先看这里）

1. **网页匿名读只加载「当前窗口」**：这张表真实有数据到第 7910 行，匿名读只回 489 行（最后一条 2025/10/14）→ 会得出「表停在 2025」的错误结论。**查重/读全表必须走 AirScript**。
2. **日期列是 Excel 序列号**：AirScript 读出来是数字（`46293`），不是日期字符串。换算：`45658 = 2025-01-01`，`46293 = 2026-09-28`。按字符串搜 `2026/` 会**一条都搜不到**。
3. **ERP CSV 的「平台单号」尾部带制表符 `\t`**：精确匹配 `=== '260903-…'` 会 0 命中，必须 `trim()`（本单就是靠 `includes(尾号)` 才捞出来的）。
4. **店铺两套叫法**：ERP 用「德达医疗旗舰店」，登记表/客服说「拼多多02店」——对应关系在工作簿的 `店铺对应关系` 表（PDD02店=德达医疗旗舰店，PDD03店=DEDAKJ医疗器械官方旗舰店…）。
5. **金额口径**：`Y 发票金额 = ERP 买家支付金额`（本单 374.12）。**不是**实际单价 598、不是让利后 398；`平台支付 23.88` 不开票。
6. **公式列一律不写**：实测（2026-09-28，第 2751 行读公式）确认有公式的是 **C/D/E/T/W/X/AO**（如 `C=COUNTIFS(J:J,J2751)`、`X=Y2751/V2751`）；
   **AK 发货日期不是公式、是人工填**（第 2 行那句「公式，自动出来」不适用于它，别被标注骗了）。看公式：`node scripts/查登记表.js --行 2751 --公式`。
7. **AirScript 传参坑**：`Context.argv` 传**数组**会被金山转成类数组对象（脚本里取不到 keywords），必须**直接传对象**（22号 的写法）。
8. **脚本正文属公司私有**（含文档链接/表名/列结构）：只存本机 `project-config/kdocs-scripts/`，**不入库**（用户 2026-09-28 拍板）；仓库里只留调用端与脱敏后的经验。

## 六、写表数据（自动生成，只算不写）

`npm run 写表数据`（或 `node scripts/生成写表数据.js [--订单号 X] [--out 文件]`）→ 把待登记条目转成 **列字母=值**：

```
A=46293(2026-09-28)  F=正常  G=普票  I=拼多多02店  J=订单号  O=AI助手
U=DH22-C1  V=1  Y=374.12  AA=抬头  AB=税号  AK=46268(2026-09-03，ERP 口径)
```

- **只包含我们该填的 12 列**；公式列（C/D/E/T/W/X/AO）**一个都不会出现**（有反向断言测试锁死）。
- 日期一律转成 **Excel 序列号**写（`2026-09-28 → 46293`；`2025-01-01 = 45658`），避免写成文本。
- 型号口径：ERP `规格名称` 去掉括号（`DH22-C1(9L) → DH22-C1`），与工作簿《德达医疗--产编》的型号列对齐（已核对 6 个型号全部命中）。
- 缺项（店铺/订单号/抬头/税号/发货日期/金额）→ 进 `待人工`，**不硬编**。
