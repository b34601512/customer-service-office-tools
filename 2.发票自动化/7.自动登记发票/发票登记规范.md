## 0. 红线（先看）
1. **平台后台一律只读**（拼多多/抖音/天猫/京东…）：不发布/提交/保存/改价/同意/回传；**天猫「待同意」永不点同意**——登记完由人工去平台点（2026-09-17 红线）。
2. **金山写表逐次授权**（`--已确认`）；**写前必须查重**、命中即停（重复登记=重复交税）；查重只信 AirScript 云端全表（网页读假阴性，2026-09-28 实测）。
3. **不新开自动化浏览器读平台**（会被风控，用户 2026-09-30 13:13）；只走既有只读入口，拿不到就停下叫人。
4. **拿不准的字段不许猜、不许编**（金额/型号/姓名/差额原因）——挂「待人工」问客服。

## 2. 抬头 / 税号（2026-10-09 15:46 售后李某某纠正；旧「AA/AB 都填姓名」作废）
- **企业票**：AA=公司抬头，AB=税号；没税号不能登 → 问客服。
- **个人票**：AA=姓名；**AB 留空**（只有开公司抬头的才填税号栏）；不得写「个人」二字。
- 个人票姓名来源：平台后台订单/聊天记录 → **买家在聊天里报的名字最优先**（黎路遥 2026-10-09 14:34「按买家聊天记录里的为准」）。
  - 实例：单 `240103-***********1794` 点拼多多「查看姓名和地址」被平台拒（`fopen/order/receiver`：「该订单暂时无法查看收件人信息」）；从售后详情页聊天记录取买家自报「白贵英」→ AA=白贵英、AB 留空（证据 `22号/runtime/probe/20261009-142017-pdd-pdd03/page.txt`）。
- 专票附加资料（AC~AF 地址/电话/开户行/账号、AG/AH 手机/邮箱）照客服/平台详情填；本地工具白名单暂无 AG/AH，要写走人工（见文末缺口）。

## 3. 金额
- **单主件**：Y=平台后台显示的开票金额（2026-10-06 黎路遥「按后台金额为准」）；平台读不到才用 ERP 买家支付金额。
- **一单多主件**（组合/套装）：主件按 ERP 顺序各一行、Y=该行 ERP 买家支付金额（=让利后）；赠品行 Y=0。
- **平台 ≠ ERP**：在 S 备注写差额事实（不猜原因）；原因读不到就不写原因。
  - 实例（2026-10-09 抖音单）：平台 1067.00 / ERP 两行合计 1069.00 → S 写「平台应开1067.00，本单按ERP拆两行合计1069.00（差2.00）」。
- 天猫同一单多次申请：取**未取消**那笔（2026-09-30）。
- 金额一律 2 位小数；平台支付/其他服务费不开票。

## 4. 赠品 / 0 元单
- **ERP 能查到的赠品就登记**（该行 Y=0、数量 V 照实）；**查不到的不登记**（2026-10-09 黎路遥；不硬凑）。
- **一个平台单可能有多个 ERP 单**（原单 + 0 元补发单）——都要登记、别只取第一条（2026-10-09 实例：SO689675869360 + SO689757956444）。
- 0 元补发单的商品先按赠品口径登记（Y=0）；拿不准要不要上发票 → 问客服。

## 5. ERP 取数（两段式，2026-10-09 黎路遥纠正）
1. 先到 ERP「**订单查询**」按平台单号搜：定这张单的时间，也能直接取 SO 单号/商品/让利后金额/发货时间（接口三档 `dateType` 都要查）。
2. 再按该日期去「**订单商品明细统计**」报表导 CSV 取字段（制单时间范围不能超 1 年）。
- 10号 导出两坑已修：日期框必须**回车提交**；必须点「查询」等明细网格加载完再导出。
- ERP 滞后于平台（如已取消那笔）时，以平台**未取消**那笔为准；收货人/电话在 ERP 列表是打码的。
- 接口/坑全文 → [`20.经验库/ERP查单两段式/`](../../20.经验库/ERP查单两段式/)。

## 6. 落表字段（两表同一套列字母）
- A=登记当天、F=正常、G=普票/专票（按平台申请）、I=店铺（写表里口径）、J=平台订单号、O=登记客服**「木婉清」**、U=型号、V=数量、Y=金额、AA=抬头、AB=税号、AK=发货日期（ERP 口径）；日期写 Excel 序列号（工具会转）。
- 型号：照表里**已有先例**抄（氧气袋 `YQD`、鼻氧管 `YY-XYG`、血氧仪 `CMS50D`、吸氧面罩 `XYMZ`）；表里没有先例就先问客服，不自己造代码。
- 同单多行：S 写「同一个订单发票开一起」+ 差额（如有）；**只合并 S 列**；按行号 1..n 顺序写、第 1 行带查重（详见 `经验/一单多行-多主件怎么写.md`）。

## 7. 工具链与闸门（写表唯一入口）
- 全流程照 `验收清单.md`：云端自检 → 探针 → 干跑 → 查重 → 写前快照 → 用户点头 → 写 → 写后快照 → 验收 4 条（目标行=期望、J=本单、其它行一字未变、下一可写行=目标+1）。
- 写入：`scripts/写登记表.js`（唯一会写；没有 `--已确认` 连查重都不跑）；一单多行用 `--行序号` 按 1..n 写。
- 改格子：`scripts/改登记行.js` **四道闸**=①身份核对（J=本单）②列白名单（A/F/G/I/J/K/L/O/U/V/Y/AA/AB/AK）③数字类型校验 ④云端写入判据（`written===true` 且目标列都在 `writtenColumns`）+ 写后回读；任何一道不过 → 一个字节不写。S 备注走 `scripts/写同单备注.js`。
- 写错/删行/恢复公式：人工在金山改（不写脚本绕闸门）。
- **AirScript 脚本一改，必须同步登记《脚本大全》**（工具 `20.经验库/kdocs脚本大全/登记脚本.cjs`：先预览，后 `--已确认`；源码放 `project-config/kdocs-scripts/`，不入库）。登记后告诉用户「第 X 行已更新」，由他从大全复制粘贴到目标文档；粘完跑 `scripts/云端自检.js` 验证版本号。
- **粘完别只跑云端自检**（只验版本/编译）：跑一次**零写入探针**验行为——发 `clearCells`（如 `"AB"`）不带 `allowWrite` 应回「缺少 allowWrite」，回「缺少 writeCells/clearCells」就是清单没解析出来（2026-10-09 实证；详见 `20.经验库/kdocs脚本大全/README.md`）。
- 验证只认云端回读；证据（快照/干跑/回读）落 `runtime/`，不入库。
