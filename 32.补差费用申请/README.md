### 带目标行的插图数据文件长什么样（v6 起；`--缩略图` 为例）
```json
[ { "行": 1674, "目标行": 1674, "源行": 451, "行语义": "目标行", "姓名": "程小霞", "id": "ID_…",
    "附件ID": "…", "文件": "451-程小霞-缩略.jpg", "字节": 19083, "mime": "image/jpeg", "缩略": true,
    "宽": 320, "高": 436, "原字节": 111253, "原宽": 1279, "原高": 1744, "缩略质量": 0.75,
    "途径": "附件", "dataURL": "data:image/jpeg;base64,…" } ]
```
- `行`/`目标行` = 目标表《汇总》的行号（插图写 C 列）；`源行` 只留痕、不参与写入。
- 映射规则在 `scripts/批次映射.cjs`：目标首行 = 批次 `预期末行.汇总` + 1；目标行 = 目标首行 + 批次 `明细[].源行号` 里的序号（**不硬编码偏移**）。
- 客户端 `写入在线表.cjs` 拿不到目标行时**拒绝写**（10-08 事故就是源行当目标行，见 `失败台账.md`）。
