## ④ 常用命令
```bash
node "28.排班与派活/src/tools/今天谁值班.cjs"                    # 今天·售后（人读）
node "28.排班与派活/src/tools/今天谁值班.cjs" --group 售前 --json  # 机器读（售前）
node "28.排班与派活/src/tools/今天谁值班.cjs" --at 20:00          # 指定时刻
cd "28.排班与派活" && node --test                                 # 单测
```
退出码：0=挑到了；**3=读不到/分不清（停下问人）**；2=读表失败/配置缺失。
