# 28. 排班与派活

## 角色（唯一口径）
「**此时此刻谁在岗**」这类问题（该 @ 谁、工单派给谁、谁接活）**只在这里定**。
别的项目（22号 / 27号 / 1号 …）**不许再自己读排班表、自己维护一份值班名单**，一律调本项目的工具 —— 避免
「每个项目都有一部分、标准不一」（用户 2026-09-30 原话）。

## 口径（黎路遥拍板，最高优先）
1. **值班看「单元格背景色标记」，不是看「早/晚」这类班次文字**（2026-09-29 亲口纠正）。
2. 颜色 → 分组：**`#BDD7EE`（浅蓝）= 售后值班**；**`#E2F0D9`（浅绿）= 售前值班**（09-29、09-30 两次实测一致）。
3. **带底色的人还要「此时此刻在班」**（2026-10-01「你要看此时此刻的」、2026-10-05「此时此刻不是邓某某上班吧」）：
   候选 = 带底色 ∩ 组名单 ∩ 此刻处于其班次时间窗口（早班 08:00-16:00；售后晚班 14:00-22:30 / 售前晚班 15:45-23:45；
   可用配置 `班次时间` 覆盖）。**窗口内没人 ⇒ 也停下来问人**（例 10-05 09:25：唯一带色的售后邓某某是晚班、还没上班 ⇒ 不挑他）。
4. **读不到带底色的值班人、或没人此刻在班 ⇒ 停下来问人，不许猜、不许兜底成组长。**
5. 同一分组 **≥2 人带底色且此刻都在班 ⇒ 判「分不清」，返回候选让人选**（不许按顺序随便挑一个）。
5. 本项目**只读**排班表；写表/排班是 21号 的事。

## 常用命令
```bash
node "28.排班与派活/src/tools/今天谁值班.cjs"                        # 今天售后值班（人读）
node "28.排班与派活/src/tools/今天谁值班.cjs" --group 售前 --json     # 机器读
node "28.排班与派活/src/tools/今天谁值班.cjs" --date 2026-09-30 --json
node "28.排班与派活/src/tools/今天谁值班.cjs" --at 20:00             # 指定「此时此刻」（默认=现在）
```
- 退出码：0=挑到了；**3=读不到/分不清（停下问人）**；2=读表失败/配置缺失。
