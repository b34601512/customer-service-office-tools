# 企业微信-能力边界（2026-09-21 查官方文档核实）

## 一、能做的：往群里发消息（webhook）✅
- 群机器人 webhook：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=<key>`
- 支持 8 种类型：text / markdown / markdown_v2 / image / news / file / voice / template_card
- 文本 ≤2048 字节、markdown ≤4096 字节；@人用 `mentioned_list`(userid) 或 `mentioned_mobile_list`(手机号)
- 本项目工具：`src/tools/send-wecom-notice.js`（`--file <txt> --at <人名>` 预演，加 `--send` 真发）
- 文档：`https://developer.work.weixin.qq.com/document/path/91770`

## 二、做不到的：读群消息 ❌
### 1. webhook 读不了（死路）
文档全文只有「消息推送」章节，**没有任何接收/读取消息的接口**，单向。

### 2. 会话内容存档能读，但本项目走不通（用户 2026-09-21 拍板：**堵死，不再尝试**）
技术上可行——「企业可以获取开启存档的员工和未开启员工之间的会话内容」，但前提：
- 管理后台**开启会话内容存档**（要设开启范围、IP 地址、消息加密公钥），员工企微需 ≥2.8.9
- **员工登录客户端会经过告知页面**（知情）；**与外部联系人的会话需经外部联系人同意**
- 要用**官方 C++ SDK**（Windows/Linux）拉取：`NewSdk()` → `Init(corpid, secret)` → 按 `seq` 分页拉（一次 ≤1000 条，≤4000 次/分钟）→ 解密
- Secret 在管理端「管理工具 → 聊天内容存档」

**卡点：用户没有管理后台权限，无法开通** → **这条路直接堵死，以后不要再查/不要再提**。

## 三、要读群消息的替代思路（若将来用户权限变了再看）
- 让有权限的管理员开通会话内容存档后，再按上面的 SDK 路径做
- 或者：把要读的信息改成"由客服主动填表/发到指定位置"，用可读的渠道（金山表等）代替读群
