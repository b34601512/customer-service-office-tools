## 三、踩坑（都已在代码里处理）
1. **网页匿名读只能拿到“当前窗口”的数据（最重要的坑）**：实测 2026-09-18，退货退款表真实有 46503 行
   （`usedRange._ranges[0].rowTo=46502`、`getRowsValidSize()=47104`），但 `getUsedRange().getRangeContents()` 只回 **29412 行**；
   截图里那单在 **K46310** 行 → 网页读法直接搜会“假没搜到”。
   → **要全表可靠查找，必须走服务端**：用官方接口（下面第四节）或 AirScript，不要靠浏览器读。
2. **工作表集合的 API 和 1号/14号 的老文档不同**：没有 `getCount()/getItemByIndex()`，要用 **`getNameList()`**；
   单个表用 `getItemByName(名字)`。
3. **`sheet.activate()` 之后 sheet 实例会被换掉**，且 `getUsedRange()` 可能还没挂上 `getRangeContents`
   → 必须「重新 `getItemByName` + 轮询等到 `getRangeContents` 存在」再用。
4. 就绪判断用**函数探测**（`workbook.getWorksheets` → `getItemByName` → `loadSheetData` → `getUsedRange().getRangeContents`），
   不要固定 `sleep` 秒数（1号 的写法）。
5. 匿名打开会有登录邀请浮层，要主动关掉：`#util-popup .wps-login-panel__header__right button`。
6. 底色（条件格式）要用 `sheet.getAppliedXf(行,列).getFill().getBack().getRGB()`，行列偏移取
   `usedRange._ranges[0].rowFrom/colFrom`；`getXfByCell` 读不到条件格式色。
7. `sheet.getRange("K46310")`、`getCellString(row,col)` 在该运行时里**不可靠**（分别回整段/空值），不要依赖；
   名称框跳转可以加载目标段，但不能用来遍历 47000 行。

## 三·补、官方两条路（2026-09-18 实测查证）
- **A. AirScript（推荐，用户做过两次）**：在文档里存一个**只读**脚本，拿「同步 webhook + AirScript-Token」；
  调用 `POST <webhookUrl>`，头 `AirScript-Token`，参数走 `Context.argv`，结果在 `data.result`。
  云端读全表 → 不受窗口限制。本项目已备好：脚本正文 `kdocs-scripts/AirScript-只读查询订单号.txt`，
  客户端 `src/engine/kdocsAirScript.js`，命令 `node src/tools/kdocs-query.js <订单号>`。
  配置写在 `project-config/kdocs-airscript.json`（不入库）。
- **B. Kdocs 开放平台 OpenAPI（要 OAuth access_token）**：
  `GET https://developer.kdocs.cn/api/v1/openapi/ksheet/:file_token/sheets/:sheet_idx/cells?access_token=…&row_from=…&row_to=…&col_from=…&col_to=…`
  （file_token = `ccj1mhG3wLy6`；返回值含 `cell_text` 显示值；测试应用 10,000 次/天，翻页读 47000 行完全够用）。
  代价：要去 open.wps.cn 开发者后台建应用拿 app_id/secret 并授权（比 AirScript 重），AirScript-Token 不能当 access_token 用。

## 四、命令备忘
```bash
node src/tools/read-kdocs.js --list                                  # 列 12 个工作表
node src/tools/read-kdocs.js --all --grep "订单号"                    # 跨全部工作表搜（网页读法，⚠ 只覆盖已加载窗口）
node src/tools/kdocs-query.js 5127667812586099609                    # 走 AirScript 服务端查（推荐，需先配 token）
```
> 大表建议：小规模核对用 `read-kdocs.js --sheet` 导出 JSON；**按订单号全表核对请用 `kdocs-query.js`（云端）**，
> 否则会被“窗口只加载 29412 行”坑到（2026-09-18 实例）。
