# 金山对接表：怎么只读读（2026-09-18 实测）

## 一、结论：不需要 token、不需要登录
能力源头是 **1号项目** `src/features/scheduleQuery/scheduleSheetFetcher.js`（14号 也照它抄了一版）。
核心：匿名打开分享链接 → 页面里的 `window.APP.workbook` 就是网页版 WPS 表格运行时 → 直接读取单元格。
本项目已复刻为 `src/engine/kdocs.js` + `src/tools/read-kdocs.js`（**只读**，不输入、不保存、不同步）。

## 三、踩坑（都已在代码里处理）
1. **工作表集合的 API 和 1号/14号 的老文档不同**：没有 `getCount()/getItemByIndex()`，要用 **`getNameList()`**；
   单个表用 `getItemByName(名字)`。
2. **`sheet.activate()` 之后 sheet 实例会被换掉**，且 `getUsedRange()` 可能还没挂上 `getRangeContents`
   → 必须「重新 `getItemByName` + 轮询等到 `getRangeContents` 存在」再用。
3. 就绪判断用**函数探测**（`workbook.getWorksheets` → `getItemByName` → `loadSheetData` → `getUsedRange().getRangeContents`），
   不要固定 `sleep` 秒数（1号 的写法）。
4. 匿名打开会有登录邀请浮层，要主动关掉：`#util-popup .wps-login-panel__header__right button`。
5. 底色（条件格式）要用 `sheet.getAppliedXf(行,列).getFill().getBack().getRGB()`，行列偏移取
   `usedRange._ranges[0].rowFrom/colFrom`；`getXfByCell` 读不到条件格式色。

## 四、命令备忘
```bash
node src/tools/read-kdocs.js --list                                  # 列 12 个工作表
node src/tools/read-kdocs.js --sheet "退货退款表" --head 5 --out runtime/kdocs/退货退款表.json
node src/tools/read-kdocs.js --sheet "退货退款表" --grep "5127667812586099609"   # 按订单号找
```
> 大表建议：先 `--out` 导出一次 JSON，再用本地脚本按订单号/状态过滤（比反复打开文档快，也少打扰在线文档）。

## 五、和用户口径的关系（待确认）
用户 2026-09-18 的说法：**能在这张表里搜到客户订单 → 说明漏处理了**。
实测补充：表里同时有「退款状态 / 实际退款金额 / 退款时间」，

只搜到但已退款，可能只是后台显示滞后。**这条要用户拍板**（见 `断点记录.md`）。
