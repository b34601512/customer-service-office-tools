## 快速上手

1. `npm install`
2. 复制 `project-config/platform-config.example.json` 为 `platform-config.json`，填企微机器人与店铺。
3. 双击「启动监控.bat」（**唯一入口**）→ 进**方向键菜单**（↑↓ 选择、数字键直达、回车执行，风格同 1 号控制台）：
   `[1]` 启动常驻监控、`[2]` 停止、`[3]` 立即巡检一轮、`[4]` 查看状态、`[5]` 登录辅助、`[6]` 今日值班、`[0]` 退出。各店浏览器窗口会一直开着，别关。
   （**这是真项目，没有演练/测试入口**：dry-run、测试提醒已彻底删除，`tests/noTestModeGuard.test.js` 锁死不许加回。）

```powershell
node src/cli/startCli.js login jd1          ; 首次为店铺登录一次（弹浏览器人工登录）
node src/cli/startCli.js once               ; 巡检一轮（发现新工单就发提醒）
node src/cli/startCli.js run                ; 常驻监控（窗口保持打开）
node src/cli/startCli.js duty               ; 看今日值班/底色/当前在班@名单
npm test
```

## 常驻监控的几个事实（2026-09-18 落地）

- **窗口一直开着**：每个启用店铺一个 Chrome 窗口（端口从 9411 起、一店一个，登记在 `runtime/state/browser-ports.json`），
  每轮复用同一个窗口，不再"每轮开关"。窗口在，登录态就在；人工关掉窗口/崩了会自动重开。
- **Ctrl+C（退出程序）不会关窗口**：正常退出与强杀单个进程，窗口都留着；
  只有"整棵进程树被杀"（任务管理器结束进程树或托管工具强制停止）会连带窗口，下次启动自动重开且登录态不丢。
- **没登录也不静默**：登录失效会照常发企微提醒（文案里写清"请重新登录京麦"）。
- **界面常驻、看得见在不在跑**：菜单进一次备用屏后**每秒原地重绘**（不清屏，所以不会闪回首页），
  状态区显示 `常驻监控：运行中`、`上次抓到新数据 HH:MM:SS（X 分钟前）`、`下一轮还有 mm:ss`、本轮摘要。
- **10 分钟新鲜度血条**：血条＝数据新鲜度，刚抓到满格、每秒掉一点、**流干＝到点自动重抓，抓到立刻回满**。
  调度就是按这个来的：下一轮排在上次"抓到新数据"之后整整一个间隔（`monitor.intervalMinutes`，当前 10 分钟），
  所以血条见底和下一次抓取是对齐的。
- **菜单是方向键 TUI**（`src/cli/tuiSelect.js`，零依赖）：界面占屏期间控制台日志静音（照旧写 `runtime/logs/run.log`），退出界面/执行动作时恢复；
  非交互环境（管道、被脚本调用）自动回退成"输入编号"的菜单，方便自动化。
- 观察项：配置里写了、但页面上找不到的页签，本轮会不计该类且**不打日志**（等再遇到一次就补显式告警，见断点记录）。
