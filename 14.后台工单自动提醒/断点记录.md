## 四、坑与事实（踩过的，别忘）

- **bat 定稿写法**：纯 ASCII 内容 + CRLF + `chcp 65001` 放第一行 + `goto` 代替括号块；中文界面全交给 node 打印。
  反面教材：UTF-8 + 纯 LF + 中途 `chcp` → cmd 按字节偏移重读串位 → **双击直接闪退**。
- **附着身份校验**不能用 CDP `Browser.getBrowserCommandLine`（它要求启动带 `--enable-automation`，实测永远失败
  → 每轮重开窗口、端口乱漂）。现用 Win32 进程命令行比对，**比对放在 PowerShell 里做、只回 MATCH/NO**（中文路径往返会乱码）。
- **退出菜单必须 `process.exit(0)`**：常驻窗口的 CDP 连接会挂住事件循环（回归测试 `tests/cliMenuExit.test.js`）。
- **窗口生命周期**：正常退出、单进程强杀都**不关窗口**；只有整棵进程树被杀才连带；下次启动自动重开（登录态在 profile 里不丢）。
- 受控 Chrome：端口 `9411` 起（自动顺延）；profile `runtime/state/browser-profiles/jd/<key>`。
- 状态 `runtime/state/monitor-state.json`；台账 `runtime/state/alert-ledger.jsonl`；日志 `runtime/logs/run.log`。
