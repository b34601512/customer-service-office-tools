# 京东 · 进店导航问答（2026-09-21 实测 jd1 德达官方旗舰店）

## 一、入口在哪（本次花时间最多的点）

用户给的 URL `https://xi.jd.com/kf-manage-lite/#/UtilsSetting/AutoReply` 打开后**默认落在「欢迎语」模块**，左侧只有三个 tab：**基础欢迎语 / 常见问题库 / 商品卡片欢迎语**。

**「进店导航自动回复」不是独立菜单，它就叫「常见问题库」。**

「常见问题库」下有两个子 tab：
- **常见问题管理** —— 配置问题 & 回复，标题显示 `添加常见问题（7/10）最多可以添加10个`
- **常见问题数据** —— 每条问题的**近7日点击量** + **最近修改时间**

**怎么找到的**（可复用的排查法）：probe 页面 dump 文本 → 全文没有"进店导航"字样 → **看截图**发现左侧"常见问题库" → 点进去才看到问题列表和点击数据。

> 教训：菜单名可能和功能名不一致（叫"常见问题库"而不是"进店导航"），**找不到就先 dump 文本+截图看全貌**，不要死磕关键词。

## 二、页面结构（jd1 实测）

**常见问题管理**：序号 ｜ 问题 ｜ 回复 ｜ 图片 ｜ 操作（预览/编辑/删除）

**常见问题数据**：问题描述 ｜ 最近修改时间 ｜ 近7日点击量
（**没有排序按钮**，顺序 = 后台默认顺序；没有"同行对比"数据）

## 四、分析口径（怎么判断"要不要优化"）

按这个顺序查：

1. **重复条目** —— 同一问题两种问法 → 客户只会点排在前面的 → 后面的删掉腾名额。
   （实例：第 3 条 28 次 vs 第 6 条 1 次，是同一个"24小时连续用"问题）
2. **低效条目** —— 点击 ≤1 且半年未改 → 候选删除。
   （实例：「如何申请国家补贴」1 次、「可以自动制氧吗」1 次）
3. **缺高频** —— 对照客户实际最常问的（来源：**效果预览图里的默认项**、客服聊天高频、售后工单），库里没有的就是空缺。
   （实例：预览图展示「发什么快递？/什么时候发货？」，但**库里根本没有这两条**；也没有退换货/保修/发票类）
4. **名额** —— 上限 10 条（7/10 → 加 3 条前要先删）
5. **改动前必须先问用户**，不要直接动后台。

## 五、踩坑

- **URL 是 hash 路由，tab 切换靠点击**：`goto` 同一个 URL 不会换视图（三个 tab 的 URL 完全一样）。
- **侧栏 tab 是 `div`，没有 `<a href>`** → 用 `a[href]` 找菜单是空数组，要按文本找元素再 `.click()`。
- **页面文本很短（312 字）不是白屏**：这个后台内容本来就少（欢迎语页 321 字）。别套用"200 字=白屏"的判断（那条针对的是**内容页**）。
- jd1 用的 CDP 端口 **9424**（与 22号、京东售后台账共用同一个浏览器 profile）。

## 六、给其他平台的通用方法（待扩展）

1. **找入口**：从「客服 / 客服管理 / 自动回复 / 机器人 / 接待设置」一类菜单里找「常见问题 / 导航 / 猜你想问 / 咨询导航」。
2. **找数据**：同一模块下一般有「数据 / 统计 / 效果分析」子 tab，重点看**点击量 / 曝光量 / 点击率**。
3. **判优化**：重复 → 低效 → 缺高频（再看名额是否满）。
4. **沉淀格式**：每平台一节，写清 ①入口路径 ②页面结构 ③实测数据 ④分析口径 ⑤踩坑。
