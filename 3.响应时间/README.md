这个工具用于复刻并升级旧按键精灵脚本的核心流程：内置生成测试内容，然后在「网页客户端」和「京东客服端」之间切换、直接写入并发送。

## 核心规则

- 不做图片识别，优先使用窗口标题识别。
- 京东客服端默认用「咚咚融合工作台」识别。
- 启动后默认先暂停，便于完成网页登录；登录完成后按 `F8` 开始。
- `F8` 暂停/继续，`F9` 停止。
- 当前版本固定走内置内容引擎直连发送，不再监听系统剪切板。

## 使用方式

推荐直接双击 `一键启动-无黑窗.vbs` 打开后台，启动时不会显示黑窗。启动器会把日志写到 `logs\last_startup.log`。

如果启动失败或需要看实时输出，再双击 `一键启动.bat` 作为排障入口。

后台会按顺序引导：

1. 打开 `https://dongdong.jd.com/`，等待你登录咚咚客服网页。
2. 检测到客服网页后，打开买家咨询网页，等待你登录买家端。
3. 两个网页都检测到后，点击后台「启动」或按 `F8` 开始；按 `F9` 停止。

排障时也可以用命令行跑旧入口：

```powershell
python .\run.py
```

## 配置

主要配置在 `config.json`：

- `rounds`：总循环轮数。
- `jd_url`：网页客户端地址，可替换为你发来的完整京东链接。
- `service_url`：咚咚客服网页地址，默认 `https://dongdong.jd.com/`。
- `login_flow`：控制网页登录引导、等待超时和是否新窗口打开网页。
- `credentials`：咚咚客服端和买家客户端账号；`*_entries` 保存多个店铺账号档案，后台页面可即时切换保存。
- `temporary_content`：内容生成器配置。
- `web_client.send_delay_sec`：网页客户端发送后的间隔。
- `jd_service.send_delay_sec`：京东客服端发送后的间隔。
- `web_client.title_keywords`：网页窗口标题关键字。
- `jd_service.title_keywords`：京东客服端窗口标题关键字。
- `input_click_ratio`：输入框兜底点击位置，相对窗口宽高比例。

如果控件聚焦失败，程序会用 `input_click_ratio` 点击窗口内的相对位置。这个不是图片识别，是长期可维护的配置兜底。
