# 3.响应时间 · 项目索引

> 开工先看：**本页** → `README.md`（使用方式）→ `CLAUDE.md`（模块）。
> 总规矩：根 `../AGENTS.md` + `../0.木婉清档案/规矩与红线.md`。最后整理：2026-10-09。

- **干嘛的**：京东客服响应时间测试——独立咚咚客服页 + 买家咨询页之间自动生成测试文字、交替写入并发送（测响应时间）。

- **口径**：不做图片识别、优先窗口标题（默认"咚咚融合工作台"）；启动默认暂停，登录后按 `F8` 开始/暂停、`F9` 停止；固定走内置内容引擎直连发送，不监听系统剪切板。
- **命令**：`python run.py --check`；`python -m unittest discover -s tests`。
- **红线**：⚠ 本工具会**真实写入并发送**京东咚咚消息（平台写操作）——与「电商平台后台一律只读」（2026-09-29 最高优先级）冲突：**默认不跑、不维护、不加功能；要跑必须先问用户**。账号/登录态只在本地 `runtime/`，不入库。
