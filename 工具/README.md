# 工具/ · 一页清单（哪个活 → 哪一条命令）

> 只放**现役入口**和命令形状；参数细节在各自文件头，别在这儿抄第二份。
> 为什么要有这一页（2026-11-10 补）：同一个动作每次临时拼命令，拼错一次就白跑一轮；这里一行一条，抄了就能用。
> 规矩：**能一条命令的，不许现场写脚本**；确实要新写，先想能不能收进这里。

## 对外发消息（企微）

| 活 | 命令 |
|---|---|
| 私发一个人（文字） | `node 工具/企微/发企微.cjs --人 "黎路遥" --text "正文" --send` |
| 私发（长文/含反引号、$()） | `node 工具/企微/发企微.cjs --人 "黎路遥" --file 正文.txt --send` |
| 原路回（按回复码） | `node 工具/企微/发企微.cjs --回 R-XXXXXXXXXXXX --text "正文" --send` |
| 发图（可带一句说明） | `node 工具/企微/发图.cjs --人 "黎路遥" --图片 a.png [--图片 b.png] --text "一句" --send` |
| 发群（要 `--理由`，且必须写明**全组/全员/所有人/大家都**） | `node 工具/企微/发企微.cjs --群 "售前群" --理由 "全组都要知道…" --text "正文" --send` |
| 窗与窗之间私信（不走企微） | `node 工具/企微/私信.cjs "巡检员·霍青桐" "正文"`（正文含反引号改 `--从文件 正文.txt`） |
| 读收件箱 / 读完标游标 | `node 工具/企微/读收件箱.mjs` ｜ `node 工具/企微/读收件箱.mjs --mark`（5 分钟内新消息加 `--强标`） |

**坑**：`--理由` 不写「全组都要知道」会被硬拒（不是提示，是拒发）；同人同日第 3 封私信要 `--连发 --理由`；企微单条 ≤2000 字节、不写 markdown。

**量退出码 / 传长文两个坑（2026-11-10 各踩一次）**：
- **别接管道量退出码**：`node x.cjs | tail; echo $?` 拿到的是 `tail` 的 0，不是脚本的。用 `node x.cjs; echo $?` 或 `node x.cjs >/dev/null 2>&1; echo $?`。今天因此把「退 3」误读成「退 0」两次，差点报了个假结论。
- **正文里有反引号/`$(` 时别用 bash 双引号传**：会被当命令执行，中间一段静默消失（今天有一封私信就被吃了一行）。改 `--从文件 正文.txt`（或 `--file`），写完回读一遍再发。

## 仓库工具（tools/，都是唯一出处，别在项目里再写一份）

- 详情看 [`tools/项目索引.md`](tools/项目索引.md) 与 [`tools/CLAUDE.md`](tools/CLAUDE.md)。
- **提交（2026-11-10 实测口径）**：`node 工具/tools/提交.js` 目前把 `工具/` 当成仓库根，**只能提交 `工具/` 下的文件**（缺陷已开 #724）；`0.木婉清档案/`、`记录/` 这些走手工路线：`node 工具/tools/打码.js --扫描` → `git add -- <点名路径>` → `git commit -m "说明" -- <点名路径>` → `node 工具/tools/打码.js --核对`。两条都禁 `-A`/`-u`。
- 打码自查：`node 工具/tools/打码.js --扫描|--学|--核对|--体检`（`--核对` 输出「✅ HEAD 里…都没有真值」才算过）。
- 共享实现：`tools/浏览器引擎/`（拉起/附着/关闭浏览器）、`tools/金山表/`（读金山链接、调只读 AirScript）、`工具/群消息/`（webhook 纯通知，要人回的事不许用）。
- 各项目里的同名文件都是薄壳，加测试锁住「不许自带一份」。

## 危险操作

- 任何删/批量覆盖/停用/清空/授权变更/发布上线/改写 git 历史：先跑 `node 工具/危险操作确认.cjs --要做 "…" --密码 <他从企微念的四到八位>`（口令只在本机，不进文档、不进仓库）。

- 群白名单再叠一层：`发企微.cjs` 已有精确群名＋理由≥8字＋一次性路由票三重硬锁，再加收益低。

```bash

node 工具/抖音登录驱动.cjs --店 douyin-store-2     # 换店（同号共用一份浏览器资料）
node 工具/抖音登录驱动.cjs --只发码                # 只发码，人自己在窗口里填
```

- 做什么：复用李沅芷项目的 Edge 资料目录（`6.抖音发票回传/runtime/account-profiles`），停在登录页 → 点「发送验证码」→ 打印「码已发」→ 等 `工具/.state/抖音验证码-答案.txt` 里出现 6 位数字 → 填码登录 → 检测 URL 离开 `/login`。
- 为什么有它：她的 `抖音登录助手.js` 只开窗不会自己点发码；黎路遥 2026-11-13 定「抖音不用问，直接干」。
