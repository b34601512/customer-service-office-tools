# 售后待办（企微智能表格）

- 文档＝企微智能表格《**售后待办清单**》（同名子表）；售前那份对应售前组。**只读为主**，加行按下面命令。
- docid／sheet／链接是本机私有：见 `售后待办.local.json`（不入库）。

## 加一行

```bash
node 工具/售后待办/写售后待办.cjs --content "要做的事" [--deadline "…"]
node 工具/售后待办/写售后待办.cjs --content "要做的事" --owner <userid> --owner-name <名字>   # 确实要派给定人才用
```

写完自动回读校验（优先认新增返回的 record_id，拿不到才用正文前 20 字）；输出会写「负责人必需名与来源」。

## 派给谁（**默认就是查值班，不用你管**）

- **不传 owner**（或 `--owner auto`）→ 工具自己拿焦宛儿 `28号` 那套：排班表底色＋**此时此刻在某班次**，只在售后名单里挑。**挑不到就硬报错、不写表**。
- 为什么不再「默认李某某」（2026-11-05 黎路遥问出来的）：组长也会休息，默默派给他就是派给一个不在岗的人，14 号工单提醒还会白 @ 他。当天就真发生了——售后待办两行写了李某某，而他当天没上班。
- 显式派：`--owner <userid> --owner-name <名字>`，**两个必须一起给**；只给名字会报错，只给 id 会报错（宁可停下问，不编假名）。

## 字段

待办事项 · 负责人 · 截止时间 · 优先级 · 任务类型 · 跟进备注 · 处理结果 · 是否完成

**备注里已写处理动作（如「已通知拦截」）＝已处理**，可勾完成、不跟催。
