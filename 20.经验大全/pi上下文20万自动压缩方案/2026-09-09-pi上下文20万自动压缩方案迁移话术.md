# 给另一台电脑 AI 的任务话术（可直接复制全段发送）

【任务】
把本机 pi 的"上下文 20 万天花板"配置，改成"保留真实窗口 + 上下文到 20 万自动压缩"。

【背景】
现在本机把各模型的 contextWindow 谎报成 200000。导致 pi 误以为可以用到约 18.4 万才触发压缩；
而压缩时要先把约 16 万历史再发一次给模型，这就会冲出 20 万窗口，压缩自身溢出失败重试 = 卡死。
（此前出现过压缩卡死，病根就在此。若你（另一台的 AI）检查后与本描述不符，先停下说明，不要照做。）

- [ ] 1. 所有谎报窗口的 modelOverrides（contextWindow: 200000）已移除；各模型回到网关真实窗口（1M 就是 1M），新模型自动带真实窗口，永不需手动配。
- [ ] 2. 存在全局扩展 auto-compact-200k.ts，内容与下面给定代码一致：上下文 ≥ 20 万自动压缩；大窗口模型正好 200k 触发，小窗口自动提前到 窗口−65536 且不低于窗口的 50%；压缩进行中加锁；压缩后需再涨 2 万才重试，防死循环。

- [ ] 4. 给出修改前后对比：哪些模型的窗口从 200000 恢复为真实值；按真实窗口计算每个常用模型的触发点。
- [ ] 5. /reload 或重启 pi 后，扩展出现在 extensions 列表（可跑 /settings 验证）。

【边界】
- 不能动 models-store.json（那是网关返回的真实模型目录，删了会丢真源）。
- 不能关闭内置压缩。
- 阈值以后只能通过环境变量 PI_AUTO_COMPACT_TOKENS 调整（如 PI_AUTO_COMPACT_TOKENS=140000），不允许改代码。
- 任何删除类操作前必须确认"备份文件夹"里已有可恢复的副本；没有备份就不许删。

import type { ExtensionAPI, ExtensionContext } from "@earendil-works/pi-coding-agent";

/**
 * 全局自动压缩：上下文达到 20 万 token 即压缩，与模型窗口无关 → 新模型自动生效。
 *
 * 余量设计（避免"卡死"）：
 *   1. 压缩本身要把待总结内容发给模型，所以触发点必须低于窗口上限 → 预留 HEADROOM。
 *   2. 窗口 < 20万 的模型（如 128k）提前到 窗口−HEADROOM，且不低于窗口的 50%。
 *   3. 单轮内暴涨由内置阈值（settings.compaction.reserveTokens）做溢出安全网，本扩展不接管。
 *   4. 压缩后仍超阈值时，需再增长 RETRY_SLACK 才重试，防死循环。
 *
 * 可用环境变量 PI_AUTO_COMPACT_TOKENS 覆盖目标阈值（一般不需要）。
 */
const DEFAULT_TARGET = 200_000;
const HEADROOM = 65_536; // 给模型回复 + 压缩请求自身留的余量（激进：提早约 6.4万）
const RETRY_SLACK = 20_000;
const MIN_WINDOW_RATIO = 0.5;

function targetTokens(): number {
	const raw = Number(process.env.PI_AUTO_COMPACT_TOKENS);
	return Number.isFinite(raw) && raw > 0 ? raw : DEFAULT_TARGET;
}

export default function (pi: ExtensionAPI) {
	let compacting = false;
	let lastCompactedTokens: number | undefined;

	pi.on("turn_end", (_event, ctx: ExtensionContext) => {
		const usage = ctx.getContextUsage();
		if (!usage || usage.tokens === null || usage.tokens === undefined) return;

		const window = usage.contextWindow || ctx.model?.contextWindow || 0;
		let threshold = targetTokens();
		if (window > 0 && window - HEADROOM < threshold) {
			// 小窗口模型：提前到 窗口−HEADROOM，且不低于窗口 50%（防微小窗口震荡）
			threshold = Math.max(window - HEADROOM, Math.floor(window * MIN_WINDOW_RATIO));
		}

		if (usage.tokens < threshold) {
			// 已明显回落（压缩生效/切换小窗口模型），解除重试基线
			if (lastCompactedTokens !== undefined && usage.tokens < threshold * 0.9) {
				lastCompactedTokens = undefined;
			}
			return;
		}
		if (compacting) return;
		if (lastCompactedTokens !== undefined && usage.tokens < lastCompactedTokens + RETRY_SLACK) return;

		compacting = true;
		lastCompactedTokens = usage.tokens;
		ctx.ui?.notify?.(
			`上下文 ${Math.round(usage.tokens / 1000)}k ≥ 阈值 ${Math.round(threshold / 1000)}k，自动压缩中…`,
			"info",
		);
		ctx.compact({
			onComplete: () => {
				compacting = false;
			},
			onError: () => {
				compacting = false;
			},
		});
	});
}
