# kdocs 整表回读校验与「筛选」

**一句话**：金山在线表格（kdocs）里，脚本写完表做「整表逐格回读比对」时，如果目标表**开着筛选**，回读值与上传值会不一致 → 脚本会报「保存后回读不一致」，看起来像保存失败。

- 首次实录：2026-10-09 09:44，9号客服数据「一键同步明细」报 `AirScript 执行失败：保存后在线“数据明细”整表回读与上传值不一致。`（在线脚本 `2026-08-07.8`：写 `A1:X{n}` → 设格式 → 清尾 → `Save()` → 整表回读比对）。黎路遥 09:50 告知根因：**数据明细表筛选了**。
- 处置口径：
  1. 先把目标表的**筛选清掉**，再重跑同步（9号：`cd 9.客服数据自动更新 && node scripts/同步金山明细.js`，只同步、不采集、不改本地）。
  2. **报错 ≠ 一定没写进去**：以只读回读核验在线实际状态为准（本轮在线状态待核）。
  3. 失败后**不自动重试**：人工判定后单次补跑（9号历史同错 12 次，均靠重跑恢复）。
- 现场与台账：`失败台账.md`（2026-10-09 09:39~09:44 条）；回执 `0.木婉清档案/任务回执/2026-10-09-日常巡检-9号数据.md`。
