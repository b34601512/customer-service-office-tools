## 改脚本的标准流程（用户 2026-09-30 定）

1. 本地改脚本（存在 `2.发票自动化/7.自动登记发票/project-config/kdocs-scripts/`）；
2. `登记脚本.cjs --已确认` 把**新版全文**登记进大全；
3. **只告诉用户「第 X 行已更新」** —— 用户自己去那一行复制 → 粘到**目标文档**的 AirScript → 保存；
4. 粘完**必须验证**：写脚本跑 `探针.js`（报 scriptVersion），读脚本跑一次只读查询；不过就停手（见 `失败台账.md` 2026-09-30 粘坏事故）。
