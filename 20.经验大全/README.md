# 20.经验大全

一个经验一个文件夹，供人和 AI 直接复用：每个文件夹内有一份经验说明 Markdown；需要脚本的经验再附一份可直接运行的只读脚本。

## 目录

| 文件夹 | 经验 | 配套脚本 |
| --- | --- | --- |
| [金山在线Word文档读取](./金山在线Word文档读取/) | 金山在线 Word/大纲文档（`otl`）无 GUI 读取正文与图片 | `金山在线Word文档读取.cjs` |
| [金山在线表格排班表读取](./金山在线表格排班表读取/) | 金山在线表格（排班表）读取值矩阵与单元格有效背景色（条件格式） | `金山在线表格排班表读取.cjs` |
| [pi上下文20万自动压缩方案](./pi上下文20万自动压缩方案/) | 把 pi 的上下文 20 万自动压缩方案迁移到另一台电脑的任务话术 | — |

## 使用约定

- 先读对应文件夹里的 `*经验.md`，里面有完整步骤、实测结论和常见坑。
- 有配套脚本时优先直接运行，不要重写。脚本依赖借用已有项目即可：

```powershell
$env:NODE_PATH = "D:\桌面\办公软件\1.客服超时督办\node_modules"
node "<脚本路径>" --help
```

- 所有脚本默认只读：不写入在线文档，不保存、不打印 Cookie/token，真实登录态只留在本机浏览器画像。

## 新增经验

1. 新建文件夹，文件夹名就是经验名；
2. 放入 `<经验名>.md`（关键代码可以直接内嵌在 Markdown 里）；
3. 如需可复用脚本，放入 `<经验名>.cjs`，并在 Markdown 开头注明“配套脚本：同目录 …”；
4. 更新本 README 的目录表。
